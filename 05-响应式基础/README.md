> 课时：4 课时

---

## 🎯 本章目标

学完这章，你将能够：

- ✅ 理解 Vue **响应式的本质**——数据变了 UI 自动跟着变
- ✅ 熟练使用 **`ref()`** 包装基本类型数据
- ✅ 熟练使用 **`reactive()`** 包装对象
- ✅ 区分 **`ref` vs `reactive`** 的使用场景
- ✅ 理解 **Proxy 拦截**的工作原理
- ✅ 掌握 **`nextTick`** 等待 DOM 更新
- ✅ 避免 4 个常见的"响应式丢失"陷阱

---

## 🤔 为什么学这章

**Vue 的"魔法"就是响应式**——你改 `count.value`，UI 自动更新。本章揭开这个魔法的原理。

**学完这章，你会**：
- 不只是"会用 `ref`"，而是"知道为什么改 `count.value` UI 会更新"
- 能**避开 90% 的响应式 bug**（比如直接赋值丢失响应式）
- 为下章的 `watch` / `watchEffect` 打基础

> 🧑 **小白**：我明明只改了一个 `count`，为什么页面上所有用到它的地方都自动变了？这不会是魔法吧？

> 🤖 **Vue 君**：不是魔法，是"响应式"——我在背后用 Proxy 盯着你的数据，一变就通知界面刷新。

> 👨🏫 **老湿**：很多面试题和线上 Bug 都藏在这章。弄懂 `ref` / `reactive` 的底层套路，你就超过 80% 的初级开发者。

## 🛠 本章实战

1. 用 `ref` 写一个**计数器**（点 +1，数字自动更新）
2. 用 `reactive` 写一个**用户表单**（双向绑定）
3. 故意**整个替换** `reactive` 对象，看响应式会不会丢
4. 用 `nextTick` 在 DOM 更新后**读最新的 DOM 值**
