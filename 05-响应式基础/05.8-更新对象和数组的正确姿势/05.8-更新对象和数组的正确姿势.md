
基础类型用 `ref` 换个 `.value` 就完事，可一上对象和数组，"改了没反应"就冒出来：`reactive` 里直接 `arr[2] = x` 界面不动、`filter` 换新数组页面还是旧的。这些坑有的已被 Proxy 填平，有的要靠方法或整体替换来绕。本节把对象和数组的"正确姿势"一次讲清，附快速参考卡。

## 🤔 一、为什么"正确姿势"是个问题？

在 Vue 2 里，对象和数组的响应式有很多坑——`arr[i] = x` 不触发更新、`obj.newKey = val` 不触发更新——这些坑源于 Vue 2 用 `Object.defineProperty` 做响应式。

Vue 3 换成了 `Proxy`，很多 Vue 2 的坑已经不存在了。但某些操作**依然需要注意**，尤其在使用 `reactive` 时。本节把这些注意事项一网打尽。

---

## 💡 二、对象更新的正确姿势

### 2.1 直接改属性 → 没问题

```js
const state = reactive({ user: { name: '张三', age: 20 } })

// ✅ Vue 3 的 Proxy 能拦截嵌套属性的修改
state.user.name = '李四'
state.user.age = 21
```

### 2.2 添加新属性 → 也没问题

```js
const state = reactive({ name: '张三' })

// ✅ Vue 3 的 Proxy 能拦截属性新增
state.age = 20
state.email = 'zhangsan@test.com'
```

这是 Vue 3 相比 Vue 2 最大的改进之一。Vue 2 需要 `Vue.set(obj, 'newKey', value)`，Vue 3 不需要。

### 2.3 删除属性 → 没问题

```js
// ✅ delete 也能被 Proxy 拦截
delete state.age
```

### 2.4 整体替换 → 有问题

```js
let state = reactive({ count: 0 })

// ❌ 断开了响应式引用
state = reactive({ count: 1 })

// ✅ 正确做法：
Object.assign(state, { count: 1, name: 'new' })
```

## 🛠 三、数组更新的正确姿势

### 3.1 Vue 能拦截的数组方法

这些方法修改数组后**会自动触发更新**：

| 方法 | 作用 |
|---|---|
| `push()` | 末尾添加 |
| `pop()` | 末尾删除 |
| `shift()` | 开头删除 |
| `unshift()` | 开头添加 |
| `splice()` | 删除/插入/替换 |
| `sort()` | 排序 |
| `reverse()` | 反转 |

```js
const list = reactive([1, 2, 3])

list.push(4)           // ✅ [1, 2, 3, 4]
list.splice(1, 1, 99)  // ✅ [1, 99, 3, 4]
list.sort((a, b) => b - a)  // ✅ 触发更新
```

### 3.2 不能直接通过索引赋值

```js
const list = reactive([1, 2, 3])

// ❌ 不会触发更新！
list[0] = 999

// ✅ 用 splice 替代
list.splice(0, 1, 999)
```

> 💬 **老师备注**：看到 `list[0] = 999` 心里先别急着敲代码——`reactive` 数组按索引赋值、`length` 截断这类"元操作"最容易静默失效。想不起来 API 没关系，搜一下"splice 三个参数"比调半天 Bug 快得多。

### 3.3 不能直接用 length 截断

```js
const list = reactive([1, 2, 3, 4, 5])

// ❌ 不会触发更新！
list.length = 2

// ✅ 用 splice 替代
list.splice(2)
```

### 3.4 filter/map/concat 等返回新数组的方法

```js
const list = reactive([1, 2, 3])

// ❌ 返回的是新数组，没赋值给原变量
list.filter(n => n > 1)  // 返回 [2, 3]，但 list 还是 [1, 2, 3]

// ✅ 用 splice 清空再 push
const filtered = list.filter(n => n > 1)
list.splice(0, list.length, ...filtered)
```

## 🔧 四、ref 数组 vs reactive 数组

如果你用 `ref` 包数组，行为就不一样了：

```js
const list = ref([1, 2, 3])

// ✅ ref 数组的索引赋值是 OK 的！
list.value[0] = 999  // 因为 ref 的 setter 会 trigger
```

为什么？因为 `ref` 数组是通过 `.value` 整体替换来触发更新的——Vue 只监听 `.value` 的变化。但注意：这是通过 Vue 内部对 `ref` 套 `reactive` 时的深层代理实现的。安全起见，建议统一用 `splice`。

---

## 💡 五、shallowReactive：轻量级响应式

`shallowReactive` 和 `shallowRef` 是一对——它只代理对象的第一层属性。

```js
import { shallowReactive } from 'vue'

const state = shallowReactive({
  count: 0,                 // ✅ 响应式（第一层）
  user: { name: '张三' },   // ❌ user 内部不是响应式
  list: [1, 2, 3]           // ❌ list 内部元素不是响应式
})

// ✅ 能触发更新
state.count++
state.user = { name: '李四' }

// ❌ 不触发更新
state.user.name = '李四'
state.list.push(4)
```

**适用场景**：

| 场景 | 推荐 |
|---|---|
| 大型配置对象，只关心顶层字段替换 | `shallowReactive` |
| 表单对象，字段都是基本类型 | `reactive`（深层不用白不用） |
| 第三方库返回的大对象 | `shallowReactive` |
| 不可变数据管理 | `shallowReactive` + `markRaw` |

```js
// 典型场景：应用配置
const config = shallowReactive({
  theme: 'light',
  lang: 'zh-CN',
  sidebarCollapsed: false,
  // 只改这些顶层字段，不需要深层响应式
})
```

## ⚠️ 六、常见陷阱汇总

| 操作 | reactive | ref |
|---|---|---|
| 对象属性赋值 | ✅ `obj.key = val` | ✅ `obj.value.key = val` |
| 对象整体替换 | ❌ | ✅ `obj.value = newObj` |
| 数组索引赋值 | ❌ `arr[i] = x` | ✅ `arr.value[i] = x` |
| 数组 push/pop 等 | ✅ | ✅ |
| `arr.length = 0` | ❌ | ✅（通过 ref setter） |
| filter/map/concat | ❌（需赋值回去） | ✅（赋值 `.value`） |
| 新增属性 | ✅ | ✅ |
| 删除属性 | ✅ | ✅ |

## 📝 快速参考卡

```
🔧 reactive 数组修改速查：

  arr[i] = newVal    →  arr.splice(i, 1, newVal)
  arr.length = n     →  arr.splice(n)
  arr = filtered     →  arr.splice(0, arr.length, ...filtered)
  arr.push/pop/shift/unshift/sort/reverse  →  直接用 ✅
```

## 🧠 本节小结

- **Vue 3 已填平的坑**：Proxy 让 `obj.newKey = val` 新增属性默认可响应（Vue 2 不行）；新增/删除对象属性用 `Object.assign` 或 `delete` 都更稳妥
- **reactive 数组别按索引赋值**：`arr[i] = x` 不可靠，统一用 `splice` 替代（`list.splice(i, 1, x)`）
- **ref 数组更新**：`arr.value[i] = x`、`arr.value.push(...)` 都可以；整体换 `.value` 也行
- **length 截断/整体替换**：`arr.length = n` → 用 `splice(n)`；`arr = filtered` → `splice(0, arr.length, ...filtered)`
- **快速参考**：能用方法改原数组就优先 `push/pop/shift/unshift/splice/sort/reverse`，别动不动换新引用
