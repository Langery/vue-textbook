## 💡 二、useDebounce：防抖

### 2.1 什么是防抖？

用户快速输入时，每次都发请求太浪费。防抖的策略是：**等用户停止输入 N 毫秒后，再执行一次操作。**

```text
用户输入:  a  p  p  l  e
          |  |  |  |  |
请求发送:                ← (等了 500ms 后只发一次)
```

### 2.2 实现

```js
// composables/useDebounce.js
import { ref, watch } from 'vue'

/**
 * 防抖 composable
 * @param {import('vue').Ref} source - 要防抖的响应式值
 * @param {number} delay - 延迟毫秒数，默认 300
 * @returns {import('vue').Ref} 防抖后的值
 */
export function useDebounce(source, delay = 300) {
  const debounced = ref(source.value)  // 初始值同步
  let timer = null

  watch(source, (newVal) => {
    // 每次 source 变化，清除上一次的定时器
    clearTimeout(timer)
    // 重新设置定时器
    timer = setTimeout(() => {
      debounced.value = newVal
    }, delay)
  })

  return debounced
}
```

### 2.3 使用

```vue
<script setup>
import { ref } from 'vue'
import { useDebounce } from './composables/useDebounce'

const keyword = ref('')
const debouncedKeyword = useDebounce(keyword, 500)

// 监听防抖后的值，发送搜索请求
watch(debouncedKeyword, async (kw) => {
  if (kw.length < 2) return
  console.log('发送搜索请求：' + kw)
  // await fetch(`/api/search?q=${kw}`)
})
</script>

<template>
  <input v-model="keyword" placeholder="搜索..." />
  <p>实时输入：{{ keyword }}</p>
  <p>防抖后（500ms）：{{ debouncedKeyword }}</p>
</template>
```

### 2.4 进阶：带 cancel 能力

```js
export function useDebounce(source, delay = 300) {
  const debounced = ref(source.value)
  let timer = null

  watch(source, (newVal) => {
    clearTimeout(timer)
    timer = setTimeout(() => { debounced.value = newVal }, delay)
  })

  // 提供取消方法
  function cancel() {
    clearTimeout(timer)
    timer = null
  }

  // 立即刷新（不等延迟）
  function flush() {
    cancel()
    debounced.value = source.value
  }

  return { debounced, cancel, flush }
}
```

## 🔑 三、useLocalStorage：持久化

### 3.1 需求

很多时候你希望用户的偏好设置（主题、语言、字体大小）**关掉浏览器再打开还在**。`ref` 只在内存里，刷新就没了。`localStorage` 可以持久化，但不是响应式的。

`useLocalStorage` 把两者结合：**一个 ref，读写自动同步到 localStorage**。

### 3.2 实现

```js
// composables/useLocalStorage.js
import { ref, watch } from 'vue'

/**
 * 持久化响应式数据到 localStorage
 * @param {string} key - localStorage 的键名
 * @param {*} defaultValue - 默认值（localStorage 里没有时使用）
 * @returns {import('vue').Ref}
 */
export function useLocalStorage(key, defaultValue) {
  // 1. 初始化：尝试从 localStorage 读取
  const stored = localStorage.getItem(key)
  const data = ref(stored !== null ? JSON.parse(stored) : defaultValue)

  // 2. 监听 data 变化，自动写入 localStorage
  watch(
    data,
    (newVal) => {
      if (newVal === null || newVal === undefined) {
        localStorage.removeItem(key)
      } else {
        localStorage.setItem(key, JSON.stringify(newVal))
      }
    },
    { deep: true }  // 深度监听，对象属性变化也能感知
  )

  return data
}
```

### 3.3 使用

```
<script setup>
import { useLocalStorage } from './composables/useLocalStorage'

// theme 和 localStorage 自动同步
const theme = useLocalStorage('app-theme', 'light')
const fontSize = useLocalStorage('app-font-size', 16)
const userPrefs = useLocalStorage('user-prefs', {
  showSidebar: true,
  language: 'zh'
})

function toggleTheme() {
  theme.value = theme.value === 'light' ? 'dark' : 'light'
  // 不用手动 localStorage.setItem —— 自动同步了！
}
</script>

<template>
  <div :class="theme">
    <button @click="toggleTheme">
      当前主题：{{ theme }}
    </button>
    <p>字体大小：{{ fontSize }}px</p>
    <p>侧边栏：{{ userPrefs.showSidebar ? '显示' : '隐藏' }}</p>
  </div>
</template>
```

刷新浏览器 → 主题还是 `dark`，因为 localStorage 里存着呢。

### 3.4 进阶：处理 JSON 解析错误

```js
function safeJSONParse(str, fallback) {
  try {
    return JSON.parse(str)
  } catch {
    return fallback
  }
}

const stored = localStorage.getItem(key)
const data = ref(stored !== null ? safeJSONParse(stored, defaultValue) : defaultValue)
```

## 🛠 四、useMouse：鼠标追踪

### 4.1 实现

```js
// composables/useMouse.js
import { ref, onMounted, onUnmounted } from 'vue'

/**
 * 追踪鼠标位置
 * @returns {{ x: Ref<number>, y: Ref<number> }}
 */
export function useMouse() {
  const x = ref(0)
  const y = ref(0)

  function update(event) {
    x.value = event.pageX
    y.value = event.pageY
  }

  onMounted(() => window.addEventListener('mousemove', update))
  onUnmounted(() => window.removeEventListener('mousemove', update))

  return { x, y }
}
```

### 4.2 进阶版：追踪更多信息

```js
// composables/useMouse.js
import { ref, onMounted, onUnmounted } from 'vue'

/**
 * 增强版鼠标追踪
 * @returns {{ x, y, sourceType, isPressed }}
 */
export function useMouse() {
  const x = ref(0)
  const y = ref(0)
  const sourceType = ref('mouse')   // 'mouse' | 'touch' | 'pen'
  const isPressed = ref(false)

  function onMove(e) {
    x.value = e.pageX
    y.value = e.pageY
    sourceType.value = e.pointerType || 'mouse'
  }

  function onDown() { isPressed.value = true }
  function onUp()   { isPressed.value = false }

  onMounted(() => {
    window.addEventListener('pointermove', onMove)
    window.addEventListener('pointerdown', onDown)
    window.addEventListener('pointerup', onUp)
  })

  onUnmounted(() => {
    window.removeEventListener('pointermove', onMove)
    window.removeEventListener('pointerdown', onDown)
    window.removeEventListener('pointerup', onUp)
  })

  return { x, y, sourceType, isPressed }
}
```

> 💬 **老师备注**：进阶版用 `pointermove` 替代 `mousemove`，这样可以同时支持鼠标、触摸屏和触控笔，一个事件搞定所有。

### 4.3 使用：跟随鼠标的 Tooltip

```vue
<script setup>
import { useMouse } from './composables/useMouse'

const { x, y } = useMouse()
</script>

<template>
  <div
    class="tooltip"
    :style="{ left: x + 15 + 'px', top: y + 15 + 'px' }"
  >
    我是跟随鼠标的提示框
  </div>
</template>

<style scoped>
.tooltip {
  position: fixed;
  pointer-events: none;
  background: #333;
  color: #fff;
  padding: 4px 8px;
  border-radius: 4px;
  font-size: 12px;
  z-index: 9999;
}
</style>
```

## 📦 五、VueUse 简介

写完这三个 composable，你可能会想："防抖、localStorage、鼠标追踪……这些功能是不是有人已经写好了？"

有的！**VueUse** 是 Vue 官方团队成员维护的 composable 工具库，包含 **200+** 开箱即用的 composable。

```bash
npm install @vueuse/core
```

```
<script setup>
// 不用自己写 useMouse，VueUse 直接提供
import { useMouse } from '@vueuse/core'
const { x, y } = useMouse()

// 不用自己写 useLocalStorage
import { useStorage } from '@vueuse/core'
const theme = useStorage('app-theme', 'light')

// 不用自己写 useDebounce
import { refDebounced } from '@vueuse/core'
const keyword = ref('')
const debouncedKeyword = refDebounced(keyword, 500)

// 还有更多：useDark, useToggle, useClipboard, useTitle...
import { useDark, useToggle } from '@vueuse/core'
const isDark = useDark()
const toggleDark = useToggle(isDark)
</script>
```

| VueUse API | 功能 |
|---|---|
| `useMouse` | 鼠标位置 |
| `useStorage` | localStorage / sessionStorage |
| `refDebounced` | ref 防抖 |
| `useDark` | 深色模式 |
| `useToggle` | 布尔切换 |
| `useClipboard` | 剪贴板 |
| `useTitle` | 页面标题 |
| `useFetch` | 网络请求 |

> 💬 **老师备注**：即使你不用 VueUse，了解它的存在本身就是一种成长——以后遇到"这个功能有没有现成的 composable？"时，先去 VueUse 搜一下。但**学会自己写是基础**，因为总有一天你会遇到 VueUse 没有的功能。

## ⚠️ 六、常见陷阱

### 陷阱 1：useDebounce 中忘记清理定时器

```js
// ❌ 旧的定时器还在跑，内存泄漏
watch(source, (val) => {
  setTimeout(() => { debounced.value = val }, delay)
})

// ✅ 每次都先清掉上一个
watch(source, (val) => {
  clearTimeout(timer)
  timer = setTimeout(() => { debounced.value = val }, delay)
})
```

### 陷阱 2：useLocalStorage 的循环写入

```js
// ❌ 可能会在初始化时触发 watch 写入，但通常无害
// ✅ 更好的做法：用 { immediate: false } 或标志位控制
```

### 陷阱 3：所有组件共享一个 useMouse 实例

每个组件调 `useMouse()` 都会创建独立的 `x`、`y` ref 和独立的事件监听器。如果多个组件同时用 `useMouse`，会在 `window` 上绑多个 `mousemove` 监听。这在大多数场景下可以接受，但如果组件数量很多，考虑把 `useMouse` 做成全局单例。

## 🧠 本节小结

- **useDebounce**：`ref` 双向 + 定时器防抖，进阶给 `cancel()`；记得清理定时器防泄漏
- **useLocalStorage**：把状态与 localStorage 双向同步；JSON 解析要 try/catch 兜底，防止脏数据崩组件
- **useMouse**：监听 `mousemove` 维护坐标 ref；注意每个组件实例独立监听器，组件多时考虑全局单例，并记得 unmounted 清理
- **通用套路**：拆"内部 state + 副作用管理 + 对外 ref 返回值"三层，内部副作用记得成对清理
- **进阶组合**：composable 内部可用 watch/watchEffect/computed，做成"带衍生数据的完整模块"
