## 🤔 一、VueUse 是什么？

回顾第 8 章，你手写了 `useDebounce`、`useLocalStorage`、`useMouse`。每个 composable 几十行代码，写完还要考虑边界情况、内存泄漏、TypeScript 类型。作为学习过程这很有价值，但在真实项目中，每次都手写这些就是在重复造轮子。

**VueUse** 就是答案。它是 Vue 核心团队成员 Anthony Fu 主导维护的 composable 工具库，提供了 200+ 个高质量、类型安全、tree-shakable 的 composable。

```bash
npm install @vueuse/core
```

```vue
<script setup>
// 不需要手写，直接 import
import { useStorage, useDark, useToggle, useClipboard } from '@vueuse/core'
</script>
```

> 💬 **老师备注**：VueUse 对 Vue 开发者来说就像 Lodash 对 JS 开发者——不是必须，但用过的都回不去了。它把"从零写轮子"变成了"从工具箱拿工具"，让你把精力集中在业务逻辑上。

## 💡 二、useStorage：比你手写的 useLocalStorage 更强

### 2.1 基本用法

```
<script setup>
import { useStorage } from '@vueuse/core'

// 这就是全部代码
// 一个 ref，读 localStorage，改了自动写回去
const theme = useStorage('app-theme', 'light')
const fontSize = useStorage('app-font-size', 16)
const dismissed = useStorage('banner-dismissed', false)
</script>

<template>
  <div :class="theme">
    <p>当前主题：{{ theme }}</p>
    <button @click="theme = theme === 'light' ? 'dark' : 'light'">
      切换主题
    </button>
  </div>
</template>
```

刷新浏览器 → 主题还在。`useStorage` 做的事情：

- 初始化时从 `localStorage` 读取，没读到用默认值
- 数据变化时自动写入 `localStorage`
- 支持字符串、数字、布尔、对象、数组（自动 JSON 序列化/反序列化）
- 多个 Tab 之间同步（通过 `storage` 事件）

### 2.2 对比：手写 vs VueUse

**手写 `useLocalStorage`（第 8 章写的）：**

```js
// 30 行代码
import { ref, watch } from 'vue'

export function useLocalStorage(key, defaultValue) {
  const stored = localStorage.getItem(key)
  const data = ref(stored !== null ? JSON.parse(stored) : defaultValue)

  watch(data, (newVal) => {
    if (newVal === null || newVal === undefined) {
      localStorage.removeItem(key)
    } else {
      localStorage.setItem(key, JSON.stringify(newVal))
    }
  }, { deep: true })

  return data
}
```

**VueUse 的 `useStorage`：**

```js
import { useStorage } from '@vueuse/core'
const data = useStorage('my-key', defaultValue)
// 一行搞定，还自带 TypeScript 类型推断、sessionStorage 支持、序列化器自定义……
```

### 2.3 进阶：sessionStorage、自定义序列化

```js
import { useStorage } from '@vueuse/core'

// 用 sessionStorage（关闭浏览器即清空）
const token = useStorage('auth-token', null, sessionStorage)

// 自定义序列化
const config = useStorage('app-config', { lang: 'zh' }, localStorage, {
  serializer: {
    read: (v) => v ? JSON.parse(v) : null,
    write: (v) => JSON.stringify(v),
  }
})
```

## 🔑 三、useDark：暗黑模式，三行代码搞定

### 3.1 开箱即用

```vue
<script setup>
import { useDark, useToggle } from '@vueuse/core'

// 一行：创建暗黑模式状态
const isDark = useDark()

// 一行：创建切换函数
const toggleDark = useToggle(isDark)
</script>

<template>
  <div>
    <p>当前模式：{{ isDark ? '🌙 暗黑' : '☀️ 明亮' }}</p>
    <button @click="toggleDark()">切换模式</button>
  </div>
</template>
```

`useDark()` 自动做了以下事情：

1. 从 `localStorage` 读取用户偏好（key 默认是 `vueuse-color-scheme`）
2. 如果没有存储过，读取系统偏好（`prefers-color-scheme: dark`）
3. 在 `<html>` 标签上自动添加/移除 `class="dark"`
4. 状态变化时自动持久化

### 3.2 配合 Tailwind CSS

Tailwind CSS 的暗黑模式要求 `<html>` 上有 `class="dark"`，这和 `useDark` 的行为完美吻合：

```html
<!-- useDark 自动加 class="dark" -->
<html class="dark">
  <body>
    <!-- Tailwind 的 dark: 前缀自动生效 -->
    <div class="bg-white dark:bg-gray-900 text-black dark:text-white">
      这段文字在暗黑模式下自动变色
    </div>
  </body>
</html>
```

### 3.3 自定义配置

```js
import { useDark, useToggle } from '@vueuse/core'

const isDark = useDark({
  selector: 'body',               // 改在 body 上加 class
  attribute: 'theme',             // 改用 theme 属性而不是 class
  valueDark: 'dark-mode',         // 暗黑模式的值
  valueLight: 'light-mode',       // 明亮模式的值
  storageKey: 'my-app-theme',     // localStorage 键名
  onChanged(dark) {
    console.log('主题切换为：', dark ? '暗黑' : '明亮')
  }
})
```

> 💬 **老师备注**：很多初学者花几小时折腾"暗黑模式"——手动管理 CSS 变量、localStorage、系统偏好检测、Class 切换。`useDark` 把这些全部封装好了。这就是"现成 composable"的价值：**别人踩过的坑你不用再踩一遍**。

## 🛠 四、useClipboard：剪贴板操作

### 4.1 复制文本

```
<script setup>
import { useClipboard } from '@vueuse/core'

const { copy, copied, isSupported } = useClipboard()

async function handleCopy(text) {
  if (!isSupported.value) {
    alert('当前浏览器不支持剪贴板操作')
    return
  }

  await copy(text)
  // copied.value 在 1.5 秒内为 true（默认），可以显示"已复制"提示
}
</script>

<template>
  <div>
    <code>npm install @vueuse/core</code>
    <button @click="handleCopy('npm install @vueuse/core')">
      {{ copied ? '✅ 已复制' : '📋 复制' }}
    </button>
  </div>
</template>
```

### 4.2 读取剪贴板

```js
const { text, copy, copied } = useClipboard()

// 读取（需要用户授权或 HTTPS）
const clipboardContent = text.value

// 也可以设置 legacy 模式
const { copy } = useClipboard({ legacy: true })
// legacy 模式用 document.execCommand('copy')，兼容老浏览器
```

### 4.3 一句话对比：手写 vs VueUse

手写剪贴板需要处理：`navigator.clipboard` 支持检测、fallback 到 `execCommand`、权限请求、`copied` 超时重置。VueUse 一个 `useClipboard()` 全搞定。

## 🛠 五、更多常用 API 速查

VueUse 有 200+ composable，这里列出最常用的十几个：

### 5.1 浏览器 API

| API | 用途 | 示例 |
|---|---|---|
| `useTitle` | 页面标题 | `useTitle('我的应用')` |
| `useWindowSize` | 窗口尺寸 | `const { width, height } = useWindowSize()` |
| `useEventListener` | 事件监听（自动清理） | `useEventListener(window, 'resize', handler)` |
| `useMediaQuery` | 媒体查询 | `const isMobile = useMediaQuery('(max-width: 768px)')` |
| `useFavicon` | 网页图标 | `useFavicon('/new-icon.png')` |

### 5.2 状态管理辅助

| API | 用途 | 示例 |
|---|---|---|
| `useStorage` | localStorage / sessionStorage | `const data = useStorage('key', default)` |
| `useStorageAsync` | 异步存储（IndexedDB 等） | 同上但支持异步 |
| `useLocalStorage` | 仅 localStorage 别名 | 同 `useStorage` |
| `useSessionStorage` | 仅 sessionStorage 别名 | 同上 |

### 5.3 工具函数

| API | 用途 | 示例 |
|---|---|---|
| `useDebounceFn` | 防抖函数 | `const debouncedSearch = useDebounceFn(search, 500)` |
| `useThrottleFn` | 节流函数 | `const throttledScroll = useThrottleFn(onScroll, 200)` |
| `useClipboard` | 剪贴板 | `const { copy } = useClipboard()` |
| `useDateFormat` | 日期格式化 | `useDateFormat(date, 'YYYY-MM-DD')` |

### 5.4 UI 交互

| API | 用途 | 示例 |
|---|---|---|
| `useDark` | 暗黑模式 | `const isDark = useDark()` |
| `useToggle` | 布尔切换 | `const toggle = useToggle(false)` |
| `useIntersectionObserver` | 元素可见性 | 懒加载、无限滚动 |
| `useScroll` | 滚动位置 | `const { x, y } = useScroll(el)` |
| `useInfiniteScroll` | 无限滚动 | 自动加载更多 |

## 🛠 六、实战：用 VueUse 重写一个常见功能

把 8.10 节手写的 composable 换成 VueUse：

```vue
<script setup>
import { ref } from 'vue'
import {
  useStorage,          // 替代 useLocalStorage
  useDark,             // 暗黑模式
  useToggle,           // 布尔切换
  useClipboard,        // 剪贴板
  refDebounced,        // 替代 useDebounce
  useMouse,            // 替代手写的 useMouse
  useTitle,            // 页面标题
} from '@vueuse/core'

// 主题（替代手写的 useLocalStorage）
const theme = useStorage('theme', 'light')

// 暗黑模式（之前根本没手写——因为太复杂了）
const isDark = useDark()
const toggleDark = useToggle(isDark)

// 搜索防抖（替代手写的 useDebounce）
const keyword = ref('')
const debouncedKeyword = refDebounced(keyword, 500)

// 鼠标追踪（替代手写的 useMouse）
const { x, y } = useMouse()

// 剪贴板
const { copy, copied } = useClipboard()

// 页面标题
useTitle('我的 Vue 应用')
</script>

<template>
  <div>
    <!-- 主题切换 -->
    <button @click="theme = theme === 'light' ? 'dark' : 'light'">
      主题：{{ theme }}
    </button>

    <!-- 暗黑模式 -->
    <button @click="toggleDark()">
      {{ isDark ? '🌙' : '☀️' }}
    </button>

    <!-- 搜索 -->
    <input v-model="keyword" placeholder="搜索..." />
    <p>防抖后：{{ debouncedKeyword }}</p>

    <!-- 鼠标 -->
    <p>鼠标位置：{{ x }}, {{ y }}</p>
  </div>
</template>
```

几行 import 替代了上百行手写代码，而且这些 VueUse 的 composable 经过了成千上万项目的验证，比你手写的更健壮。

## ⚠️ 七、不要过度使用

VueUse 很好，但也有一些需要注意的地方：

### 7.1 不要用它替代基本 API

```js
// ❌ 杀鸡用牛刀
import { useEventListener } from '@vueuse/core'
useEventListener(window, 'click', () => console.log('click'))

// ✅ 如果逻辑很简单，原生 API 更直接
window.addEventListener('click', () => console.log('click'))
```

VueUse 的价值在于处理了**清理（cleanup）**和**响应式整合**这些你容易忘记的细节。如果只是给 `window` 加个事件、组件卸载时也不需要清理，原生写法完全可以。

### 7.2 了解它做了什么

使用 VueUse 不代表你不用理解原理。面试官可能会问"暗黑模式是怎么实现的"——你需要能说出：监听 `prefers-color-scheme` 媒体查询、操作 `document.documentElement.classList`、持久化到 `localStorage`。

### 7.3 版本兼容性

VueUse 更新活跃，API 偶尔有小调整。团队项目里锁好版本号。

## 🧠 本节小结

- **VueUse 是什么**：官方推荐的开源工具集，基于组合式 API 的 200+ 个 composable/函数，覆盖状态、浏览器、DOM、网络等场景
- **常见成员**：`useMouse`、`useDark`、`useToggle`、`useDebounceFn`、`onClickOutside`、`useLocalStorage`
- **按需引入**：`import { useDark } from '@vueuse/core'` 单函数引入，走 tree-shaking 不撑大包体
- **可组合**：函数之间互相调用（如 useDark + useToggle），和手写 composable 无缝配合
- **替代手写**：先查 VueUse 有没有现成的，再决定是否自己造轮子，减少维护成本
- **版本注意**：VueUse 更新活跃、API 偶尔调整，团队项目锁好版本号
