## 🎯 项目需求（一句话）

做一个"本地笔记"：右侧写笔记、自动保存到浏览器本地，左侧实时按关键词过滤笔记列表，支持新建 / 删除 / 编辑——全程只用第 8 章已学的 composable 思想与手写 `useLocalStorage` / `useDebounce`，不引入任何第三方库、不需要后端。

### ✅ 验收标准（能跑、能展示）

- [ ] 项目能 `npm run dev` 启动，左侧笔记列表 + 右侧编辑区，顶部有搜索框

## 🛠 分步提示（3~5 步，含关键代码锚点）

> 以下只给路线和关键锚点，**不贴全量答案**。卡住时回头翻 8.9 / 8.10 / 8.5 对应小节。

### Step 1：把课堂写过的持久化 composable 拿进项目

新建 `src/composables/useLocalStorage.js`，直接复用你在 8.10 手敲过的实现（`localStorage` 读取初始化 + `watch(..., { deep: true })` 自动回写）。检查点：调用 `const n = useLocalStorage('notes', [])` 后刷新页面数组不丢。

### Step 2：把"笔记业务"抽成 `useNotes`

真正体现 8.9 组合式设计：一个 composable 管一块完整逻辑，内部只依赖上一步的 `useLocalStorage`：

```js

import { useLocalStorage } from './useLocalStorage'

export function useNotes() {
  const notes = useLocalStorage('campus-notes', [])
  const addNote = () => { /* 生成 id + 空笔记，push 进 notes.value */ }
  const removeNote = (id) => { /* 用 filter 生成新数组替换（回顾 5.8 更新姿势） */ }
  const updateNote = (id, patch) => { /* map 出新数组，合并 patch */ }
  return { notes, addNote, removeNote, updateNote }
}
```

> 锚点检查：组件里 `const { notes, addNote, removeNote, updateNote } = useNotes()` 后，模板能直接 `v-for` 出列表——"存"这件事已经被 composable 藏起来了。

### Step 3：搜索过滤——`useDebounce` + `computed`

搜索不该每敲一个字符都过滤（以后接后端就是每敲一个字符发请求）。用 8.10 的 `useDebounce` 包一层：

```js
const keyword = ref('')
const debouncedKeyword = useDebounce(keyword, 300)   // 停笔 300ms 后才更新

const filteredNotes = computed(() => {
  const kw = debouncedKeyword.value.trim()
  if (!kw) return notes.value
  return notes.value.filter(n =>
    n.title.includes(kw) || n.content.includes(kw)
  )
})
```

> 锚点检查：快速连续敲 "vue 教材" 六个字，`debouncedKeyword` 只在停笔后才变成完整词——在输入框下方显示 `keyword` 与 `debouncedKeyword` 两个值即可肉眼验证。

### Step 4：编辑与"自动保存"

编辑区用 `v-model` 绑定当前选中笔记的 `title` / `content`，改动经 `updateNote` 写回 `notes.value`——由于 `useLocalStorage` 内部有 `deep watch`，**保存自动发生**，无需任何手动代码。可选：右上角放一个"最近保存时间"小字，用 `watch` 监听选中笔记内容变化更新时间，让"自动保存"看得见。

### Step 5：界面收尾

左侧列表显示每条的标题与预览（`content.slice(0, 20)` 之类），右侧编辑选中项；"新建"生成新笔记并选中；删除按钮带一个 `confirm` 确认。空列表时给一句引导文案。把搜索框放到顶部，让整页像"极简备忘录"。
