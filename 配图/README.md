## 📄 文件命名规范

**图号 = 章号-章内序号**，与所在章目录编号严格一致（第 4 章的图一定是 `图4-x`，不沿用历史章号）：

| 后缀 | 用途 |
|---|---|
| `图N-X.svg` | **最终交付的图**（Markdown 引用这个）——当前主体，矢量、体积小、可再编辑 |
| `图N-X.png` | 光栅图（当前仅图1-1、图1-2 两张） |
| `图N-X.html` | 该图的 HTML 源文件（用 skill 改图时用这个），统一归档在 `配图/_源文件_html/` |

示例：
- `图4-1.svg` —— 第 4 章第 1 张图
- `图1-1.png` + `_源文件_html/图1-1.html` —— 第 1 章第 1 张图（成品在章目录、源文件在归档目录）

## 🔗 Markdown 引用规范

教材 Markdown 文件引用图时，**用相对路径**，从教材正文位置出发：

```markdown
<!-- 从 教材/04-组件化思想/04.1-xxx/ 引用第 4 章图 -->
![图 4-1：xxx](../../../配图/04-组件化思想/图4-1.svg)
```

**路径层数计算**：从小节目录回到 vue-textbook 根目录，要走几层：
- `教材/01-Vue入门与准备/01.1-xxx/` → 走 3 层回到根 → `../../../`
- 章 README（`教材/01-xxx/README.md`）→ 走 2 层回到根 → `../../`

## 🎨 出图工作流

```bash
# 1. 准备 HTML 源文件（从 templates/ 复制或自己写，源文件放归档目录）
cp ~/.hermes/skills/creative/textbook-diagram/templates/concept.html \
   ~/Desktop/vue-textbook/配图/_源文件_html/图N-X.html

# 2. 填内容（改 HTML 里的标题、节点等）

# 3. 渲染（成品放章目录）
~/.hermes/skills/creative/textbook-diagram/scripts/render.sh \
   ~/Desktop/vue-textbook/配图/_源文件_html/图N-X.html \
   ~/Desktop/vue-textbook/配图/0X-章名/图N-X.svg

# 4. 在 Markdown 里引用
# ![图 N-X：xxx](../../../配图/0X-章名/图N-X.svg)
```

## ⚠️ 注意事项

- ❌ **不要**把图放在节目录里（`01.1-xxx/图1-1.png`）—— 容易乱
- ✅ 成品图（svg/png）放章目录，HTML 源文件放 `配图/_源文件_html/`——**成品与源文件分开存**
- ✅ **必须**用相对路径引用，不用绝对路径
- ✅ **必须**用 `图N-X.svg` 命名（N=章号，X=该章序号；光栅图用 `.png`）
