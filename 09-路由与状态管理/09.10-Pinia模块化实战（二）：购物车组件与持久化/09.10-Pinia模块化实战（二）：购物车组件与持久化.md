## 🛠 一、组件层：产品列表

```vue
<!-- src/components/ProductList.vue -->
<script setup>
import { useCartStore } from '../stores/cart'
import { useProductStore } from '../stores/product'

const productStore = useProductStore()
const cartStore = useCartStore()

function handleAdd(productId) {
  cartStore.addToCart(productId)
  // 可选的反馈
  console.log(`商品 ${productId} 已加入购物车`)
}
</script>

<template>
  <div class="product-list">
    <h2>全部商品</h2>
    <div class="products">
      <div
        v-for="p in productStore.availableProducts"
        :key="p.id"
        class="product-card"
      >
        <span class="product-image">{{ p.image }}</span>
        <h3>{{ p.name }}</h3>
        <p class="price">¥{{ p.price }}</p>
        <p class="stock">库存：{{ p.stock }}</p>
        <button @click="handleAdd(p.id)">加入购物车</button>
      </div>
    </div>
  </div>
</template>
```

> 💬 **老师备注**：ProductList 只负责"展示商品 + 触发加入购物车"。加入购物车的具体逻辑（防重复、加数量）全部封装在 cart store 的 `addToCart` action 里，组件不写业务逻辑。

## 🛠 二、组件层：购物车面板

```vue
<!-- src/components/CartPanel.vue -->
<script setup>
import { useCartStore } from '../stores/cart'

const cart = useCartStore()
</script>

<template>
  <div class="cart-panel">
    <h2>
      购物车
      <span v-if="cart.totalCount" class="badge">
        {{ cart.totalCount }}
      </span>
    </h2>

    <!-- 空状态 -->
    <p v-if="cart.cartDetail.length === 0" class="empty">
      购物车是空的，快去选购吧~
    </p>

    <!-- 商品列表 -->
    <ul v-else>
      <li v-for="item in cart.cartDetail" :key="item.productId">
        <span>{{ item.product?.image }}</span>
        <span class="name">{{ item.product?.name }}</span>
        <span class="price">¥{{ item.product?.price }}</span>

        <!-- 数量调整 -->
        <button @click="cart.updateQuantity(item.productId, item.quantity - 1)">
          −
        </button>
        <span class="quantity">{{ item.quantity }}</span>
        <button @click="cart.updateQuantity(item.productId, item.quantity + 1)">
          +
        </button>

        <!-- 小计 -->
        <span class="subtotal">¥{{ item.subtotal }}</span>

        <button
          class="remove"
          @click="cart.removeFromCart(item.productId)"
        >
          删除
        </button>
      </li>
    </ul>

    <!-- 底部：总价 + 操作 -->
    <div v-if="cart.totalCount > 0" class="cart-footer">
      <p class="total">合计：¥{{ cart.totalPrice }}</p>
      <button class="clear" @click="cart.clearCart()">清空购物车</button>
    </div>
  </div>
</template>
```

> 💬 **老师备注**：CartPanel 直接访问 `cart.cartDetail`、`cart.totalPrice` 这些 getter——它们已经在 store 里算好了，组件只负责渲染。注意 `item.product?.name` 用了可选链，商品信息可能还没关联上，渲染时要做防御。

## 🛠 三、组件层：结算页（跨 store 协作）

```vue
<!-- src/components/Checkout.vue -->
<script setup>
import { useCartStore } from '../stores/cart'
import { useUserStore } from '../stores/user'
import { useProductStore } from '../stores/product'

const cart = useCartStore()
const user = useUserStore()
const product = useProductStore()

function handleCheckout() {
  if (!user.hasAddress) {
    alert('请先填写收货信息')
    return
  }

  if (cart.totalCount === 0) {
    alert('购物车是空的')
    return
  }

  // 减库存
  for (const item of cart.cartDetail) {
    product.reduceStock(item.productId, item.quantity)
  }

  // 模拟下单
  alert(`下单成功！总金额 ¥${cart.totalPrice}，将送至 ${user.address}`)

  // 清空购物车
  cart.clearCart()
}
</script>

<template>
  <div class="checkout">
    <h2>确认订单</h2>

    <div class="section">
      <h3>收货信息</h3>
      <p v-if="user.hasAddress">
        {{ user.name }} / {{ user.phone }} / {{ user.address }}
      </p>
      <p v-else class="empty">请先填写收货信息</p>
    </div>

    <div class="section">
      <h3>订单明细</h3>
      <ul>
        <li v-for="item in cart.cartDetail" :key="item.productId">
          {{ item.product?.name }} × {{ item.quantity }} = ¥{{ item.subtotal }}
        </li>
      </ul>
      <p class="total">合计：¥{{ cart.totalPrice }}</p>
    </div>

    <button
      class="checkout-btn"
      :disabled="!user.hasAddress || cart.totalCount === 0"
      @click="handleCheckout"
    >
      提交订单
    </button>
  </div>
</template>
```

> 💬 **老师备注**：Checkout 是"跨 store 协作"最集中的地方——它同时读了 cart、user、product 三个 store：读 cart 的明细和总价、读 user 的收货信息、调用 product 的 `reduceStock` 减库存。三个 store 各司其职，组件只做编排。

## 🔑 四、购物车持久化：localStorage

购物车数据存在内存里，刷新页面就没了。用 `watch` + `localStorage` 实现持久化（这个逻辑已经写在上一节的 cart store 里了，这里单独拆开讲）：

```js
// 关键代码：cart store 里的持久化
import { ref, watch } from 'vue'

// 初始化时从 localStorage 恢复
const items = ref(loadFromStorage())

function loadFromStorage() {
  try {
    const stored = localStorage.getItem('cart-items')
    return stored ? JSON.parse(stored) : []
  } catch {
    return []
  }
}

// 监听变化，自动写入 localStorage
watch(
  items,
  (newItems) => {
    localStorage.setItem('cart-items', JSON.stringify(newItems))
  },
  { deep: true }
)
```

三个要点：

| 要点 | 说明 |
|---|---|
| **初始化恢复** | `ref(loadFromStorage())` 在创建 store 时就读一次本地数据 |
| **深监听** | `{ deep: true }`——购物车条目里改 `quantity` 也要触发保存 |
| **异常兜底** | `JSON.parse` 失败时返回 `[]`，避免脏数据导致页面崩溃 |

## ⚠️ 五、常见陷阱

### 陷阱 1：computed 里循环调 useStore

```js
// ❌ cartDetail 的 map 里每次都调 useProductStore()
const cartDetail = computed(() => {
  return items.value.map(item => {
    const ps = useProductStore()  // 每条都调一次（虽然没有功能问题，但不够优雅）
    // ...
  })
})

// ✅ 在 computed 开头调一次
const cartDetail = computed(() => {
  const productStore = useProductStore()
  return items.value.map(item => {
    const product = productStore.products.find(p => p.id === item.productId)
    // ...
  })
})
```

### 陷阱 2：localStorage 存储敏感信息

购物车数据存 localStorage 没问题，但不要把用户密码、手机号、token 存进去（不安全）。敏感信息用 `sessionStorage` 或干脆不持久化。

### 陷阱 3：store 之间形成循环依赖

```js
// ❌ cart.js import product.js，product.js 又 import cart.js
// 这会导致初始化时的循环引用问题
```

如果确实需要相互引用，在函数内部惰性调用（比如在 action 里调 `useCartStore()`），而不是在模块顶层 import。

## 🧠 本节小结

- **组件接入 store**：`useCartStore()` 后直接用 state/getters，展示数据用 `storeToRefs` 解构保住响应
- **操作收敛**：改购物车、算总价都写在 store 的 action/getter 里，组件只负责调用和渲染
- **持久化思路**：state 变化时把数据同步进 `localStorage`，应用启动时读回来初始化
- **敏感信息别放 localStorage**：token/密码要放更安全的存储，持久化只适合非敏感偏好和缓存
- **防循环依赖**：store 之间协作保持单向引用（如 cart 读 product），别两个 store 互相 import
