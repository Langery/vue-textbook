## 🤔 一、案例背景

我们要做一个完整的购物车系统，包含三个数据模块：

- **产品（product）**：所有可购买的商品列表
- **购物车（cart）**：用户选中的商品和数量，是本次实战的核心
- **用户（user）**：下单时需要的收货信息

这三个 store 有明确的依赖关系：购物车需要读产品信息（算总价时需要单价），结算时需要读用户信息（收货地址）。

---

## 💡 二、产品 Store

```js
// stores/product.js
import { ref, computed } from 'vue'
import { defineStore } from 'pinia'

export const useProductStore = defineStore('product', () => {
  // ========== State ==========
  const products = ref([
    { id: 1, name: '机械键盘', price: 299, image: '⌨️', stock: 50 },
    { id: 2, name: '无线鼠标', price: 99, image: '🖱️', stock: 120 },
    { id: 3, name: '显示器', price: 1499, image: '🖥️', stock: 30 },
    { id: 4, name: '耳机', price: 199, image: '🎧', stock: 80 },
    { id: 5, name: 'USB 集线器', price: 49, image: '🔌', stock: 200 },
    { id: 6, name: '鼠标垫', price: 29, image: '🟫', stock: 300 },
  ])

  // ========== Getters ==========
  // 根据 ID 查找产品
  const getProductById = computed(() => {
    return (id) => products.value.find(p => p.id === id)
  })

  // 在售产品（库存 > 0）
  const availableProducts = computed(() =>
    products.value.filter(p => p.stock > 0)
  )

  // ========== Actions ==========
  // 减少库存（下单后调用）
  function reduceStock(productId, quantity) {
    const product = products.value.find(p => p.id === productId)
    if (product && product.stock >= quantity) {
      product.stock -= quantity
    }
  }

  return { products, getProductById, availableProducts, reduceStock }
})
```

> 💬 **老师备注**：product store 是纯粹的数据源——它只管"有哪些商品、库存多少"，不关心购物车怎么用这些数据。这符合**职责单一**原则。

## 🔑 三、购物车 Store（核心）

```js
// stores/cart.js
import { ref, computed, watch } from 'vue'
import { defineStore } from 'pinia'
import { useProductStore } from './product'

export const useCartStore = defineStore('cart', () => {
  // ========== State ==========
  // 购物车条目：{ productId, quantity }
  const items = ref(loadFromStorage())

  // ========== 持久化：从 localStorage 恢复 ==========
  function loadFromStorage() {
    try {
      const stored = localStorage.getItem('cart-items')
      return stored ? JSON.parse(stored) : []
    } catch {
      return []
    }
  }

  // 监听变化，自动写入 localStorage
  watch(
    items,
    (newItems) => {
      localStorage.setItem('cart-items', JSON.stringify(newItems))
    },
    { deep: true }
  )

  // ========== Getters ==========
  // 购物车内商品总数量
  const totalCount = computed(() =>
    items.value.reduce((sum, item) => sum + item.quantity, 0)
  )

  // 总价（需要关联产品 store 拿单价）
  const totalPrice = computed(() => {
    const productStore = useProductStore()
    return items.value.reduce((sum, item) => {
      const product = productStore.products.find(p => p.id === item.productId)
      return sum + (product ? product.price * item.quantity : 0)
    }, 0)
  })

  // 完整购物车明细（带产品信息）
  const cartDetail = computed(() => {
    const productStore = useProductStore()
    return items.value.map(item => {
      const product = productStore.products.find(p => p.id === item.productId)
      return {
        ...item,
        product,
        subtotal: product ? product.price * item.quantity : 0
      }
    })
  })

  // ========== Actions ==========
  function addToCart(productId, quantity = 1) {
    const existing = items.value.find(i => i.productId === productId)
    if (existing) {
      // 已存在：加数量
      existing.quantity += quantity
    } else {
      // 新商品：加入
      items.value.push({ productId, quantity })
    }
  }

  function removeFromCart(productId) {
    const index = items.value.findIndex(i => i.productId === productId)
    if (index !== -1) {
      items.value.splice(index, 1)
    }
  }

  function updateQuantity(productId, quantity) {
    const item = items.value.find(i => i.productId === productId)
    if (item) {
      if (quantity <= 0) {
        // 数量为 0 或负数 → 移除
        removeFromCart(productId)
      } else {
        item.quantity = quantity
      }
    }
  }

  function clearCart() {
    items.value = []
  }

  return {
    items,
    totalCount,
    totalPrice,
    cartDetail,
    addToCart,
    removeFromCart,
    updateQuantity,
    clearCart,
  }
})
```

> 💬 **老师备注**：注意 `totalPrice` 里调了 `useProductStore()`。在 Pinia 中，computed 和 action 里可以随时调用其他 store 的函数来获取数据——这是跨 store 协作最自然的方式。注意不要在 `totalPrice` 里用 `storeToRefs` 解构 `products`，在 computed 里直接访问 `productStore.products` 即可，Vue 会自动追踪依赖。

## 🛠 四、用户 Store

```js
// stores/user.js
import { ref, computed } from 'vue'
import { defineStore } from 'pinia'

export const useUserStore = defineStore('user', () => {
  const name = ref('')
  const address = ref('')
  const phone = ref('')

  // 是否已填写收货信息
  const hasAddress = computed(() =>
    name.value && address.value && phone.value
  )

  function setUserInfo({ name: n, address: a, phone: p }) {
    name.value = n
    address.value = a
    phone.value = p
  }

  // 重置
  function $reset() {
    name.value = ''
    address.value = ''
    phone.value = ''
  }

  return { name, address, phone, hasAddress, setUserInfo, $reset }
})
```

> 💬 **老师备注**：user store 只有三块数据和一个判断——它不依赖 product 和 cart，是三个 store 中最独立的。等到结算时，cart 才需要读 user 的收货地址。

## ⚠️ 五、跨 Store 协作的要点

回顾三个 store 的设计，跨 store 协作的关键做法：

| 要点 | 说明 |
|---|---|
| **在 getter/action 里调其他 store** | `const productStore = useProductStore()` 直接用，Pinia 自动处理 |
| **数据单向** | cart 读 product，但 cart 不改 product（只有下单时通过 `reduceStock` action 修改） |
| **每个 store 职责单一** | product 负责数据源，cart 负责选购逻辑，user 负责收货信息 |
| **不在组件里做跨 store 逻辑** | 比如算总价——在 cart 的 getter 里算好，组件直接 `cart.totalPrice`，不自己算 |

> 💬 **老师备注**：这个购物车系统已经接近真实项目的架构。你可以在它的基础上加上优惠券（coupon store）、地址管理（address store）、订单历史（order store）等模块——每个模块一个 store 文件，清晰独立。下一节我们会把组件层和持久化补完。

## 🧠 本节小结

- **模块化拆法**：按业务域拆 store（user/cart/product…），每个 store 职责单一、独立成文件
- **在 store 内部协作**：getter/action 里直接 `useXxxStore()` 拿另一个 store 用，Pinia 自动处理依赖
- **保持数据单向**：cart 读 product 可以，但别绕过 action 乱改别人的数据；下单才走 `reduceStock`
- **组件只管调用**：跨 store 算总价这类逻辑放 cart 的 getter，组件只写 `cart.totalPrice`
- **扩展性好**：优惠券、地址、订单历史都能按同一模式加 store，不互相纠缠
