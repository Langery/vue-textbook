## 📊 参考答案

### 选择题

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | **A** | 前后端分离的核心就是前端管 UI、后端管数据。B 错在语言可以不同；C 错在分离恰恰依赖 HTTP；D 是后端的事 |
| 2 | **C** | `response.data` 是后端返回的数据体。A 是 `response.status`；B 是 `response.headers`；D 是 `response.config` |
| 3 | **C** | 404 就是"Not Found"。200 是成功；301 是重定向；500 是服务器内部错误 |
| 4 | **B** | 响应拦截器在组件拿到数据**之前**执行。它先于组件的 `await` 或 `.then()` 拿到响应 |
| 5 | **B** | `AbortController` 主要是防止内存泄漏。快速切换页面时取消旧请求，避免更新已销毁的组件 |

### 判断题

| 题号 | 答案 | 解析 |
|---|---|---|
| 6 | ✅ **正确** | Axios 默认自动将 JavaScript 对象序列化为 JSON，并设置 `Content-Type: application/json` |
| 7 | ❌ **错误** | 401 是"未认证"（Unauthorized），表示 token 过期或未登录。500 才是"服务器内部错误" |
| 8 | ❌ **错误** | 请求拦截器必须 `return config`，否则请求会被拦截器"吞掉"，发不出去 |
| 9 | ✅ **正确** | 4xx 是客户端错误，参数有问题或权限不够，重试多少次都没用，应该让用户纠正后再试 |
| 10 | ❌ **错误** | Vue 官方推荐但并非强制。不以 `use` 开头也能正常运行，但建议遵循规范 |

### 编码题参考代码

#### 题目 1 参考

```js
import axios from 'axios'

const request = axios.create({
  baseURL: 'https://jsonplaceholder.typicode.com',
  timeout: 8000
})

request.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

request.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response) {
      if (error.response.status === 401) {
        localStorage.removeItem('token')
        window.location.href = '/login'
      } else if (error.response.status >= 500) {
        alert('服务器繁忙')
      }
    }
    return Promise.reject(error)
  }
)

export default request
```

#### 题目 2 参考

```js
import { ref, onUnmounted } from 'vue'

export function useRequest(fetchFn) {
  const data = ref(null)
  const loading = ref(false)
  const error = ref('')
  let controller = null

  const execute = async (...args) => {
    if (controller) controller.abort()
    controller = new AbortController()

    loading.value = true
    error.value = ''

    try {
      const result = await fetchFn(...args, controller.signal)
      data.value = result
      return result
    } catch (err) {
      if (err.name === 'CanceledError' || err.code === 'ERR_CANCELED') return
      error.value = err.message || '请求失败'
      throw err
    } finally {
      loading.value = false
    }
  }

  onUnmounted(() => controller?.abort())

  return { data, loading, error, execute }
}
```

#### 题目 3 参考

```
<script setup>
import { onMounted } from 'vue'
import request from '@/utils/request'
import { useRequest } from '@/composables/useRequest'

// 带重试的请求包装
async function fetchWithRetry(signal) {
  const maxRetries = 3
  let lastError

  for (let i = 0; i <= maxRetries; i++) {
    try {
      return await request.get('/posts', { signal })
    } catch (err) {
      // 被取消不重试
      if (err.name === 'CanceledError') throw err
      // 4xx 不重试
      if (err.response && err.response.status >= 400 && err.response.status < 500) throw err
      // 最后一次不重试
      if (i === maxRetries) throw err

      lastError = err
      // 指数退避
      await new Promise((r) => setTimeout(r, 1000 * Math.pow(2, i)))
    }
  }
}

const { data: posts, loading, error, execute } = useRequest(
  (signal) => fetchWithRetry(signal)
)

onMounted(() => execute())
</script>

<template>
  <h1>文章列表</h1>

  <p v-if="loading">加载中...</p>
  <p v-else-if="error" style="color: red;">{{ error }}</p>
  <p v-else-if="posts && posts.length === 0">暂无文章</p>
  <ul v-else-if="posts">
    <li v-for="post in posts" :key="post.id">{{ post.title }}</li>
  </ul>
</template>
```
