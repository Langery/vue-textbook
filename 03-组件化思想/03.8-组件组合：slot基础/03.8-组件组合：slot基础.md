你会用 Props 往子组件传数据了，可需求变成：写一个通用"卡片"组件，标题栏每个页面长得都不一样——有的放按钮、有的放搜索框、有的放自定义 HTML。Props 传字符串？结构和按钮根本传不进去。这时你需要让父组件往子组件内部塞内容的机制，Vue 的答案叫插槽（slot），它最灵活，也最容易被新手和 Props 搞混。

## 🤔 一、slot 是什么？

上一节我们讲了**开闭原则**——组件通过 Props 暴露"可变数据"。

但有一种情况 Props 搞不定：**"组件内部的某一块 HTML 结构，每个使用场景都不一样"**。

### 场景：一个弹窗组件

假设你要做一个弹窗组件 `Modal`：

```vue
<!-- 理想中的 Modal -->
<Modal>
  这里是弹窗的内容 —— 有时候是表单，有时候是文字，有时候是图片
</Modal>
```

**问题**：弹窗的"框架"是固定的（遮罩层、关闭按钮、居中容器），但**里面的内容**每次都不一样——有时候要放一个登录表单，有时候要放一段提示文字，有时候要放一张大图。

**如果用 Props**：

```
<Modal :content="'这是提示文字'" />
<Modal :content="'<form>...很长的表单 HTML...</form>'" />
```

用字符串传 HTML——麻烦、不安全、代码提示也丢了。**这就是 slot 的用武之地**。

> 💬 **老师备注**：你可以把 slot 理解为组件身上预留的 **"插槽"**——就像主机箱后面的 USB 口，你可以插鼠标、插键盘、插 U 盘，只要接口匹配就行。组件不用管"插进来的是什么"，只管提供插槽。

## 💡 二、默认 slot：最基本的用法

在子组件里放一个 `<slot />`，父组件里写在子组件标签中间的内容，就会自动塞进去。

```
<!-- 子组件：MyCard.vue -->
<template>
  <div class="card">
    <div class="card-header">卡片标题（固定部分）</div>
    <div class="card-body">
      <!-- 🎯 slot：这里是"可变部分" -->
      <slot />
    </div>
  </div>
</template>
```

```vue
<!-- 父组件 -->
<template>
  <!-- 标签中间的内容会自动塞进子组件的 <slot /> 位置 -->
  <MyCard>
    <p>这张卡的内容是动态的！</p>
    <button>点我</button>
  </MyCard>

  <MyCard>
    <img src="photo.jpg" alt="照片" />
    <span>另一张卡，完全不同的内容</span>
  </MyCard>
</template>
```

### slot 的默认内容（后备内容）

如果父组件没传内容，slot 可以显示默认内容：

```vue
<template>
  <div class="card">
    <slot>
      <!-- 父组件没传内容时，显示这个 -->
      <p class="placeholder">暂无内容</p>
    </slot>
  </div>
</template>
```

## 💡 三、具名 slot：多个插槽各司其职

默认 slot 只能有一个。如果组件需要**多个可变区域**（比如弹窗的标题、主体、底部按钮），就需要**具名 slot**。

### 定义一个多插槽布局组件

```
<!-- Layout.vue —— 页面布局组件 -->
<template>
  <div class="layout">
    <header class="layout-header">
      <slot name="header">
        <!-- 默认头部 -->
        <h1>默认标题</h1>
      </slot>
    </header>

    <aside class="layout-sidebar">
      <slot name="sidebar">
        <!-- 默认侧边栏 -->
        <nav>侧边导航</nav>
      </slot>
    </aside>

    <main class="layout-main">
      <!-- 默认 slot：不写 name 就是默认 slot -->
      <slot />
    </main>

    <footer class="layout-footer">
      <slot name="footer">
        <p>© 2026 版权所有</p>
      </slot>
    </footer>
  </div>
</template>

<style scoped>
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}
.layout-header  { grid-area: header;  padding: 16px; background: #42b883; color: #fff; }
.layout-sidebar { grid-area: sidebar; padding: 16px; background: #f7fafc; border-right: 1px solid #e2e8f0; }
.layout-main    { grid-area: main;    padding: 24px; }
.layout-footer  { grid-area: footer;  padding: 12px; background: #edf2f7; text-align: center; }
</style>
```

### 父组件使用具名 slot

```
<template>
  <Layout>
    <!-- 用 v-slot:name 或 #name 指定插哪个槽 -->
    <template #header>
      <h1>Vue 3 学习平台</h1>
      <nav>首页 | 课程 | 关于</nav>
    </template>

    <template #sidebar>
      <ul>
        <li>第 1 章：入门</li>
        <li>第 2 章：模板语法</li>
        <li>第 3 章：组件化思想</li>
      </ul>
    </template>

    <!-- 默认 slot 的内容（不写 template 也行，直接放） -->
    <div class="main-content">
      <h2>欢迎学习 Vue 3</h2>
      <p>这是主内容区。</p>
    </div>

    <template #footer>
      <p>Made with Vue 3 + ❤️</p>
    </template>
  </Layout>
</template>
```

> 💬 **老师备注**：`v-slot:header` 可以简写为 `#header`。跟 `v-bind:` 简写为 `:`、`v-on:` 简写为 `@` 一样，Vue 喜欢让常用语法尽量短。

**具名 slot 速查表**：

| 写法 | 含义 |
|---|---|
| `<slot />` | 默认 slot（不写 name） |
| `<slot name="header" />` | 具名 slot（name="header"） |
| `<template #header>` | 父组件使用具名 slot |
| `<template #default>` | 父组件显式使用默认 slot（可省略） |

## ⚠️ 四、常见陷阱

### 陷阱 1：具名 slot 不写 `<template>` 标签

```vue
<!-- ❌ 这样写会报错或不起作用 -->
<Layout>
  <div #header>标题</div>  <!-- #header 只能写在 <template> 上 -->
</Layout>

<!-- ✅ 正确 -->
<Layout>
  <template #header>
    <div>标题</div>
  </template>
</Layout>
```

### 陷阱 2：`v-slot` 和默认 slot 内容混用导致歧义

当一个组件既有默认 slot 又有具名 slot，且你写了 `v-slot` 在组件标签上时，**其他内容必须用 `<template>` 包裹**。

## 🧠 本节小结

- **slot 是什么**：父组件往子组件"留的洞"里塞内容；Props 传"值"，slot 传"长相"（HTML/组件）
- **默认 slot**：一个组件没有具名插槽时，写进组件标签之间的内容全部进默认插槽
- **后备内容**：`<slot>默认文案</slot>` 让没传内容的调用方也有兜底展示
- **具名 slot**：一个布局要开多个口，用 `name="xxx"` + 父组件 `<template #xxx>` 一一对应
- **两个坑**：具名 slot 必须写在 `<template>` 上；`v-slot` 别和默认内容混用制造歧义
