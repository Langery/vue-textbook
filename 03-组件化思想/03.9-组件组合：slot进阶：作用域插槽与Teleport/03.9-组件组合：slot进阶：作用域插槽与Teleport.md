## 💡 一、作用域 slot：子组件把数据"回传"给父组件

**场景**：你有一个列表组件 `<FancyList>`，它负责渲染列表的**框架**（边框、滚动、加载状态），但**每一项的渲染**希望由父组件来决定。

问题：每一项的数据（`item`）在子组件里，父组件怎么拿到它？

**答案**：作用域 slot（scoped slot）——子组件通过 slot 把数据"抛"给父组件。

### 子组件：把数据绑在 slot 上

```vue
<!-- FancyList.vue -->
<script setup>
defineProps({
  items: { type: Array, required: true }
})
</script>

<template>
  <ul class="fancy-list">
    <!--
      把 item 绑在 slot 上
      父组件可以通过 v-slot="slotProps" 拿到它
    -->
    <li v-for="item in items" :key="item.id">
      <slot name="item" :item="item" :index="index">
        <!-- 默认渲染：只显示 item.name -->
        {{ item.name }}
      </slot>
    </li>
  </ul>
</template>
```

### 父组件：接收数据并自定义渲染

```vue
<script setup>
const students = [
  { id: 1, name: '张三', score: 92, avatar: '...' },
  { id: 2, name: '李四', score: 78, avatar: '...' },
  { id: 3, name: '王五', score: 85, avatar: '...' }
]
</script>

<template>
  <FancyList :items="students">
    <!--
      用 v-slot:item="slotProps" 接收子组件传来的数据
      slotProps 是一个对象：{ item, index }
      可以解构：v-slot:item="{ item, index }"
    -->
    <template #item="{ item, index }">
      <div class="student-item">
        <span class="rank">#{{ index + 1 }}</span>
        <img :src="item.avatar" :alt="item.name" class="avatar" />
        <span class="name">{{ item.name }}</span>
        <span class="score" :class="{ excellent: item.score >= 90 }">
          {{ item.score }}分
        </span>
        <span v-if="item.score >= 90" class="medal">🏅</span>
      </div>
    </template>
  </FancyList>
</template>
```

> 💬 **老师备注**：作用域 slot 是 slot 体系里**最强大**的一种。它让你在保持"框架由子组件控制"的同时，把"内容渲染的自由"交给父组件。很多 UI 库（Element Plus、Ant Design Vue）大量使用作用域 slot 来做表格列自定义、下拉选项自定义等。

## 🛠 二、完整可运行示例：通用 Modal 弹窗组件

这是一个**真正可复用**的弹窗组件，用了默认 slot + 具名 slot + Props 组合：

```
<!-- AppModal.vue -->
<script setup>
defineProps({
  visible: { type: Boolean, default: false },
  title: { type: String, default: '提示' },
  width: { type: String, default: '500px' },
  closeOnOverlay: { type: Boolean, default: true }
})

const emit = defineEmits(['close'])

function handleOverlayClick() {
  emit('close')
}
</script>

<template>
  <!-- 遮罩层 -->
  <div
    v-if="visible"
    class="modal-overlay"
    @click.self="closeOnOverlay && handleOverlayClick()"
  >
    <!-- 弹窗主体 -->
    <div class="modal-container" :style="{ maxWidth: width }">
      <!-- 头部（具名 slot） -->
      <div class="modal-header">
        <slot name="header">
          <h3>{{ title }}</h3>
        </slot>
        <button class="modal-close" @click="emit('close')">✕</button>
      </div>

      <!-- 主体（默认 slot） -->
      <div class="modal-body">
        <slot />
      </div>

      <!-- 底部（具名 slot） -->
      <div class="modal-footer">
        <slot name="footer">
          <button class="btn btn-cancel" @click="emit('close')">取消</button>
          <button class="btn btn-confirm" @click="emit('close')">确定</button>
        </slot>
      </div>
    </div>
  </div>
</template>

<style scoped>
```

**使用示例**：

```
<script setup>
import { ref } from 'vue'
import AppModal from './AppModal.vue'

const showModal = ref(false)
const showFormModal = ref(false)
const username = ref('')
</script>

<template>
  <button @click="showModal = true">打开提示弹窗</button>

  <!-- 示例 1：简单文字弹窗（只用默认 slot） -->
  <AppModal
    :visible="showModal"
    title="操作提示"
    @close="showModal = false"
  >
    <p>确定要删除这条记录吗？此操作不可撤销。</p>
  </AppModal>

  <button @click="showFormModal = true">打开表单弹窗</button>

  <!-- 示例 2：表单弹窗（自定义 header + 默认 + footer） -->
  <AppModal
    :visible="showFormModal"
    :width="'420px'"
    @close="showFormModal = false"
  >
    <!-- 自定义头部 -->
    <template #header>
      <h3>📝 添加用户</h3>
    </template>

    <!-- 默认 slot：表单内容 -->
    <form @submit.prevent="showFormModal = false">
      <label>
        用户名：
        <input v-model="username" placeholder="请输入用户名" />
      </label>
    </form>

    <!-- 自定义底部按钮 -->
    <template #footer>
      <button class="btn btn-cancel" @click="showFormModal = false">取消</button>
      <button class="btn btn-confirm" @click="showFormModal = false">保存</button>
    </template>
  </AppModal>
</template>
```

> 💬 **老师备注**：这个 AppModal 可以在整个项目里反复用——提示弹窗、表单弹窗、图片预览弹窗，**框架一样，内容不同**。这就是 slot + Props 组合拳的威力。

## ⚠️ 三、常见陷阱

### 陷阱 1：忘记 slot 的编译作用域

**父模板里的变量，在父作用域编译；子模板里的变量，在子作用域编译。**

```vue
<!-- 子组件 -->
<template>
  <div>
    <slot />
  </div>
</template>
<script setup>
const childMsg = '我是子组件的数据'
</script>

<!-- 父组件 -->
<template>
  <Child>
    <!-- ❌ 拿不到 childMsg！因为这段在父作用域编译 -->
    {{ childMsg }}
  </Child>
</template>
```

**如果需要访问子组件数据，请用作用域 slot**。

## 🚀 四、进阶：Teleport —— 把 slot 内容送到 DOM 任意位置

上面我们写的 Modal 组件用 `position: fixed` + `z-index: 1000` 来实现弹窗。这在大多数情况下没问题，但有一种场景会翻车：

**弹窗所在的父组件设置了 `overflow: hidden` 或 `transform`**——这时 `position: fixed` 会**失效**，弹窗被父容器"关住"，无法覆盖整个页面。弹窗、下拉菜单、Tooltip 等**需要"跳出"组件层级限制**的 UI，都会遇到这个问题。

**Teleport 就是解决这个问题的内置组件**：

```
<!-- AppModal.vue —— 用 Teleport 改造 -->
<template>
  <!-- Teleport 把内部内容"传送"到 <body> 末尾 -->
  <Teleport to="body">
    <div
      v-if="visible"
      class="modal-overlay"
      @click.self="closeOnOverlay && handleOverlayClick()"
    >
      <div class="modal-container" :style="{ maxWidth: width }">
        <div class="modal-header">
          <slot name="header">
            <h3>{{ title }}</h3>
          </slot>
          <button class="modal-close" @click="emit('close')">✕</button>
        </div>
        <div class="modal-body">
          <slot />
        </div>
        <div class="modal-footer">
          <slot name="footer">
            <button class="btn btn-cancel" @click="emit('close')">取消</button>
            <button class="btn btn-confirm" @click="emit('close')">确定</button>
          </slot>
        </div>
      </div>
    </div>
  </Teleport>
</template>
```

**Teleport 做了什么**：

- `<Teleport to="body">` 告诉 Vue："把我里面的 DOM 渲染到 `<body>` 下面，不要放在当前组件的位置"
- 弹窗的 DOM 节点在 `<body>` 末尾——**不受任何父组件的 CSS 限制**
- 但**逻辑（Props、事件、slot）仍然属于当前组件**——Teleport 只改变 DOM 位置，不改变组件关系

```text
<!-- 没有 Teleport 时 -->
<div id="app">
  <SomeContainer style="overflow: hidden">
    <div class="modal-overlay">  ← 被父容器"关住"了！
      ...
    </div>
  </SomeContainer>
</div>

<!-- 用了 Teleport 后 -->
<div id="app">
  <SomeContainer style="overflow: hidden">
    <!-- Teleport 的"逻辑位置"还在这里（响应式、事件都正常） -->
  </SomeContainer>
</div>
<body>
  <div class="modal-overlay">  ← DOM 被"传送"到 body 下，完全不受限制！
    ...
  </div>
</body>
```

> 💬 **老师备注**：Teleport 是 Vue 3 的内置组件，和 `<KeepAlive>` 一样不需要 import。它的 `to` 属性接受 CSS 选择器——`"body"`、`"#app"`、`".some-class"` 都行。在实际项目中，弹窗和下拉菜单几乎**必须**用 Teleport，否则迟早遇到样式问题。本节已经系统讲解了它的用法，现在你先记住"弹窗 = Teleport"这个口诀就行。

## 🧠 本节小结

- **作用域 slot 解决"数据回传"**：子组件把数据绑到 `<slot :user="user">` 上，父组件用 `#default="{ user }"` 接住自定义渲染
- **典型应用**：通用表格/列表组件——数据与遍历在子组件，每行怎么画由父组件说了算
- **编译作用域提醒**：父组件模板里只能访问父组件的数据，插槽内容想要子组件数据必须走"作用域插槽"通道
- **Teleport 解决"越级渲染"**：`<Teleport to="body">` 把弹窗等组件送到指定 DOM 位置，摆脱父容器 `overflow/z-index` 的压制
- **口诀**：弹窗 = Teleport；要"自定义每块内容的渲染" = 作用域插槽
