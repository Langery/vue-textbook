# 第 3 章 组件化思想 ⭐

> 课时：8 课时（重点章）
> 难度：⭐⭐（进阶）
> 重要性：⭐⭐⭐⭐⭐（**上篇最核心**）

---

## 🎯 本章目标

学完这章，你将能够：

- ✅ **理解**：组件的本质——"UI = 数据 + 模板"
- ✅ **理解**：组件设计的三大原则（单一职责、可复用、可组合）
- ✅ **掌握**：组件组合模式（slot 默认插槽、具名插槽、作用域插槽）
- ✅ **掌握**：受控 vs 非受控组件的区别和使用场景
- ✅ **掌握**：组件文件的组织方式（一个文件一个组件 / Barrel export）
- ✅ **理解**：组件树的层次结构，能拆解中型页面的组件结构
- ✅ **了解**：选项式 API vs 组合式 API 的区别和选择

---

## 🤔 为什么本章是上篇最核心

**前面学的（1-2 章）都是"基础语法"**——能写，但写出来的是"一团代码"。

**学完本章，你会"组件化思考"**——把任何 UI 都拆成可复用的小积木。这是**从"会写 Vue"到"会用 Vue 写工程"的分水岭**。

> 🧑 **小白**：为什么非要把页面拆成组件？一个文件从头写到尾，不是更省事吗？

> 🤖 **Vue 君**：等你一个文件写到 5000 行，改一个按钮要翻三个地方一起动的时候，就会回来找我拆组件了……

> 👨🏫 **老湿**：组件化就是"把大问题拆成小积木"。这章是全书的分水岭，学完你才算真正"会写 Vue"。

> 💬 **老师备注**：本章是上篇**最关键的一章**。如果你只学一章，必须是这一章。8 课时的安排不是随便给的——组件化思维需要大量练习。

## 🛠 本章实战

学完本章，你应该能：

1. **独立设计**一个"商品列表页"的组件树（不超过 6 个组件）
2. **用 slot** 写一个通用"卡片"组件，支持自定义标题/内容/操作区
3. **用 `<component :is>`** 写一个 Tab 切换组件
4. **判断**某个表单应该用受控还是非受控
5. **组织**一个中等项目的 components/ 目录
