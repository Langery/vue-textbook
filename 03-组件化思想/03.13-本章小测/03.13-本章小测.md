### 实操题 1：Tab 页签组件（25 分）

**要求**：

1. **Props**：接收 `tabs` 数组，每项包含 `{ id, label }`
2. **默认 slot**：显示当前选中 Tab 的内容
3. **事件**：切换 Tab 时 emit `change` 事件，传出选中 Tab 的 `id`
4. **使用 `<KeepAlive>`** 缓存切换后的内容（状态不丢失）
5. 写出 **子组件代码**（TabContainer.vue）和 **父组件使用示例**

### 选择题答案

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | **B** | `.vue` 文件可以包含 template、script、style 三部分 |
| 2 | **C** | 单一职责原则：一个组件只做一件事 |
| 3 | **B** | 弹窗的标题和底部每次不同 → 适合用 slot 传"结构"而非"值" |
| 4 | **C** | KeepAlive 可以缓存动态组件，保留状态 |
| 5 | **B** | 受控：父组件管控数据；非受控：子组件自管 |
| 6 | **A** | `子组件 <slot :data="item" />` → 父组件 `<template #default="slotProps">{{ slotProps.data }}</template>` |
| 7 | **C** | v-model 可以在任何组件上使用，不限于 `<input>` |
| 8 | **C** | 没有固定标准，先写再拆，按三问判断 |
| 9 | **B** | Props 向下，事件向上 —— 这是 Vue 的核心约束 |
| 10 | **B** | `<script setup>` 是组合式 API 的语法糖 |

### 实操题评分要点

**实操题 1 参考思路**：

```vue
<!-- TabContainer.vue -->
<script setup>
import { KeepAlive } from 'vue'

defineProps({
  tabs: { type: Array, required: true },
  modelValue: [String, Number]
})

const emit = defineEmits(['update:modelValue', 'change'])

function selectTab(id) {
  emit('update:modelValue', id)
  emit('change', id)
}
</script>

<template>
  <div class="tab-container">
    <nav class="tab-nav">
      <button
        v-for="tab in tabs"
        :key="tab.id"
        :class="{ active: modelValue === tab.id }"
        @click="selectTab(tab.id)"
      >
        {{ tab.label }}
      </button>
    </nav>
    <KeepAlive>
      <slot />
    </KeepAlive>
  </div>
</template>
```

**实操题 2 参考思路**：

- `defineProps({ visible: Boolean, title: String })` + `defineEmits(['update:visible', 'confirm', 'cancel'])`
- `@click.self` 实现遮罩关闭
- `onMounted(() => window.addEventListener('keydown', handleEsc))` + `onUnmounted` 清理
- 三个具名 slot：`#header`、默认、`#footer`
