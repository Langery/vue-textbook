## 🤔 一、什么是动态组件？

先看一个场景：你做了一个后台管理页面，左侧是菜单（"用户管理"、"订单管理"、"数据统计"），点击菜单项，右边切换显示对应的内容。

**如果不了解动态组件，你可能会这样写**：

```
<template>
  <div>
    <!-- ❌ 写一堆 v-if，菜单越多越乱 -->
    <UserManage v-if="currentTab === 'user'" />
    <OrderManage v-if="currentTab === 'order'" />
    <DataStats  v-if="currentTab === 'stats'" />
    <Settings   v-if="currentTab === 'settings'" />
    <LogViewer  v-if="currentTab === 'log'" />
    <!-- 10 个菜单就得写 10 个 v-if... -->
  </div>
</template>
```

<img src="../00-公共资源/图/03-组件化思想/图3-5.svg" alt="动态组件的比喻 —— 遥控器切换信号源">

**动态组件的解决方案**：

```vue
<script setup>
import { ref } from 'vue'
import UserManage from './UserManage.vue'
import OrderManage from './OrderManage.vue'
import DataStats from './DataStats.vue'
import Settings from './Settings.vue'
import LogViewer from './LogViewer.vue'

const currentTab = ref('user')
</script>

<template>
  <div>
    <!-- ✅ 一行搞定，currentTab 是哪个就显示哪个 -->
    <component :is="currentTab" />
  </div>
</template>
```

**这就是动态组件的魔力**——**一行代码替代 N 个 v-if**。

> 💬 **老师备注**：`<component :is="..." />` 就像一个"组件插座"——你告诉它要插哪个组件，它就显示哪个。`:is` 的值变了，插的组件也跟着变。

## 💡 二、`<component :is>` 的三种用法

### 用法 1：`:is` 绑定组件名（字符串）

```vue
<script setup>
import { ref } from 'vue'
import HomeTab from './HomeTab.vue'
import AboutTab from './AboutTab.vue'

// 用一个对象做映射表
const tabs = {
  home: HomeTab,
  about: AboutTab
}

const activeTab = ref('home')
</script>

<template>
  <select v-model="activeTab">
    <option value="home">首页</option>
    <option value="about">关于</option>
  </select>

  <!-- 直接传组件对象 -->
  <component :is="tabs[activeTab]" />
</template>
```

### 用法 2：`:is` 绑定组件对象（import 进来的）

```
<script setup>
import { ref, markRaw } from 'vue'
import TabA from './TabA.vue'
import TabB from './TabB.vue'
import TabC from './TabC.vue'

// 对象映射（推荐用 markRaw 避免不必要的响应式转换）
const tabComponents = {
  a: markRaw(TabA),
  b: markRaw(TabB),
  c: markRaw(TabC)
}

const current = ref('a')
</script>

<template>
  <button v-for="(comp, key) in tabComponents" :key="key" @click="current = key">
    {{ key }}
  </button>
  <component :is="tabComponents[current]" />
</template>
```

> 💬 **老师备注**：用 `markRaw()` 包一下组件对象是个好习惯——组件对象本身不需要响应式，markRaw 告诉 Vue "别追踪它"，可以省点性能。

### 用法 3：在对象数组里带组件

```
<script setup>
import { ref, markRaw } from 'vue'
import ProfileTab from './ProfileTab.vue'
import PostsTab from './PostsTab.vue'
import SettingsTab from './SettingsTab.vue'

const tabs = ref([
  { id: 1, label: '个人资料', component: markRaw(ProfileTab) },
  { id: 2, label: '我的帖子', component: markRaw(PostsTab) },
  { id: 3, label: '账号设置', component: markRaw(SettingsTab) }
])

const activeId = ref(1)
const activeComponent = computed(() => {
  return tabs.value.find(t => t.id === activeId.value)?.component
})
</script>

<template>
  <nav>
    <button
      v-for="tab in tabs"
      :key="tab.id"
      @click="activeId = tab.id"
      :class="{ active: activeId === tab.id }"
    >
      {{ tab.label }}
    </button>
  </nav>
  <component :is="activeComponent" />
</template>
```

### 用法小结

| 用法 | `:is` 的值 | 适用场景 |
|---|---|---|
| 用法 1 | 组件名字符串 | 选项式 API、模板里注册过的组件 |
| 用法 2 | 组件对象（推荐） | 组合式 API，import 进来直接用 |
| 用法 3 | 对象数组里的 `component` 字段 | Tab 列表、可配置菜单 |

## ⚠️ 三、常见陷阱

### 陷阱 1：`:is` 绑的名字和组件没对上

```vue
<script setup>
import UserManage from './UserManage.vue'
const current = ref('UserManage')
</script>

<template>
  <!-- ❌ 字符串 "UserManage" 不等于组件对象 UserManage -->
  <component :is="current" />
</template>
```

**`字符串`必须跟 `components` 注册的名字一致**（使用选项式 API 时）。组合式 API 推荐直接传组件对象。

### 陷阱 2：忘记 `computed` 的 import

在用法 3 里用到了 `computed`，记得从 `vue` 里引入：

```
<script setup>
import { ref, computed, markRaw } from 'vue'
```

## 🧠 本节小结

- **动态组件 = 组件当变量用**：`<component :is="xxx" />` 里的 `xxx` 是组件名或组件对象，Vue 帮你渲染对应的组件
- **三种用法**：`:is` 绑字符串名字、绑 import 进来的组件对象、绑对象数组做数据驱动切换
- **适用场景**：Tab 页签、多步骤表单、后端配置驱动的页面——组件一多别再写一长串 `v-if`
- **踩坑点**：`:is` 绑的名字要和注册/导入的名字一致；别忘 import `computed`
- **代价提醒**：切换会销毁旧组件，状态不保留——这正是下一节 `<KeepAlive>` 要解决的
