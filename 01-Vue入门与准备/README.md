# 第 1 章 Vue 入门与准备

> 课时：4 课时（4 节 × 45 分钟）
> 难度：⭐（入门）
> 重要性：🔧 基础（不学不能学后面）

---

## 🎯 本章目标

学完这章，你将能够：

- ✅ 说出 Vue 是什么、它解决什么问题
- ✅ 在自己电脑上**装好开发环境**（Node.js + Vite + VS Code）
- ✅ 用 `npm create vue@latest` 创建项目
- ✅ 认识 Vue 项目的**目录结构**（每个文件夹是干什么的）
- ✅ 写出**第一个 Vue 组件**并跑起来

---

## 🤔 为什么学这章

Vue 是个 JavaScript 框架——**你写 Vue 代码之前，得先有个能跑代码的环境**。

这章不讲"怎么写代码"（那是第 2 章以后的事），而是**把工具准备好**。学完这章，你的电脑就是一个"Vue 工厂"——以后写任何 Vue 项目，都从这里开始。

> 🧑 **小白**：我要学 Vue，怎么第一章不是写代码，而是装 Node.js、Vite？这也太不"酷"了吧？

> 🤖 **Vue 君**：别急，我跑起来需要一台"发动机"——Node.js 就是我的引擎，Vite 是点火开关。没它们，你写了代码我也没法表演。

> 👨🏫 **老湿**：工具顺了，后面每章的代码才能"即写即跑"。这一章花 4 课时，换来后面 12 章的顺畅，值！

## 🛠 本章实战

学完本章，你应该能完成这些事：

1. **打开终端**，输入 `node -v` 能看到 Node.js 版本
2. **打开 VS Code**，安装好 Vue 官方插件（Volar）
3. **执行命令** `npm create vue@latest` 创建一个新项目
4. **运行** `npm run dev` 看到浏览器里的"Welcome to Vue"
5. **修改** `App.vue` 让页面显示 "你好，我是 XXX"（XXX 是你的名字）
