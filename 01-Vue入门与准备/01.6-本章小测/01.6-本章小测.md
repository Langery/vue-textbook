## ✅ 答案

### 选择题答案

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | **A** | Vue 是 JavaScript 框架（library / framework 都被接受为"框架"在中文语境） |
| 2 | **C** | Vue 3 = 声明式 + 响应式 |
| 3 | **C** | Node.js 是必需的（运行 npm + Vite） |
| 4 | **B** | `npm create vue@latest` 是官方命令 |
| 5 | **B** | `package.json` 里 `dev: "vite"`，所以跑的是 `vite` |
| 6 | **C** | SFC 3 段：`<script setup>` + `<template>` + `<style scoped>` |
| 7 | **B** | `scoped` 表示样式只作用于当前组件 |
| 8 | **C** | `components/` 放可复用组件 |
| 9 | **B** | `node_modules/` 是 npm 自动管理的，**不要手动改** |
| 10 | **B** | HMR = Hot Module Replacement，改代码自动刷新 |

### 实操题答案

实操题无标准答案——按评分标准对照你的实现打分。

**自查清单**：
- [ ] 项目能跑
- [ ] 3 段式结构正确
- [ ] 3 个字段都显示
- [ ] 有边框和圆角
- [ ] 名字字号大
- [ ] App.vue 引用成功
