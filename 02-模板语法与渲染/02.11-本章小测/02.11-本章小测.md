## 📝 第二部分：判断题（每题 3 分，共 15 分）

**1.** `<template v-if>` 会在 DOM 中生成一个 `<template>` 标签。（ ）

**2.** 用 `index` 做 key 的唯一风险是性能问题，不会导致功能 Bug。（ ）

**3.** `v-for="n in 5"` 会渲染 1、2、3、4、5 共五个元素。（ ）

**4.** `v-else-if` 和 `v-else` 必须紧跟在 `v-if` 或 `v-else-if` 的元素后面，不能插入其他元素。（ ）

**5.** `v-memo` 的作用和 `computed` 完全一样，只是写的位置不同。（ ）

## 🛠 第三部分：实操题（每题 10 分，共 20 分）

### 实操题 1：商品筛选器

写一个商品列表，**支持按类别筛选**：

```vue
<script setup>
import { ref, computed } from 'vue'
const products = ref([
  { id: 1, name: 'iPhone', category: 'phone', price: 5999 },
  { id: 2, name: 'iPad', category: 'tablet', price: 3999 },
  { id: 3, name: 'MacBook', category: 'laptop', price: 12999 },
  { id: 4, name: 'AirPods', category: 'phone', price: 1299 },
])
const selectedCategory = ref('all')

const filteredProducts = computed(() => {
  if (selectedCategory.value === 'all') return products.value
  return products.value.filter(p => p.category === selectedCategory.value)
})
</script>

<template>
  <select v-model="selectedCategory">
    <option value="all">全部</option>
    <option value="phone">手机</option>
    <option value="tablet">平板</option>
    <option value="laptop">电脑</option>
  </select>

  <ul>
    <li v-for="p in filteredProducts" :key="p.id">
      {{ p.name }}：¥{{ p.price.toLocaleString() }}
    </li>
  </ul>
</template>
```

**评分**：
- 列表渲染（4 分）
- 类别筛选（4 分）
- 价格千分位（2 分）

### 实操题 2：权限切换 UI

根据用户角色显示不同内容：

```
<script setup>
import { ref } from 'vue'
const role = ref('guest')  // guest / user / admin
</script>

<template>
  <select v-model="role">
    <option value="guest">游客</option>
    <option value="user">普通用户</option>
    <option value="admin">管理员</option>
  </select>

  <div v-if="role === 'guest'">
    <h1>请先登录</h1>
    <button>登录</button>
  </div>

  <div v-else-if="role === 'user'">
    <h1>普通用户面板</h1>
    <p>查看个人资料</p>
  </div>

  <div v-else>
    <h1>管理员后台</h1>
    <p>管理所有用户</p>
    <p>查看系统日志</p>
  </div>
</template>
```

**评分**：
- v-if/v-else-if/v-else 正确（6 分）
- 三种角色都显示（2 分）
- 切换无报错（2 分）
