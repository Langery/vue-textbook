## 一、模板里能写什么

`{{ }}` 是 **JS 表达式**——所有合法的 JS 表达式都能用。

### 1. 变量和常量

```vue
<script setup>
import { ref } from 'vue'
const name = ref('小明')
const age = 20           // 普通变量也能用
const PI = 3.14
</script>

<template>
  <p>{{ name }}</p>
  <p>{{ age }}</p>
  <p>{{ PI }}</p>
</template>
```

### 2. 算术运算

```
<template>
  <p>总和：{{ 10 + 20 }}</p>          <!-- 30 -->
  <p>差：{{ 50 - 30 }}</p>             <!-- 20 -->
  <p>积：{{ 6 * 7 }}</p>                <!-- 42 -->
  <p>商：{{ 10 / 3 }}</p>              <!-- 3.333 -->
  <p>余：{{ 10 % 3 }}</p>              <!-- 1 -->
  <p>平方：{{ 5 ** 2 }}</p>             <!-- 25（ES6 幂运算） -->
</template>
```

### 3. 比较运算

```vue
<template>
  <p>{{ 5 > 3 }}</p>          <!-- true -->
  <p>{{ 5 === '5' }}</p>      <!-- false（严格等于） -->
  <p>{{ 'a' < 'b' }}</p>      <!-- true（字符串比较） -->
</template>
```

> 💬 **老师备注**：模板里**用 `===` 不用 `==`**（`==` 会做类型转换，可能出 bug）。

### 4. 逻辑运算

```
<template>
  <p>{{ true && 'yes' }}</p>           <!-- yes -->
  <p>{{ false || 'default' }}</p>      <!-- default -->
  <p>{{ !isLoading }}</p>              <!-- 取反 -->
</template>
```

### 5. 三元运算

```vue
<template>
  <p>{{ age >= 18 ? '成年' : '未成年' }}</p>
  <p>{{ count > 0 ? '有' : '无' }}</p>
</template>
```

### 6. 数组方法

```
<script setup>
const fruits = ['苹果', '香蕉', '橙子']
</script>

<template>
  <!-- map：数组变换 -->
  <p>数量：{{ fruits.length }}</p>
  <p>大写：{{ fruits.map(f => f.toUpperCase()) }}</p>
  <!-- 注意：map 返回数组，渲染时用逗号分隔 -->

  <!-- filter：过滤 -->
  <p>有"果"的：{{ fruits.filter(f => f.includes('果')) }}</p>

  <!-- join：数组转字符串 -->
  <p>拼接：{{ fruits.join('、') }}</p>     <!-- 苹果、香蕉、橙子 -->
</template>
```

### 7. 字符串方法

```vue
<script setup>
const name = 'Vue 3 教程'
</script>

<template>
  <p>长度：{{ name.length }}</p>
  <p>大写：{{ name.toUpperCase() }}</p>
  <p>包含"教程"：{{ name.includes('教程') }}</p>
  <p>截取：{{ name.slice(0, 4) }}</p>     <!-- "Vue 3" -->
</template>
```

### 8. 数字格式化

```
<script setup>
const price = 1234.5678
</script>

<template>
  <!-- toFixed：保留 N 位小数 -->
  <p>价格：{{ price.toFixed(2) }}</p>           <!-- 1234.57 -->

  <!-- 千分位 -->
  <p>千分位：{{ price.toLocaleString() }}</p>   <!-- 1,234.568 -->
</template>
```

> 💬 **老师备注**：**数字格式化**也可以用 Intl 对象（`new Intl.NumberFormat('zh-CN').format(1234.5)`）——更专业。

## 二、模板里不能写什么

### 1. 不能声明变量

```vue
<!-- ❌ 错 -->
{{ const a = 1 }}
{{ let name = 'test' }}
{{ var count = 0 }}

<!-- ✅ 对：在 <script> 里声明 -->
```

### 2. 不能写语句

```
<!-- ❌ 错：if 是语句 -->
{{ if (ok) { return 'yes' } }}

<!-- ✅ 对：用三元 -->
{{ ok ? 'yes' : 'no' }}
```
```
<!-- ❌ 错：for 是语句 -->
{{ for (let i = 0; i < 3; i++) { ... } }}

<!-- ✅ 对：用数组方法 map（第 2.7 节讲） -->
{{ items.map(item => ...) }}
```

### 3. 不能写多行代码

```
<!-- ❌ 错 -->
{{
  const a = 1
  const b = 2
  a + b
}}

<!-- ✅ 对：单行表达式 -->
{{ 1 + 2 }}
```

### 4. 不能用 var/let/const 重新赋值 ref

```
<script setup>
const count = ref(0)
</script>

<template>
  <!-- ❌ 错：模板里不能改 ref 的值 -->
  <button @click="{{ count.value = 1 }}">...</button>

  <!-- ✅ 对：在事件处理器里改 -->
  <button @click="count++">...</button>
</template>
```

> 💬 **老师备注**：`{{ count++ }}` 在 Vue 3 里**会报错**——模板里只能"读"，不能"写"。

把这四类限制汇总成一张"红绿灯"表，犯错前先看它：

| 禁区 | 错误示例 | 为什么不行 | 正确姿势 |
|---|---|---|---|
| **① 声明变量** | `{{ const a = 1 }}` | 模板是"展示层"，不负责存数据 | 变量放 `` <script setup> `` 里声明 |
| **② 写语句** | `{{ if (ok) { ... } }}` | `{{ }}` 里只接受"有值"的表达式 | 用三元 `{{ ok ? 'yes' : 'no' }}` |
| **③ 多行代码** | `{{ 多行逻辑 }}` | 模板追求简洁，复杂逻辑请移步 | 用 computed / 函数封装 |
| **④ 修改状态** | `{{ count++ }}` | 模板只能"读"，不能"写" | 在事件处理器里 `@click="count++"` |

> 🧑 **小白**：记不住怎么办？
> 👨🏫 **老湿**：就记一句话——**模板是"显示屏"，不是"计算器"也不是"记事本"**。读数据、调函数可以；声明、写逻辑、改数据，统统回 `<script>` 去。

## 三、模板 vs Script：边界

| 在哪？ | 能做什么？ | 不能做什么？ |
|---|---|---|
| **`<script>`** | 声明变量、函数、import | — |
| **`<template>`** | 调用变量、调用函数、表达式 | 声明、语句、修改状态 |

**简单判断**：
- 模板只做"展示"——把数据变成 HTML
- Script 做"业务"——定义数据、定义逻辑

## 四、复杂逻辑怎么办？用 computed

**模板里写超长表达式 = 代码异味**。**用 `computed` 替代**。

```
<!-- ❌ 不好：模板里逻辑复杂 -->
<template>
  <p>{{ items.filter(i => i.active).map(i => i.name).join('、') }}</p>
</template>

<!-- ✅ 好：用 computed 抽出 -->
<script setup>
import { computed } from 'vue'

const items = ref([...])
const activeNames = computed(() =>
  items.value
    .filter(i => i.active)
    .map(i => i.name)
    .join('、')
)
</script>

<template>
  <p>{{ activeNames }}</p>
</template>
```

**好处**：
- 模板简洁
- 逻辑可测试
- 性能更好（computed 会缓存，重复读不重复算）

> 💬 **老师备注**：`computed` 会在第 5 章深入讲。现在你只要知道：**复杂逻辑用 computed**。

## 五、3 个模板技巧

### 技巧 1：链式调用

```
<template>
  <!-- 一行完成：过滤 → 转换 → 拼接 -->
  <p>{{ items.filter(i => i > 0).map(i => i * 2).join(' + ') }}</p>
</template>
```

### 技巧 2：可选链 `?.`

```
<script setup>
const user = ref(null)
</script>

<template>
  <!-- 安全访问：如果 user 是 null，不会报错 -->
  <p>{{ user?.name }}</p>
  <p>{{ user?.address?.city }}</p>
</template>
```

### 技巧 3：默认值 `??`

```
<template>
  <!-- nullish 合并：只有 null/undefined 才用默认值 -->
  <p>{{ user?.name ?? '游客' }}</p>
  <p>{{ count ?? 0 }}</p>
</template>
```

## 🧠 本节小结

- **能写**：变量、算术/比较/逻辑运算、三元、数组方法、字符串方法、可选链等合法表达式
- **不能写**：变量声明（`var/let/const`）、语句（`if/for/switch/return`）、多行代码、给 ref 重新赋值
- **边界直觉**：模板只负责"读数据 + 简单变换"，不负责"逻辑 + 副作用"
- **复杂逻辑怎么办**：别在模板里硬堆，交给 `computed`（第 5 章正式学）
- **实用技巧**：链式调用、可选链 `?.`、默认值 `??` 能让模板更简洁安全

```
  { name: 'iPad', price: 3999, stock: 0 },
  { name: 'MacBook', price: 12999, stock: 2 },

<template>
  <ul>
    <li v-for="(p, i) in products" :key="i">
      <span>{{ p.name }}</span>
      <span>¥{{ p.price.toLocaleString() }}</span>

```
