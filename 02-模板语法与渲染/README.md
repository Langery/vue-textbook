# 第 2 章：模板语法与渲染

> 课时建议：10 课时（含练习）
> 适用对象：Vue 3 初学者

---

## 章简介

本章是 Vue 3 的**模板语法基础**。从"模板到底是个啥"出发，带你掌握插值、指令、条件渲染（v-if）、列表渲染（v-for）、key 的作用与最佳实践、列表与条件的组合用法，以及 v-memo 渲染加速。第 7 章"条件列表与 key"的内容已并入本章，成为 2.5~2.9 节。

> 🧑 **小白**：页面用 HTML 写不就行了？为什么还要学一套"模板语法"？

> 🤖 **Vue 君**：HTML 是"死"的——写死什么就显示什么。我能让页面"活"起来：数据一变，界面自动跟着变。

> 👨🏫 **老湿**：这一章你会第一次尝到"数据驱动视图"的甜头。先把插值、指令、v-if、v-for 这几板斧练熟，后面组件化全靠它们。

---

## 本章目标

学完本章，你将能够：

- ✅ 理解 Vue 模板的本质（HTML + 指令 + 表达式）
- ✅ 熟练使用插值 `{{ }}` 与常用指令（v-bind / v-on / v-model / v-html / v-text）
- ✅ 掌握模板的三大规矩：单根、合法表达式、驼峰命名
- ✅ 用 v-if / v-else / v-else-if 实现条件渲染，并理解与 v-show 的区别
- ✅ 用 v-for 遍历数组、对象、数字、字符串
- ✅ 深刻理解 key 的"身份证"作用，会为列表选择正确的 key
- ✅ 掌握列表 + 条件的组合用法（computed / template / 内部 v-if 三种方案）
- ✅ 用 v-memo 优化大列表渲染性能

## 学习提示

- **2.1-2.4 是地基**：模板三大规矩（单根、合法表达式、驼峰命名）必须背熟。
- **2.5-2.6 是核心**：v-if 和 v-for 是日常开发出现频率最高的两个指令，多写多练。
- **2.7 是重点节**：key 的原理与最佳实践，面试高频考点。先看 Bug 案例，再理解 Diff，最后记住选值优先级。
- **2.8 的三种方案**：列表 + 条件组合是 Vue 3 的经典考点，建议把三种正确方案都敲一遍。
- **2.9 是进阶**：v-memo 是性能优化利器，理解依赖数组的判定逻辑即可，不必死记语法。
- 不要跳读，尤其是 2.5 和 2.7——条件渲染和 key 的坑，后面所有章节都会用到。

## 常见坑

| 坑 | 说明 |
|---|---|
| `{{ }}` 里写语句 | 只能写表达式，`if` / `return` 等语句直接报错 |
| 列表用 index 做 key | 中间增删时内容错位、输入框状态串位 |
| v-if 和 v-for 同元素 | Vue 3 中 v-if 优先级更高，容易踩未定义变量 |
| v-else 不紧跟 v-if | 中间插入其他元素会导致不生效 |
| 依赖项过多用 v-memo | 比较成本大于跳过收益，反而变慢 |
