## 一、Teleport —— "传送门"

有时你需要把一段 HTML **渲染到 DOM 树的另一个位置**。比如弹窗（Modal）——它在组件树里可能很深，但视觉上必须覆盖整个页面。如果直接在当前组件渲染，CSS 的 `z-index` 很容易被父级"关住"。

**Teleport** 就是解决这个问题的：

```vue
<template>
  <button @click="show = true">打开弹窗</button>

  <!-- Teleport 把内部内容"传送"到 <body> 下 -->
  <Teleport to="body">
    <div v-if="show" class="modal-overlay">
      <div class="modal-box">
        <h2>我是弹窗</h2>
        <button @click="show = false">关闭</button>
      </div>
    </div>
  </Teleport>
</template>

<script setup>
import { ref } from 'vue'
const show = ref(false)
</script>
```

无论包裹这个组件的父元素 `overflow` 是什么、`z-index` 是多少，弹窗**永远渲染在 `<body>` 末尾**，完全不受父级制约。

> 💬 **老师备注**：Teleport 听起来像魔法，但其实就是 Vue 帮你移动了几个 DOM 节点。第 3 章“组件组合”会系统学习它。

## 二、Suspense —— "异步加载"

实际项目中，组件可能需要**异步加载数据**后才能渲染。Suspense 让你可以优雅地**在数据加载期间显示"骨架屏"**，而不是让用户对着白屏发呆。

```
<template>
  <Suspense>
    <!-- 第 1 个插槽：真正要显示的内容（异步加载完成后） -->
    <template #default>
      <AsyncDashboard />
    </template>

    <!-- 第 2 个插槽：加载中的占位内容 -->
    <template #fallback>
      <div class="loading">
        <p>加载中，请稍候...</p>
      </div>
    </template>
  </Suspense>
</template>

<script setup>
import { defineAsyncComponent } from 'vue'

// defineAsyncComponent：异步加载组件
const AsyncDashboard = defineAsyncComponent(() =>
  import('./Dashboard.vue')
)
</script>
```

当 `Dashboard.vue` 还在网络加载时，用户看到的是"加载中..."；加载完成瞬间，内容自动切换。

> 💬 **老师备注**：Suspense 是 Vue 3 的"实验性功能"，但目前生态已经广泛支持。你在第 3 章“动态组件进阶”和第 10 章“异步与路由”会深入学习它。

## 三、v-memo —— "记忆缓存"

2.7 节你学了 `:key`，它让 Vue 在列表更新时识别元素身份。`v-memo` 更进一步：**如果依赖没变，直接复用上次的 VNode，连 diff 都跳过**。

```vue
<template>
  <!-- 只有 item.id 或 item.selected 变了，才重新渲染这个 <li> -->
  <li
    v-for="item in list"
    :key="item.id"
    v-memo="[item.id, item.selected]"
    :class="{ active: item.selected }"
  >
    {{ item.text }}
  </li>
</template>
```

假设列表有 1000 条，你只改了其中 1 条的 `selected`——**Vue 只重新渲染那 1 条**，其余 999 条直接复用。在大列表中性能提升巨大。

> 💬 **老师备注**：`v-memo` 是性能优化的"终极武器"——用好了飞起来，用错了反而可能阻碍正常更新。2.9 节已经讲了 v-memo 的基础用法。现在你只要知道 Vue 还有这个能力就行。

## 🧠 本节小结

- **Teleport**：把 DOM 渲染到任意位置，专门解决弹窗/浮层被父级 `z-index` "关住"的问题
- **Suspense**：为异步组件/异步依赖提供加载态（fallback），让页面不再"白屏干等"
- **v-memo**：依赖数组不变时直接复用 VNode、跳过 diff，2.9 已正式学过
- **学习节奏**：模板基础语法到此告一段落，Teleport / Suspense 会在第 3、10 章正式展开
