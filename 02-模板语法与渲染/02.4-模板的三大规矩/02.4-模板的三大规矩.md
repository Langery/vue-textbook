## 规矩 1：单根元素（最常踩坑）

### ❌ 错误：多根

```vue
<template>
  <h1>标题</h1>
  <p>段落 1</p>
  <p>段落 2</p>
</template>
```

**报错**：
```text
Component template requires a single root element
```

### ✅ 正确：包一层 `<div>`

```
<template>
  <div>
    <h1>标题</h1>
    <p>段落 1</p>
    <p>段落 2</p>
  </div>
</template>
```

### ✅ 也对：Vue 3 支持多根（Fragment）

**Vue 3 起**允许多根：

```vue
<template>
  <h1>标题</h1>
  <p>段落 1</p>
  <p>段落 2</p>
</template>
```

**但**——**99% 情况还是包一层**。原因：
- 单根 + 配合 `transition` 做动画更简单
- 单根 + `<style scoped>` 隔离更彻底
- 第三方组件库**不**都支持 Fragment

> 💬 **老师备注**：**默认包 `<div>`**。除非有特殊理由（性能、布局），否则不写多根。

### 单根的好习惯

```
<template>
  <div class="user-card">      <!-- 根 div 加语义化 class -->
    <header>
      <h1>{{ name }}</h1>
    </header>
    <main>
      <p>{{ bio }}</p>
    </main>
  </div>
</template>
```

## 规矩 2：合法 JS 表达式

`{{ }}` 里**只能写表达式，不能写语句**（上一节讲过）。

### 常见违规

```vue
<!-- ❌ 错：if 语句 -->
{{ if (ok) { return 'yes' } }}

<!-- ❌ 错：赋值 -->
{{ count = 5 }}

<!-- ❌ 错：变量声明 -->
{{ const a = 1 }}

<!-- ❌ 错：多行 -->
{{
  const a = 1
  const b = 2
  a + b
}}
```

### 为什么这么限制？

Vue 编译模板时，**把 `{{ }}` 变成 JS 表达式的求值**。

```
<!-- 模板 -->
<p>{{ count + 1 }}</p>

<!-- 编译成 -->
function render() {
  return h('p', null, count + 1)   // 直接当表达式
}
```

**如果写成 if 语句**：

```vue
<!-- 模板 -->
<p>{{ if (ok) { return 'yes' } }}</p>

<!-- 编译时——没法编译！ -->
// JS 报错：Unexpected token 'if'
```

> 💬 **老师备注**：这就是为什么**模板里不能写 if/for/变量声明**——它们是"语句"，不是"表达式"。

### 解决：复杂逻辑用 computed

```
<!-- 错：模板里逻辑复杂 -->
<p>{{ items.filter(i => i.active).map(i => i.name).join('、') }}</p>

<!-- 对：抽到 computed -->
<script setup>
import { computed } from 'vue'
const activeNames = computed(() =>
  items.value.filter(i => i.active).map(i => i.name).join('、')
)
</script>
<template>
  <p>{{ activeNames }}</p>
</template>
```

## 规矩 3：驼峰命名

HTML 属性**不区分大小写**（浏览器会全部转小写）。Vue 模板要处理这个差异。

### 两种写法

```vue
<template>
  <!-- kebab-case（短横线）：HTML 原生写法 -->
  <MyComponent :user-name="name" @close-dialog="handleClose" />

  <!-- camelCase（驼峰）：Vue 写法 -->
  <MyComponent :userName="name" @closeDialog="handleClose" />
</template>
```

**两种都对**——Vue 都认。

### 命名规则总结

| 场景 | 推荐写法 | 原因 |
|---|---|---|
| **HTML 原生属性**（`class` / `id` / `for`） | 小写 / kebab | HTML 规范 |
| **Vue 组件标签** | PascalCase（`<MyComponent>`） | 跟 import 一致 |
| **Props 传递** | camelCase（`:userName`） | 跟 JS 变量名一致 |
| **事件监听** | camelCase（`@closeDialog`） | 跟 emit 名字一致 |
| **自定义指令** | kebab-case（`v-my-directive`） | 跟 HTML 一致 |

### ❌ 错误：标签名小写

```
<!-- ❌ 错：Vue 找名为 "mycomponent" 的组件，找不到 -->
<mycomponent />

<!-- ✅ 对：PascalCase -->
<MyComponent />
```

> 💬 **老师备注**：**第 3 章会专门讲组件命名**。简单记：**HTML 标签小写、Vue 组件首字母大写**。

## 三、其他"软规则"（不报错但不推荐）

### 软规则 1：模板尽量简单

```vue
<!-- ⚠️ 不推荐：模板里 100 行逻辑 -->
<template>
  <div v-for="user in users.filter(u => u.active).sort((a, b) => a.age - b.age)">
    {{ user.name + ' (' + user.age + ')' }}
  </div>
</template>

<!-- ✅ 推荐：逻辑在 script 里 -->
<script setup>
const sortedUsers = computed(() =>
  users.value
    .filter(u => u.active)
    .sort((a, b) => a.age - b.age)
)
</script>
<template>
  <div v-for="user in sortedUsers" :key="user.id">
    {{ `${user.name} (${user.age})` }}
  </div>
</template>
```

### 软规则 2：避免副作用

```
<!-- ❌ 错：在模板里改数据（无限循环！） -->
<template>
  <p>{{ count++ }}</p>     <!-- 每次 render 都会改 count -->
</template>

<!-- ✅ 对：用事件处理器 -->
<template>
  <p>{{ count }}</p>
  <button @click="count++">+1</button>
</template>
```

### 软规则 3：避免复杂三元嵌套

```vue
<!-- ⚠️ 不推荐：3 层三元 -->
<p>{{ a ? 'A' : b ? 'B' : c ? 'C' : 'D' }}</p>

<!-- ✅ 推荐：抽到 computed -->
<script setup>
const label = computed(() => {
  if (a.value) return 'A'
  if (b.value) return 'B'
  if (c.value) return 'C'
  return 'D'
})
</script>
<template>
  <p>{{ label }}</p>
</template>
```

## Vue 3 特例：Fragment + `<script setup>`

### Fragment（多根）已支持

```
<!-- Vue 3：这样不会报错 -->
<template>
  <header>...</header>
  <main>...</main>
  <footer>...</footer>
</template>
```

**但要小心**：
- `transition` 包裹多根组件会**失效**
- `:key` 必须显式声明

### `<script setup>` 语法糖

**Vue 3 推荐**用 `<script setup>`——少写很多样板代码：

```vue
<!-- 老写法（Vue 2 / 选项式） -->
<script>
export default {
  data() { return { count: 0 } },
  methods: { increment() { this.count++ } }
}
</script>

<!-- 新写法（Vue 3 / 组合式 + setup） -->
<script setup>
import { ref } from 'vue'
const count = ref(0)
const increment = () => count.value++
</script>
```

> 💬 **老师备注**：**本书所有代码都用 `<script setup>`**。

## 🧠 本节小结

- **规矩 1 单根**：模板默认只能有一个根元素，Vue 3 用 Fragment 支持多根，但业务上仍推荐包一层 `<div>`
- **规矩 2 合法表达式**：`{{ }}` 里只放表达式，复杂逻辑用 `computed` 接住
- **规矩 3 驼峰命名**：Props/事件在 JS 里用 camelCase，HTML 属性用 kebab-case，标签名用 PascalCase
- **三条软规则**：模板保持简单、避免副作用、避免复杂三元嵌套
- **Vue 3 特例**：`<script setup>` 语法糖 + Fragment 让组件写法更简洁
