## 🎯 本章目标

学完这章，你将能够：

- ✅ 理解 Vue 组件的**生命周期**（创建/挂载/更新/卸载）

- ✅ 用 **`watch`** 精准监听特定数据

## 🤔 为什么学这章

**数据有了，但怎么"对数据变化做反应"？**——比如：
- `count` 变了，要**请求接口**
- `userId` 变了，要**重置表单**
- 组件**卸载了，要清掉定时器**

本章教"副作用管理"——Vue 应用里 80% 的"业务逻辑"都在这一章。

> 🧑 **小白**：数据变了页面会自动更新，可我想在数据变化时"多做点事"——比如重新请求接口，该怎么办？

> 🤖 **Vue 君**：交给我 `watch` 和 `watchEffect`！你告诉我"盯谁、做什么"，剩下的依赖追踪我全包。

> 👨🏫 **老湿**：请求接口、重置表单、清理定时器……Vue 应用里 80% 的业务逻辑都在这章，认真学。

1. 用 `watchEffect` 实现"**输入框防抖**"（500ms 后才查接口）

4. 故意**不写清理函数**，看定时器在组件卸载后是否还在跑

## ⚠️ 学习提示

- **不要**把"任何"逻辑都放进 `watchEffect`——**事件处理**用 `@click`，**计算**用 `computed`，只有"数据变化要做额外的事"才用 watch
- **清理函数** 一定要写——尤其是定时器、事件订阅、AbortController
- **`watch` 的 deep 选项** 默认是 false，对象/数组要写 `deep: true`
