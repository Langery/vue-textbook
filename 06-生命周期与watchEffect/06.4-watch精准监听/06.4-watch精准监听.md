```text
├── 三种监听源
│   ├── ref：watch(count, ...)
│   ├── reactive 对象：watch(state, ...)（自动 deep）
│   └── getter 函数：watch(() => x.value + y.value, ...)
├── 关键选项
│   ├── deep: true → 深度监听对象/数组内部
│   ├── immediate: true → 首次立即执行

│   └── watch([ref1, ref2], ([new1, new2], [old1, old2]) => { ... })
└── 三兄弟对比
    ├── computed：纯计算，返回一个值，有缓存
    ├── watchEffect：自动追踪，立即执行，只要"干了就好"
    └── watch：精准指定，拿到新旧值，可配选项
```

`watchEffect` 确实省事，但有两个"够不着"的场景：你想对比新旧值，或只想盯某个字段而不管其他数据。这时它的"自动追踪一切"反而成了缺点。`watch` 走另一条路：明确告诉它"监听谁"，它把新值和旧值一起递给你，还带 `deep`、`immediate` 等选项。本节把 watch 的三种监听源和选项讲透。

---

## 🤔 一、`watch` 解决了什么问题？

`watchEffect` 方便，但有两个限制：
1. **无法拿到旧值**——你不知道数据"从什么变成什么"
2. **无法精细控制**——不能指定"只监听 X，别管 Y"，不能配 `deep`

`watch` 就是为这些场景设计的：**精准指定监听谁、拿到新旧值、自定义选项**。

> 💬 **老师备注**：`watch` 像一个"定点探头"——你指定装在哪个角落，监控什么，报警时告诉你"从什么变成了什么"。`watchEffect` 则是"全景摄像头"——自己看有啥就监控啥。

## 💡 二、基本语法

```javascript
import { watch } from 'vue'

// 语法：watch(监听源, 回调函数, 选项?)
watch(source, (newVal, oldVal) => {
  // newVal：变化后的值
  // oldVal：变化前的值
})
```

**监听源 `source` 有四种写法**：

| 写法 | 示例 | 监听什么 |
|---|---|---|
| ref | `watch(count, ...)` | `count.value` 的变化 |
| reactive 对象 | `watch(state, ...)` | `state` 任意属性的变化（自动 deep） |
| getter 函数 | `watch(() => x.value + y.value, ...)` | 函数的返回值变化 |
| 数组（多源） | `watch([a, b], ...)` | `a` 或 `b` 任一变化 |

## 🛠 三、完整可运行示例

### 示例 1：监听 ref（最常用）

```vue
<script setup>
import { ref, watch } from 'vue'

const keyword = ref('')
const debouncedKeyword = ref('')

// 监听 keyword 变化，500ms 防抖后再更新
let timer = null
watch(keyword, (newVal, oldVal) => {
  console.log(`关键词从 "${oldVal}" 变为 "${newVal}"`)
  
  // 防抖：清除上一次定时器
  clearTimeout(timer)
  timer = setTimeout(() => {
    debouncedKeyword.value = newVal
  }, 500)
})
</script>

<template>
  <div>
    <input v-model="keyword" placeholder="输入搜索关键词" />
    <p>实时输入：{{ keyword }}</p>
    <p>防抖结果：{{ debouncedKeyword }}</p>
  </div>
</template>
```

### 示例 2：监听 reactive 对象

```
<script setup>
import { reactive, watch } from 'vue'

const form = reactive({
  username: '',
  password: '',
  remember: false
})

// 监听整个 reactive 对象
// 注意：reactive 对象默认 deep: true（内部属性变化也能监听到）
watch(form, (newForm, oldForm) => {
  // ⚠️ newForm 和 oldForm 指向同一个对象引用
  console.log('表单数据变了', newForm)
})
</script>

<template>
  <div>
    <input v-model="form.username" placeholder="用户名" />
    <input v-model="form.password" type="password" placeholder="密码" />
    <label>
      <input type="checkbox" v-model="form.remember" /> 记住我
    </label>
  </div>
</template>
```

> 💬 **老师备注**：监听 `reactive` 对象时，`newVal` 和 `oldVal` 是同一个引用（因为 reactive 是 Proxy，修改属性不会改变对象本身）。如果你需要"具体的哪个属性变了"，用 getter 函数。

### 示例 3：用 getter 函数监听对象某个属性

```vue
<script setup>
import { reactive, watch } from 'vue'

const form = reactive({
  username: '',
  password: ''
})

// ✅ getter 函数：精准监听 form.username
watch(
  () => form.username,
  (newName, oldName) => {
    console.log(`用户名从 "${oldName}" 变为 "${newName}"`)
  }
)

// 也可以监听计算结果
watch(
  () => form.username.length,
  (newLen) => {
    console.log(`用户名长度：${newLen}`)
  }
)
</script>
```

### 示例 4：同时监听多个源

```
<script setup>
import { ref, watch } from 'vue'

const price = ref(100)
const quantity = ref(1)
const total = ref(0)

// 同时监听 price 和 quantity
watch(
  [price, quantity],
  ([newPrice, newQty], [oldPrice, oldQty]) => {
    console.log(`price: ${oldPrice}→${newPrice}, qty: ${oldQty}→${newQty}`)
    total.value = newPrice * newQty
  }
)
</script>

<template>
  <div>
    单价：<input type="number" v-model.number="price" />
    数量：<input type="number" v-model.number="quantity" />
    <p>总价：{{ total }}</p>
  </div>
</template>
```

## 🔧 四、关键选项：`deep` 和 `immediate`

### `immediate: true` —— 立即执行

```javascript
const count = ref(0)

// 默认：只有 count 变化时才触发
watch(count, (newVal) => {
  console.log(newVal)  // 首次不触发
})

// immediate: true → 创建时立刻执行一次
watch(count, (newVal) => {
  console.log(newVal)  // 首次就输出 0
}, { immediate: true })
```

### `deep: true` —— 深度监听

```javascript
const list = ref([1, 2, 3])

// ❌ 默认 shallow：list.value = [...] 才触发（整个数组被替换）
//    list.value.push(4) 不会触发！
watch(list, () => { /* 不触发 */ })

// ✅ deep: true：数组内部 push/pop/splice 都触发
watch(list, () => {
  console.log('数组变了')
}, { deep: true })
```

> 💬 **老师备注**：`deep: true` 有性能开销（Vue 要递归遍历整个对象）——大对象慎用。更好的做法是用 getter 函数只监听需要的字段，而不是整个对象 deep 监听。

### `deep` 速查表

| 源类型 | 默认 deep | 说明 |
|---|---|---|
| `ref(基本类型)` | 不需要 | 值本身变了就是变了 |
| `ref(对象)` | ❌ false | 只有整个对象被替换才触发 |
| `ref(对象) + deep:true` | ✅ 强制 | 内部属性变化也触发 |
| `reactive(对象)` | ✅ 自动 deep | reactive 自带深度监听 |
| getter 函数 | 看返回值 | 返回基本类型不用 deep；返回对象同理 |

## 🆚 五、`computed` vs `watchEffect` vs `watch`

这是 Vue 3 里最容易被搞混的三个 API。一句话分清楚：

| API | 一句话 | 何时用 |
|---|---|---|
| **`computed`** | "**根据已有数据算出一个新值**" | 需要"纯计算结果"，有缓存 |
| **`watchEffect`** | "**数据变了就自动干某事**" | 简单粗暴，不管新旧值 |
| **`watch`** | "**我知道监听谁，还要知道怎么变的**" | 精准控制，需新旧值 |

### 实战对比

```vue
<script setup>
import { ref, computed, watchEffect, watch } from 'vue'

const price = ref(100)
const quantity = ref(1)
const discount = ref(0.9)

// ✅ computed：纯计算总价，price/quantity/discount 变 → total 自动变
const total = computed(() => {
  return price.value * quantity.value * discount.value
})

// ✅ watchEffect：自动监听价格变化，超过 500 弹提醒
watchEffect(() => {
  if (price.value > 500) {
    alert('价格太高了！')
  }
})

// ✅ watch：精准监听 quantity，需要对比新旧值
watch(quantity, (newQty, oldQty) => {
  console.log(`数量从 ${oldQty} 变为 ${newQty}`)
})
</script>
```

> 💬 **老师备注**：一个简单的判断法：
> 1. 你要**返回一个值**吗？ → `computed`
> 2. 你要**干一件事（发请求、存数据）**但不在乎旧值？ → `watchEffect`
> 3. 你要**干一件事 + 知道怎么变的（新旧值对比）**？ → `watch`

## ⚠️ 六、常见陷阱

### 陷阱 1：`ref(数组).push()` 不触发 watch ❌

```javascript
const list = ref([1, 2, 3])

// ❌ 不会触发：list.value 的引用没变，是数组内部变了
watch(list, () => console.log('变了'))

list.value.push(4)  // 没反应

// ✅ 解决方案：加 deep: true 或用 reactive
watch(list, () => console.log('变了'), { deep: true })
```

### 陷阱 2：`reactive` 对象 watch 拿不到真正旧值 ❌

```javascript
const state = reactive({ count: 0 })

watch(state, (newVal, oldVal) => {
  console.log(newVal === oldVal)  // true！同一个对象
})
```

**原因**：reactive 返回的是 Proxy，修改属性不会创建新对象。用 getter 解决：

```javascript
watch(() => state.count, (newCount, oldCount) => {
  console.log(`${oldCount} → ${newCount}`)  // 真正的旧值
})
```

### 陷阱 3：`deep: true` 在大对象上滥用 ❌

```javascript
// 一个 10 万行的表格数据
const bigData = ref(/* 超大的对象/数组 */)

// ❌ 性能杀手：每次任何字段变化都要遍历整个对象
watch(bigData, () => { /* ... */ }, { deep: true })
```

**解决**：用 getter 只监听需要的字段。

## 🧠 本节小结

- **watch 基本语法**：`watch(source, callback, options?)`，回调收到 `(newVal, oldVal)`
- **三种监听源**：ref 直接传；reactive 对象自动 deep；getter 函数精准监听表达式
- **immediate: true**：创建时立即执行一次，拿初始值做初始化逻辑
- **deep: true 慎用**：大对象深监听性能差，优先用 getter 收窄监听范围
- **多源监听**：`watch([a, b], ([na, nb], [oa, ob]) => ...)` 数组写法
- **三兄弟分工**：computed 纯计算有缓存；watchEffect 自动追踪"干了就好"；watch 精准拿新旧值可配选项
