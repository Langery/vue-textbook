给原生 `<input>` 用 `v-model` 大家都会，但一到自定义组件就翻车：`<MyInput v-model="name" />` 能打字，父组件的 `name` 却不动。原因很反直觉：组件上的 `v-model` 只是 `:modelValue` + `@update:modelValue` 的语法糖，子组件没实现这套契约，更新就传不回去。本节剥开这层糖衣。

## 🤔 一、v-model 的本质是什么？

在讲组件上的 `v-model` 之前，先回想一下原生表单元素：

```vue
<input v-model="text" />
```

这行代码等价于：

```
<input
  :value="text"
  @input="text = $event.target.value"
/>
```

**v-model 本质就是"Props（:value）+ 事件（@input）"的语法糖。**

把这个思路搬到组件上：

```vue
<!-- 希望 CustomInput 支持 v-model -->
<CustomInput v-model="text" />
```

等价于：

```
<CustomInput
  :model-value="text"
  @update:model-value="text = $event"
/>
```

所以——只要你的子组件接收 `modelValue` prop，并在合适时机 emit `update:modelValue` 事件，它就天然支持 `v-model`。

> 💬 **老师备注**：这就是 Vue 设计的精妙之处——没有魔法，就是把前 6 节学的 Props + Emit 组合在一起，用更好的语法写出来。

## 💡 二、基本实现：理解 v-model 的底层机制

> ⚠️ **先声明**：Vue 3.4+ 推荐用 `defineModel`（第四节）一行搞定。但理解底层 Props + Emit 机制很重要，下面先用传统写法拆解原理。

### 传统写法：defineProps + defineEmits

```vue
<!-- CustomInput.vue -->
<script setup>
// 接收 modelValue prop
defineProps(['modelValue'])
const emit = defineEmits(['update:modelValue'])

function onInput(e) {
  // 触发 update:modelValue 事件，把新值传出去
  emit('update:modelValue', e.target.value)
}
</script>

<template>
  <input
    :value="modelValue"
    @input="onInput"
    class="custom-input"
  />
</template>
```

```
<!-- 父组件 -->
<script setup>
import { ref } from 'vue'
import CustomInput from './components/CustomInput.vue'

const name = ref('张三')
</script>

<template>
  <CustomInput v-model="name" />
  <p>你输入的是：{{ name }}</p>
</template>
```

三件事缺一不可：
1. 子组件接收 prop 名为 `modelValue`
2. 子组件 emit 事件名为 `update:modelValue`
3. 父组件用 `v-model` 绑定

## 💡 三、v-model 参数：绑定多个值

一个组件可以有好几个 `v-model`：

```vue
<!-- 父组件 -->
<UserForm
  v-model:name="userName"
  v-model:email="userEmail"
  v-model:age="userAge"
/>
```

```
<!-- UserForm.vue -->
<script setup>
// 声明多个 v-model prop
defineProps(['name', 'email', 'age'])
const emit = defineEmits([
  'update:name',
  'update:email',
  'update:age'
])
</script>

<template>
  <input :value="name" @input="emit('update:name', $event.target.value)" />
  <input :value="email" @input="emit('update:email', $event.target.value)" />
  <input :value="age" @input="emit('update:age', $event.target.value)" />
</template>
```

**命名规则**：`v-model:xxx` 对应 prop `xxx` 和事件 `update:xxx`。

> 💬 **老师备注**：上面用的是传统写法（defineProps + defineEmits）。如果用 `defineModel`，多绑定更简洁——`const title = defineModel('title')`、`const content = defineModel('content')`，详见下一节。

顺便说一句，Vue 2 老项目里有个 `.sync` 修饰符，和 `v-model` 是一对"双胞胎"——它俩的底层机制几乎一样，只是写法不同：

| 对比维度 | `v-model`（Vue 3） | `.sync`（Vue 2 遗物） |
|---|---|---|
| 语法 | `v-model:title="val"` | `:title.sync="val"` |
| 背后机制 | `modelValue` + `update:modelValue`（或 `title` + `update:title`） | `title` + `update:title` |
| 默认绑定 | `v-model` 默认绑 `modelValue` | 必须显式写 `:xxx.sync` |
| 支持多个 | 支持多个 `v-model:xxx` | 也支持多个 `:xxx.sync` |
| 现状 | Vue 3 官方推荐 | Vue 2 专属，Vue 3 已移除 |

## 💡 四、defineModel：推荐写法（Vue 3.4+）

> ⭐ **本书推荐首选 `defineModel`，这也是 Vue 官方在 3.4+ 后的推荐方向。**

Vue 3.4 引入了 `defineModel`，一行代码顶过去五行，我们来直观感受一下：

```vue
<!-- ❌ 旧写法：defineProps + defineEmits（5 行） -->
<script setup>
defineProps(['modelValue'])
const emit = defineEmits(['update:modelValue'])
function onInput(e) { emit('update:modelValue', e.target.value) }
</script>

<!-- ✅ 新写法：defineModel（1 行） -->
<script setup>
const text = defineModel()
</script>
```

实际用法：

```
<!-- CustomInput.vue —— Vue 3.4+ 写法 -->
<script setup>
// 就这一行！自动处理 modelValue prop + update:modelValue emit
const text = defineModel()
</script>

<template>
  <input v-model="text" class="custom-input" />
</template>
```

支持多个 v-model：

```vue
<script setup>
const name = defineModel('name')
const email = defineModel('email')
</script>

<template>
  <input v-model="name" />
  <input v-model="email" />
</template>
```

带默认值：

```
<script setup>
// 默认值为空字符串
const text = defineModel({ default: '' })

// 带类型
const count = defineModel({ type: Number, default: 0 })
</script>
```

> 💬 **老师备注**：`defineModel` 是 Vue 3.4 才稳定的特性。如果你用的 Vite 项目创建时间早于 2024 年，记得升级 `vue` 到 3.4+。它同样是编译宏，不需要 `import`。

## ⚠️ 六、常见陷阱

### 陷阱 1：defineModel 需要 Vue 3.4+

如果你的项目是 Vue 3.3 或更早版本，`defineModel` 不可用。确认版本：

```bash
npm list vue   # 看版本号，必须 >= 3.4.0
```

升不了的话就用传统的 Props + Emit 写法。

### 陷阱 2：v-model 不要和 :modelValue 混用

```
<!-- ❌ 冲突：v-model 已经绑定了 modelValue，你又手动绑了一个 -->
<Child v-model="val" :model-value="anotherVal" />
```

### 陷阱 3：忘记 defineModel 也是"只读"的

```vue
<script setup>
const val = defineModel()
val.value = 'xxx'   // ✅ 在子组件内可以赋值（因为背后是 emit）
</script>
```

`defineModel` 返回的是一个 ref，你修改它时 Vue 会自动 emit。所以它**看起来像本地状态，实际上是 Props+Emit 的封装**。

### 陷阱 4：v-model 修饰符

```
<!-- 原生修饰符：.trim / .number / .lazy -->
<input v-model.trim="text" />

<!-- 组件上也支持，需要自己处理 -->
<Child v-model:title.capitalize="title" />
<!-- 子组件通过 defineModel 的第二个参数拿到修饰符 -->
```

## 🧠 本节小结

- **v-model 的本质**：组件上 `<Child v-model="val">` = `:modelValue="val"` + `@update:modelValue="val = $event"`，是 Props + Emit 的语法糖
- **子组件要配合实现**：接收 `modelValue` prop，值变化时 `emit('update:modelValue', newVal)`，契约对不上父组件数据就不动
- **多值绑定**：`v-model:title` / `v-model:content` 各自对应 `title`/`content` prop 和对应 update 事件
- **defineModel（Vue 3.4+）**：`const val = defineModel()` 自动处理好 props + emit，一行顶五行，是推荐写法
- **修饰符**：`.trim`/`.number`/`.lazy` 用于原生元素；自定义修饰符通过 defineModel 第二个参数接收
- **历史对照**：Vue 2 的 `.sync` 写法在 Vue 3 已统一为 `v-model:xxx`
