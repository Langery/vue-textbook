## 🤔 一、为什么需要 Props？

先回顾第 3 章学到的：**组件是独立的"积木"**。每个组件有自己的数据、逻辑和样式，默认情况下互不干扰。

这带来了一个问题：**如果父组件有一份数据，子组件要用，怎么办？**

举个例子：你做了一个 `UserCard` 组件，用来展示用户名片。但用户数据在父组件（`App.vue`）里——因为 App 要从服务器拿数据、要管理登录状态。

```vue
<!-- 父组件 App.vue -->
<script setup>
import { ref } from 'vue'
const userName = ref('张三')
</script>

<template>
  <!-- 我想让 UserCard 显示 "张三" —— 怎么传过去？ -->
  <UserCard />
</template>
```

答案就是 **Props**。

> **Props 是父组件传给子组件的"参数"**，就像函数调用时传的实参。你把它理解为**组件对外暴露的"接口"**就行。

## 💡 二、defineProps 基本语法

### 子组件：声明"我要接收什么"

子组件用 `defineProps` 声明自己需要哪些参数：

```
<!-- UserCard.vue -->
<script setup>
// 数组写法：声明要接收 name 和 role 两个 prop
const props = defineProps(['name', 'role'])
</script>

<template>
  <div class="card">
    <h2>{{ props.name }}</h2>
    <p>{{ props.role }}</p>
  </div>
</template>
```

> 💬 **老师备注**：`defineProps` 是**编译宏**——不需要 `import`，Vue 编译器会自动处理。你直接写就行。

在 `<template>` 里，props 可以直接用变量名访问，不需要写 `props.`：

```vue
<template>
  <div class="card">
    <!-- ✅ 模板里可以直接写 name，不用 props.name -->
    <h2>{{ name }}</h2>
    <p>{{ role }}</p>
  </div>
</template>
```

### 父组件：写属性传值

父组件在子组件标签上像写 HTML 属性一样传值：

```
<!-- App.vue -->
<script setup>
import UserCard from './components/UserCard.vue'
</script>

<template>
  <!-- 静态值：直接写字符串 -->
  <UserCard name="张三" role="前端工程师" />

  <!-- 动态值：加冒号 :，后面写 JS 表达式 -->
  <UserCard :name="user.name" :role="user.role" />
</template>
```

> 💬 **老师备注**：不加冒号 `name="张三"` 传的是**字符串字面量**"张三"；加了冒号 `:name="user.name"` 传的是**JS 表达式**的结果。这个区别很重要，第 4.2 节会展开讲。

## 🛠 三、完整可运行示例：消息卡片

```vue
<!-- MessageCard.vue —— 子组件 -->
<script setup>
// 声明要接收的 props
defineProps(['title', 'content', 'author'])
</script>

<template>
  <div class="message-card">
    <h3>{{ title }}</h3>
    <p class="content">{{ content }}</p>
    <span class="author">—— {{ author }}</span>
  </div>
</template>

<style scoped>
.message-card {
  border-left: 4px solid #42b883;
  padding: 16px 20px;
  margin: 12px 0;
  background: #f0fdf4;
  border-radius: 6px;
  max-width: 420px;
}
.message-card h3 {
  margin: 0 0 8px 0;
  font-size: 18px;
  color: #1a202c;
}
.content {
  margin: 0 0 8px 0;
  color: #4a5568;
  line-height: 1.6;
}
.author {
  color: #a0aec0;
  font-size: 13px;
}
</style>
```

```
<!-- App.vue —— 父组件 -->
<script setup>
import { ref } from 'vue'
import MessageCard from './components/MessageCard.vue'

const msg = ref({
  title: '关于期末考试的通知',
  content: '请各位同学于 7 月 10 日前提交课程设计报告，逾期不候。',
  author: '教务处'
})
</script>

<template>
  <!-- 静态传值 -->
  <MessageCard
    title="欢迎新同学"
    content="欢迎加入计算机科学与技术专业！"
    author="系主任"
  />

  <!-- 动态传值 -->
  <MessageCard
    :title="msg.title"
    :content="msg.content"
    :author="msg.author"
  />
</template>
```

运行效果：父组件渲染两张消息卡片，一张静态内容、一张动态内容。`MessageCard` 只负责"展示"，数据完全由父组件决定。

## ⚠️ 四、常见陷阱

### 陷阱 1：忘了加冒号，传的是字符串

```vue
<!-- ❌ 传的是字符串 "42"，不是数字 42 -->
<UserCard :age="42" />   <!-- ✅ 正确 -->
<UserCard age="42" />    <!-- ❌ 错误：传的是字符串 -->
```

### 陷阱 2：Props 名用 camelCase，模板里用 kebab-case

```
<!-- 子组件 -->
<script setup>
defineProps(['userName'])   // camelCase
</script>

<!-- 父组件 -->
<UserCard user-name="张三" />  <!-- ✅ kebab-case -->
<UserCard userName="张三" />   <!-- ❌ 不推荐 -->
```

Vue 官方推荐：**JS 里用 camelCase，模板里用 kebab-case**。

### 陷阱 3：子组件修改 Props（会报错）

```vue
<script setup>
const props = defineProps(['name'])
// ❌ 不要这样做！Props 是只读的
props.name = '李四'
</script>
```

这个在第 4.3 节会详细讲。

## 🧠 本节小结

- **组件是"孤岛"**：默认数据不互通，父组件有数据、子组件要用，就必须显式"传参"
- **Props 是组件对外的接口**：父组件在子组件标签上写属性，子组件用 `defineProps` 声明并接收
- **单向数据流**：数据只能父传子，子组件不能反向修改（改了会告警，长期造成数据来源混乱）
- **两种声明写法**：数组写法快速声明名字；对象写法还能声明类型、必填与默认值
- **类比记忆**：Props 就像组件的"函数参数列表"，父组件传什么、子组件就收到什么
