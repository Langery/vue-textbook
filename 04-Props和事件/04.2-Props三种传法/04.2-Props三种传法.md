刚会写 `defineProps`，你可能这样传值：`<Card name="张三" age="18" />`，结果页面把"18"当字符串用，判断永远出错——不加冒号时，Vue 一律按字符串处理，数字、布尔、对象全传不过去。本节把 Props 三种传法讲透：静态、动态和展开，看完你就知道什么时候该加冒号、什么时候能一次传一坨。

## 🤔 一、静态传值

**不加冒号**，直接写。传的一定是**字符串**。

```vue
<!-- 父组件 -->
<template>
  <!-- 三个 prop 全部传字符串 -->
  <UserCard
    name="张三"
    role="前端工程师"
    level="3"
  />
</template>
```

```
<!-- 子组件 -->
<script setup>
defineProps(['name', 'role', 'level'])
</script>

<template>
  <p>姓名：{{ name }}</p>
  <p>职位：{{ role }}</p>
  <!-- level 是字符串 "3"，不是数字 3！ -->
  <p>等级：{{ level }}</p>
</template>
```

> 💬 **老师备注**：`level="3"` 传到子组件是字符串 `"3"`，不是数字 `3`。如果你在子组件里做 `level + 1`，结果是 `"31"`（字符串拼接），不是 `4`。这是静态传值最容易踩的坑。

**什么时候用静态传值？** 文案、标题、固定的配置项——这些"写死了就不变"的东西。

---

## 💡 二、动态传值

**加冒号** `:`（`v-bind` 的简写），后面写 JS 表达式。可以传**任意 JS 类型**。

```vue
<script setup>
import { ref } from 'vue'

const user = ref({
  name: '张三',
  age: 20,
  isAdmin: false,
  hobbies: ['篮球', '编程'],
  address: { city: '广州', district: '天河' }
})
</script>

<template>
  <UserCard
    :name="user.name"              <!-- 字符串 -->
    :age="user.age"                <!-- 数字 -->
    :is-admin="user.isAdmin"       <!-- 布尔 -->
    :hobbies="user.hobbies"        <!-- 数组 -->
    :address="user.address"        <!-- 对象 -->
    :score="user.age > 18 ? 100 : 60"   <!-- 表达式也可以 -->
  />
</template>
```

**什么时候用动态传值？** 数据来自变量、需要计算、类型不是字符串——这些场景必须用 `:`。

### 布尔值的特殊写法

布尔类型 prop 有一个简写：**只写 prop 名不写值，默认传 `true`**。

```
<!-- 下面两种写法等价 -->
<UserCard :is-vip="true" />
<UserCard is-vip />     <!-- 简写：省略 = 号值，默认 true -->
```

## 💡 三、展开传值

如果一个对象的所有属性恰好就是子组件需要的所有 props，可以用 `v-bind` 一次性展开：

```vue
<script setup>
import { ref } from 'vue'

const product = ref({
  name: '机械键盘',
  price: 299,
  brand: 'Logitech',
  inStock: true
})
</script>

<template>
  <!-- 下面的写法等价于：
       :name="product.name"
       :price="product.price"
       :brand="product.brand"
       :in-stock="product.inStock" -->
  <ProductCard v-bind="product" />
</template>
```

> 💬 **老师备注**：`v-bind` 不带参数名时，会把对象的所有属性作为 props 传进去。这在 props 很多、且你的数据结构刚好匹配组件接口时非常好用——一行顶十行。

**注意**：对象的 key 名要和子组件的 prop 名一致（kebab-case 自动转换）。

三种传法各有各的用武之地，放在一起看更清楚：

| 对比维度 | 静态传值 | 动态传值 | 展开传值 |
|---|---|---|---|
| 写法 | `name="张三"` | `:name="user.name"` | `v-bind="product"` |
| 传的值 | 只能是字符串 | 任意 JS 类型（数字 / 布尔 / 对象 / 数组） | 对象的所有属性 |
| 适用场景 | 固定文案、常量配置 | 变量、计算、类型非字符串 | props 很多且数据结构匹配 |
| 灵活性 | 低 | 高 | 中（受对象结构约束） |
| 使用频率 | 偶尔 | 最常用 | 批量场景 |

## 🛠 四、完整可运行示例：三种方式一起上

```
<!-- ProductCard.vue -->
<script setup>
defineProps(['name', 'price', 'brand', 'inStock'])
</script>

<template>
  <div class="product-card" :class="{ 'out-of-stock': !inStock }">
    <h3>{{ name }}</h3>
    <p class="price">¥{{ price }}</p>
    <p class="brand">{{ brand }}</p>
    <span class="stock">{{ inStock ? '有货' : '缺货' }}</span>
  </div>
</template>

<style scoped>
.product-card {
  border: 1px solid #e2e8f0;
  padding: 16px;
  border-radius: 8px;
  width: 220px;
}
.out-of-stock {
  opacity: 0.6;
}
.price {
  color: #e53e3e;
  font-size: 20px;
  font-weight: 700;
  margin: 8px 0;
}
.brand {
  color: #718096;
  font-size: 13px;
}
.stock {
  display: inline-block;
  padding: 2px 8px;
  border-radius: 4px;
  background: #c6f6d5;
  color: #276749;
  font-size: 12px;
}
.out-of-stock .stock {
  background: #fed7d7;
  color: #9b2c2c;
}
</style>
```

```vue
<!-- App.vue -->
<script setup>
import { ref } from 'vue'
import ProductCard from './components/ProductCard.vue'

const products = ref([
  { name: '机械键盘', price: 299, brand: 'Logitech', inStock: true },
  { name: '鼠标垫', price: 29, brand: 'Razer', inStock: false },
  { name: '显示器', price: 1499, brand: 'Dell', inStock: true }
])
</script>

<template>
  <div class="product-list">
    <!-- 静态传值：固定的热销标签 -->
    <ProductCard name="热销款" price="99" brand="官方自营" in-stock />

    <!-- 展开传值：products 数组里每个对象展开为 props -->
    <ProductCard
      v-for="(item, index) in products"
      :key="index"
      v-bind="item"
    />
  </div>
</template>

<style scoped>
.product-list {
  display: flex;
  gap: 16px;
  flex-wrap: wrap;
}
</style>
```

运行效果：第一张卡片用静态传值展示固定内容，后面三张用 `v-bind` 展开对象批量渲染。注意 `v-bind` 展开时自动做了 camelCase → kebab-case 转换（`inStock` → `in-stock`）。

## ⚠️ 五、常见陷阱

### 陷阱 1：数字写成静态

```
<!-- ❌ price 传的是字符串 "99"，不是数字 99 -->
<ProductCard price="99" />

<!-- ✅ 正确：加冒号传数字 -->
<ProductCard :price="99" />
```

### 陷阱 2：对象/数组必须用动态传值

```vue
<!-- ❌ 报错：hobbies 被当成字符串 "[1,2,3]" -->
<UserCard hobbies="[1,2,3]" />

<!-- ✅ 正确 -->
<UserCard :hobbies="[1, 2, 3]" />
```

### 陷阱 3：展开传值时 prop 名对不上

```
<script setup>
// 子组件声明的是 camelCase
defineProps(['inStock'])
</script>

<!-- ✅ 父组件用 kebab-case，展开时自动转换 -->
<ProductCard v-bind="{ inStock: true }" />

<!-- ✅ 父组件直接写 kebab-case 也行 -->
<ProductCard v-bind="{ 'in-stock': true }" />
```

两种都能正确匹配，Vue 会自动处理。

## 🧠 本节小结

- **三种传法各有适用**：静态适合固定文案，动态适合变量/表达式（最常用），展开适合批量传一坨对象属性
- **静态传的是字符串**：`age="18"` 传过去一定是字符串，要传数字、布尔、对象必须加冒号
- **动态传任意 JS 类型**：`:count="5"`、`:visible="isShow"`、`:user="userObj"`，冒号后面就是表达式
- **展开传值**：`v-bind="obj"` 把对象所有属性一次性变成 props，和数据结构刚好对应时特别省事
- **注意陷阱**：布尔值写静态会传成字符串"true"；对象/数组不动态传只会得到 `[object Object]`
