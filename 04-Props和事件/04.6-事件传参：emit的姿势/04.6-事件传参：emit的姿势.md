## 🤔 一、emit 为什么要带参数？

4.5 节我们学会了 emit 的基本用法——子组件喊一声"事件发生了"，父组件听到后做点什么。

但光喊"发生了"不够，父组件还需要知道**发生了啥**：

```text
❌ 子组件：有人点赞了！（父组件：谁？哪个帖子？什么时间？）
✅ 子组件：有人给帖子 #42 点赞了，当前赞数 109
```

emit 可以带参数——就像打电话时，不光说"我有事"，还把具体内容说出来。

---

## 💡 二、emit 带参数的三种写法

### 子组件：emit 时传参

```vue
<!-- RateInput.vue —— 评分组件 -->
<script setup>
const emit = defineEmits(['change'])

function setRate(value) {
  // emit 第二个参数开始，全部传给父组件
  emit('change', value)
}
</script>

<template>
  <div class="rate">
    <button
      v-for="n in 5"
      :key="n"
      @click="setRate(n)"
    >
      {{ n }}⭐
    </button>
  </div>
</template>
```

### 父组件：三种接收方式

```
<script setup>
import { ref } from 'vue'
import RateInput from './components/RateInput.vue'

const score = ref(0)

// 方式 1：用 $event 接收（只有一个参数时最简洁）
</script>

<template>
  <!-- $event 就是 emit 传来的参数 -->
  <RateInput @change="score = $event" />

  <!-- 方式 2：用函数参数 -->
  <RateInput @change="(val) => score = val" />

  <!-- 方式 3：用方法名（Vue 自动传参） -->
  <RateInput @change="handleChange" />
</template>

<script setup>
// 方式 3 的方法定义
function handleChange(val) {
  score.value = val
}
</script>
```

> 💬 **老师备注**：方式 3 最常用——写一个方法名，Vue 自动把 emit 的参数传进去。如果 emit 传了多个参数，方法也会依次接收。

## 💡 三、emit 多参数

```vue
<!-- 子组件 -->
<script setup>
const emit = defineEmits(['update'])

function handleUpdate() {
  // 一次传三个参数
  emit('update', '张三', 20, 'admin')
}
</script>
```

```
<!-- 父组件 -->
<script setup>
function onUpdate(name, age, role) {
  // 依次接收：name='张三', age=20, role='admin'
  console.log(name, age, role)
}
</script>

<template>
  <ChildComponent @update="onUpdate" />
</template>
```

## 💡 四、defineEmits 对象语法（参数校验）

跟 Props 一样，emit 也可以用对象语法做类型校验：

```vue
<script setup>
const emit = defineEmits({
  // 不带参数的校验
  submit: null,

  // 带参数校验：校验函数返回 true 才通过
  change: (value) => {
    if (typeof value !== 'number' || value < 1 || value > 5) {
      console.warn('评分必须在 1-5 之间')
      return false
    }
    return true
  }
})

function setRate(value) {
  emit('change', value)   // value=10 会触发警告
}
</script>
```

> 💬 **老师备注**：对象语法在实际项目里用得不多，大部分团队用 TypeScript 做类型校验。但考试和面试可能会问到，了解一下就行。

## 🛠 五、完整可运行示例：Todo 列表

这个示例展示完整的 **Props 下 + Emit 上** 闭环。

```
<!-- TodoInput.vue —— 子组件：输入框 + 添加按钮 -->
<script setup>
import { ref } from 'vue'

const emit = defineEmits(['add'])

const text = ref('')

function handleAdd() {
  const trimmed = text.value.trim()
  if (!trimmed) return    // 空内容不添加
  emit('add', trimmed)    // 把输入内容传给父组件
  text.value = ''         // 清空输入框
}
</script>

<template>
  <div class="todo-input">
    <input
      v-model="text"
      @keyup.enter="handleAdd"
      placeholder="输入待办事项..."
      class="input"
    />
    <button @click="handleAdd" class="btn">添加</button>
  </div>
</template>

<style scoped>

}

```
<!-- App.vue —— 父组件 -->
<script setup>
import { ref } from 'vue'
import TodoInput from './components/TodoInput.vue'
import TodoItem from './components/TodoItem.vue'

const todos = ref([
  { id: 1, text: '完成 Vue 第 4 章作业', done: false },
  { id: 2, text: '复习组件化思想', done: true }
])

let nextId = 3

function handleAdd(text) {
  todos.value.push({ id: nextId++, text, done: false })
}

function handleToggle(index) {
  todos.value[index].done = !todos.value[index].done
}

function handleRemove(index) {
  todos.value.splice(index, 1)
}
</script>

<template>
  <div class="app">
    <h2>📋 我的待办</h2>
    <TodoInput @add="handleAdd" />

    <div class="list">
      <TodoItem
        v-for="(todo, index) in todos"
        :key="todo.id"
        :text="todo.text"
        :done="todo.done"
        @toggle="handleToggle(index)"
        @remove="handleRemove(index)"
      />
    </div>

    <p class="stats">
      共 {{ todos.length }} 项，
      {{ todos.filter(t => t.done).length }} 项已完成
    </p>
  </div>
</template>

## ⚠️ 六、常见陷阱

### 陷阱 1：父组件忘了接收参数

```vue
<!-- 子组件 emit('change', 5) -->

<!-- ❌ 处理方法没有参数，5 被丢弃了 -->
<RateInput @change="handleChange" />
function handleChange() { /* val 丢了 */ }

<!-- ✅ 正确 -->
function handleChange(val) { console.log(val) }
```

### 陷阱 2：emit 事件名用了内置事件名

```
<!-- ❌ 事件名 'click' 跟原生事件冲突 -->
defineEmits(['click'])

<!-- ✅ 用有意义的自定义名称 -->
defineEmits(['select', 'submit', 'delete'])
```

### 陷阱 3：用 $event 接收多参数

```vue
<!-- $event 只能拿到第一个参数 -->
<Child @change="handle($event)" />

<!-- ✅ 多参数用箭头函数 -->
<Child @change="(a, b, c) => handle(a, b, c)" />
```

## 🧠 本节小结

- **emit 可以带参**：`emit('事件名', 参数1, 参数2, ...)`，第一个参数是事件名，后面全传给父组件
- **父组件三种接收方式**：单参数推荐 `$event`，多参数推荐函数参数或箭头函数内联，别混着用
- **多参数传递**：子组件 `emit('change', newVal, oldVal, source)`，父组件用 `...args` 或函数多个形参接住
- **`defineEmits` 对象语法**：声明事件名 + 参数类型/校验函数，运行时帮你做类型检查
- **常见陷阱**：父组件忘了接收参数；事件名撞内置名；想用 `$event` 接多个参数（拿不全）
