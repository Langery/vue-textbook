---

学了 `v-if` 和 `v-for`，你是不是忍不住想：能不能写在一个元素上，一边遍历一边过滤？很多新手都会这么干，结果页面直接白屏，控制台还甩出一句 `Cannot read properties of undefined`。这其实不是手滑，而是 Vue 3 的优先级设计导致的一个经典禁忌。上一节我们刚弄懂 key，这一节就来聊聊 `v-if` 和 `v-for` 为什么不能"同框"，以及正确的三种替代写法。

---

## 🤔 一、为什么不能放一起？

在 2.5 节陷阱里提过这个，现在我们深挖一下。

```vue
<!-- ❌ 绝对禁止 -->
<li v-for="item in list" v-if="item.active" :key="item.id">
  {{ item.name }}
</li>
```

Vue 3 中，`v-if` 的优先级高于 `v-for`。也就是说 Vue 会**先尝试执行 `v-if`**。但此时 `v-for` 还没跑，变量 `item` 压根不存在，结果：

```
Uncaught TypeError: Cannot read properties of undefined
```

直接报错，页面白屏。这不是"不推荐"，是**不能用**。

> 💬 **老师备注**：Vue 2 和 Vue 3 在这个行为上有差异——Vue 2 中 `v-for` 优先级更高，所以上面那种写法在 Vue 2 不报错（但不推荐）。本书是 Vue 3 教材，请记住：**在 Vue 3 里，这两个指令绝不同行**。

---

## 💡 二、三种正确方案

假设我们要做一个小功能：展示学生列表，但只显示"已激活"的学生。

### 方案一：`computed` 过滤（最推荐）

**核心思想**：模板只负责"画"，数据逻辑在 script 里搞定。

```
<script setup>
import { ref, computed } from 'vue'

const students = ref([
  { id: 1, name: '张三', active: true },
  { id: 2, name: '李四', active: false },
  { id: 3, name: '王五', active: true },
  { id: 4, name: '赵六', active: false },
])

// ✅ 用 computed 产生过滤后的新数组
const activeStudents = computed(() =>
  students.value.filter(s => s.active)
)
</script>

<template>
  <ul>
    <li v-for="s in activeStudents" :key="s.id">
      {{ s.name }}
    </li>
  </ul>
</template>
```

**优点**：
- 模板干净，一看就懂
- `computed` 自动缓存（数据不变不重算）
- 方便复用（其他地方也能用 `activeStudents`）

### 方案二：外层 `<template v-if>` + 内层 `v-for`

**适用场景**：控制"整个列表要不要显示"。

```vue
<template>
  <!-- ✅ 列表不为空才显示 -->
  <template v-if="students.length > 0">
    <ul>
      <li v-for="s in students" :key="s.id">{{ s.name }}</li>
    </ul>
  </template>
  <p v-else>暂无数据</p>
</template>
```

这种写法不涉及过滤，只是控制整个列表区域的显隐。

### 方案三：内部元素用 `v-if`

**适用场景**：列表每条都渲染，但每条内部根据条件显示不同内容。

```
<template>
  <ul>
    <li v-for="s in students" :key="s.id">
      {{ s.name }}
      <span v-if="s.active" class="badge--active">● 已激活</span>
      <span v-else class="badge--inactive">● 未激活</span>
    </li>
  </ul>
</template>
```

这里 `v-for` 和 `v-if` **不在同一个元素上**——`v-if` 在 `<span>` 上，完全没问题。

## 🛠 三、完整可运行示例：带搜索 + 过滤的学生表

```vue
<script setup>
import { ref, computed } from 'vue'

const students = ref([
  { id: 1, name: '张三', grade: '2023级', score: 92 },
  { id: 2, name: '李四', grade: '2024级', score: 78 },
  { id: 3, name: '王五', grade: '2023级', score: 85 },
  { id: 4, name: '赵六', grade: '2024级', score: 45 },
  { id: 5, name: '孙七', grade: '2023级', score: 66 },
])

const keyword = ref('')
const onlyPassed = ref(false)
const selectedGrade = ref('')

// 筛选项
const grades = computed(() =>
  [...new Set(students.value.map(s => s.grade))]
)

// 核心：computed 组合过滤
const filteredStudents = computed(() => {
  let result = students.value

  // 搜索
  if (keyword.value.trim()) {
    result = result.filter(s =>
      s.name.includes(keyword.value.trim())
    )
  }

  // 年级筛选
  if (selectedGrade.value) {
    result = result.filter(s => s.grade === selectedGrade.value)
  }

  // 及格线
  if (onlyPassed.value) {
    result = result.filter(s => s.score >= 60)
  }

  return result
})
</script>

<template>
  <h2>📋 学生列表</h2>

  <!-- 筛选栏 -->
  <div class="filters">
    <input v-model="keyword" placeholder="搜索姓名..." />
    <select v-model="selectedGrade">
      <option value="">全部年级</option>
      <option v-for="g in grades" :key="g" :value="g">{{ g }}</option>
    </select>
    <label>
      <input type="checkbox" v-model="onlyPassed" />
      只看及格
    </label>
  </div>

  <!-- 列表 -->
  <template v-if="filteredStudents.length > 0">
    <table border="1" cellpadding="6" cellspacing="0">
      <thead>
        <tr><th>姓名</th><th>年级</th><th>成绩</th><th>状态</th></tr>
      </thead>
      <tbody>
        <tr v-for="s in filteredStudents" :key="s.id">
          <td>{{ s.name }}</td>
          <td>{{ s.grade }}</td>
          <td>{{ s.score }}</td>
          <td>
            <span v-if="s.score >= 90" style="color: green">🏆 优秀</span>
            <span v-else-if="s.score >= 60">✅ 及格</span>
            <span v-else style="color: red">❌ 不及格</span>
          </td>
        </tr>
      </tbody>
    </table>
  </template>
  <p v-else>没有匹配的学生</p>
</template>
```

这个例子把三种正确方案全用上了：
- `filteredStudents` — **方案一**（computed 过滤）
- `<template v-if="filteredStudents.length">` — **方案二**（列表显隐）
- `<span v-if="s.score >= 90">` — **方案三**（每条内部条件）

## 🆚 四、三选一决策

| 你的需求 | 用哪种方案 |
|---|---|
| 从数组中筛掉一部分数据 | 方案一：`computed` 过滤 |
| 根据条件决定整个列表显不显示 | 方案二：`<template v-if>` |
| 每条显示不同的子内容 | 方案三：内部 `v-if` |

## ⚠️ 五、常见误区

```
<!-- ❌ 误区：想隐藏列表中的某些行，直接在 v-for 上加 v-if -->
<tr v-for="item in list" v-if="item.visible">  <!-- 崩了 -->
```

```vue
<!-- ❌ 误区：想筛数据却在模板里用 v-for + v-show -->
<li v-for="item in list" v-show="item.active">  <!-- 能跑，但浪费 -->
```

`v-show` 只是隐藏，DOM 还在，1000 条数据只显示 5 条，其余 995 个空 DOM 白白占着内存。**筛数据请用 computed，别偷懒**。

---

## 🧠 本节小结

- **禁忌**：`v-if` 和 `v-for` 写在同一元素上，Vue 3 中 `v-if` 优先，会因变量未定义报错
- **方案一（最推荐）**：用 `computed` 先把数据过滤好，模板只负责渲染
- **方案二**：`<template v-if>` 包住整段 `v-for`，控制"整个列表显不显示"
- **方案三**：`v-for` 外层 + 内部元素写 `v-if`，控制"每条内部显不显示"
- **选型口诀**：筛数据 → computed；整块显隐 → template v-if；单条条件 → 内部 v-if
