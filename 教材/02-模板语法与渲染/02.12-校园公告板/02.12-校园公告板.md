# 2.12 章末实战：校园公告板（P2）

> 章节：第 2 章 模板语法与渲染

一整章的语法学下来，插值、`v-if`、`v-for`、`key`、`v-memo` 都有了，但都是"点状"的。这一节我们干一件正经事：把它们拼成一个**能跑、能展示**的小应用——「校园公告板」，模拟校园二手集市首页的闲置列表。

## 🎯 项目需求（一句话）

做一个"校园二手闲置公告板"单页应用：页面展示若干条学生发布的闲置物品（教材、电动车、吉他……），顶部可切换分类，进入时有加载态、列表为空时有空态——全部只用第 2 章已学的模板语法实现，不引入任何新库。

### ✅ 验收标准（能跑、能展示）

- [ ] 项目能 `npm run dev` 启动，浏览器打开能看到页面（数据写在本地，不依赖后端）
- [ ] 默认展示全部闲置：每条含 emoji 占位封面、标题、价格、发布人、分类徽章
- [ ] 顶部有「全部 / 数码 / 学习资料 / 生活用品」筛选按钮，点击后列表实时切换
- [ ] 首次进入先看到"加载中"状态，约 1 秒后切换到列表（`v-if` 切换两个分支）
- [ ] 把源数据改成空数组时，页面显示"还没有人发布闲置"空态，而不是一片空白
- [ ] 能向同学讲清楚：这个列表用到了哪几个指令、`key` 为什么这么选

## 🛠 分步提示（3~5 步，含关键代码锚点）

> 以下只给路线和关键锚点，**不贴全量答案**。卡住时回头翻 2.5 / 2.6 / 2.8 对应小节。

### Step 1：搭一个干净的页面

新建项目（或复用 01 章 P1 名片的 Vite 工程），把默认的计数器模板和样式清掉：

```bash
npm create vite@latest bulletin-board -- --template vue
cd bulletin-board && npm install && npm run dev
```

### Step 2：把"闲置数据"定义在 `<script setup>` 里

准备 6~8 条本地数据，字段固定为 `id / title / price / owner / category`，再准备分类数组和当前选中分类：

```js
const goods = ref([
  { id: 1, title: '九成新《高等数学》上下册', price: 15, owner: '计算机-小林', category: '学习资料' },
  // …… 自己再补 5~7 条：耳机、电动车、吉他、篮球……
])
const categories = ['全部', '数码', '学习资料', '生活用品']
const activeCategory = ref('全部')
const loading = ref(true)   // 初始为加载中
```

### Step 3：用 `computed` 做筛选（回顾 2.8 方案一）

`v-for` 不要直接遍历 `goods`，而是遍历一个"筛选后的数组"，这样切分类时模板不用改：

```js
const filteredGoods = computed(() =>
  activeCategory.value === '全部'
    ? goods.value
    : goods.value.filter((item) => item.category === activeCategory.value)
)
```

### Step 4：模板里写"加载中 / 空态 / 列表"三分支

分类按钮用 `v-for` 渲染并高亮当前项；列表主体用 `v-if / v-else-if / v-else` 三兄弟分工（回顾 2.5、2.6、2.8）：

```html
<p v-if="loading">⏳ 正在加载闲置列表…</p>
<p v-else-if="filteredGoods.length === 0">🌱 还没有人发布闲置，快来抢沙发</p>
<ul v-else>
  <li v-for="item in filteredGoods" :key="item.id">
    <!-- 标题 / 价格 / 发布人 / 分类徽章 -->
  </li>
</ul>
```

"加载中"不要一直手动改：在 `<script setup>` 顶层加一行 `setTimeout(() => (loading.value = false), 1000)` 模拟网络请求；选中分类时也可以顺手把 `loading` 置回 `true` 再切回来，感受"加载态 + 列表态"的真实切换。

### Step 5（进阶锚点）：给大列表加 `v-memo`（回顾 2.9）

把 `goods` 复制成 500 条后，在 `v-for` 的 `<li>` 上加 `v-memo="[item.sold]"`——只有 `sold` 变化的行才重新渲染，其余行跳过 diff：

```html
<li v-for="item in filteredGoods" :key="item.id" v-memo="[item.sold]">
```

## 🚀 延伸挑战（1~2 个加分项）

1. **"只看在售"开关**：加一个 `v-show` 的复选框，勾选后列表只显示 `sold === false` 的闲置（体会 `v-if` 与 `v-show` 的适用差异，回顾 2.5 末尾）。
2. **按价格排序**：在筛选按钮旁加「价格 ↑ / 价格 ↓」切换，用 `computed` 里 `[...filteredGoods].sort(...)` 实现，注意不要直接改原数组。
