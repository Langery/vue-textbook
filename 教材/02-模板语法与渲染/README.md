## 🤔 为什么学这章

本章是 Vue 3 的**模板语法基础**。从"模板到底是个啥"出发，带你掌握插值、指令、条件渲染（v-if）、列表渲染（v-for）、key 的作用与最佳实践、列表与条件的组合用法，以及 v-memo 渲染加速。原书第 7 章"条件列表与 key"的内容已并入本章，成为 2.5~2.9 节。

> 🧑 **小白**：页面用 HTML 写不就行了？为什么还要学一套"模板语法"？

> 🤖 **Vue 君**：HTML 是"死"的——写死什么就显示什么。我能让页面"活"起来：数据一变，界面自动跟着变。

> 👨🏫 **老湿**：这一章你会第一次尝到"数据驱动视图"的甜头。先把插值、指令、v-if、v-for 这几板斧练熟，后面组件化全靠它们。

## 🛠 本章实战

1. 把一份写死的 HTML 名片改成"数据驱动"版本：用 `{{ }}` 插值 + `v-bind` 绑定属性
2. 用 `v-if` / `v-else-if` / `v-else` 写一个"按分数显示等级"的小页面
3. 用 `v-for` 渲染商品列表，分别用 index 和唯一 id 做 key，在列表中间插入一条，观察输入框内容是否错位
4. 用 `computed` 完成"列表 + 条件组合"，并与"template + v-if"、"元素上同时写 v-if/v-for"三种写法对比
5. 用 `v-memo` 缓存长列表中的行，对比优化前后的渲染表现

## ⚠️ 学习提示

- **2.1-2.4 是地基**：模板三大规矩（单根、合法表达式、驼峰命名）必须背熟。
- **2.5-2.6 是核心**：v-if 和 v-for 是日常开发出现频率最高的两个指令，多写多练。
- **2.7 是重点节**：key 的原理与最佳实践，面试高频考点。先看 Bug 案例，再理解 Diff，最后记住选值优先级。
- **2.8 的三种方案**：列表 + 条件组合是 Vue 3 的经典考点，建议把三种正确方案都敲一遍。
- **2.9 是进阶**：v-memo 是性能优化利器，理解依赖数组的判定逻辑即可，不必死记语法。
- 不要跳读，尤其是 2.5 和 2.7——条件渲染和 key 的坑，后面所有章节都会用到。

**常见坑自查**：

| 坑 | 说明 |
|---|---|
| `{{ }}` 里写语句 | 只能写表达式，`if` / `return` 等语句直接报错 |
| 列表用 index 做 key | 中间增删时内容错位、输入框状态串位 |
| v-if 和 v-for 同元素 | Vue 3 中 v-if 优先级更高，容易踩未定义变量 |
| v-else 不紧跟 v-if | 中间插入其他元素会导致不生效 |
| 依赖项过多用 v-memo | 比较成本大于跳过收益，反而变慢 |

## 📖 本章术语表

下表收录本章 2.1~2.10 正文实际讲到的核心术语，按首次出现的节号排序，方便随时回查。

| 术语 | 一句话解释 | 首现节号 |
|---|---|---|
| 模板（Template） | 用「HTML 标签 + Vue 插值/指令」写成的页面结构，浏览器不认，Vue 会先编译再渲染成真实页面。 | 2.1 |
| 虚拟 DOM（VNode） | Vue 内部用一个 JS 对象描述「页面应该长啥样」，更新时先比这些对象，再决定怎么改真实 DOM。 | 2.1 |
| 模板编译 / 渲染函数 | Vue 把你写的模板编译成 JS 渲染函数，执行这个函数才产出 VNode。 | 2.1 |
| 插值 `{{ }}`（Mustache 语法） | 把 JS 表达式的结果塞进 HTML 文本里，是模板里最基础的「显示数据」方式。 | 2.2 |
| 指令（Directive） | 模板里 `v-` 开头的特殊属性，用来给 HTML 加上条件、循环、绑定等逻辑。 | 2.2 |
| `v-text` / `v-html` | 用指令把数据放进元素：`v-text` 当纯文本（自动转义、安全），`v-html` 会按 HTML 解析（有 XSS 风险，只用于可信内容）。 | 2.2 |
| `v-bind`（简写 `:`） | 把 JS 表达式的结果绑定到 HTML 属性上，如 `:src="imageUrl"`。 | 2.2 |
| 模板表达式 | 写在 `{{ }}` 或指令值里的 JS 片段，只能写表达式，不能写 `if`/`return` 这类语句，也不能改状态。 | 2.2 |
| `computed`（计算属性） | 把模板里的复杂逻辑抽出来写成属性，模板更简洁，而且会缓存、重复读取不重复计算。 | 2.3 |
| 可选链 `?.` / 空值合并 `??` | 安全访问可能为空的属性（`user?.name`），为空时给默认值（`user?.name ?? '游客'`）。 | 2.3 |
| 单根元素 / Fragment | 组件模板默认只能有一个根标签，多根会报错；Vue 3 支持多根（Fragment），但多数场景仍建议包一层 `<div>`。 | 2.4 |
| 驼峰命名 / 短横线命名 | HTML 属性不区分大小写，所以 props、事件用驼峰（`:userName`、`@closeDialog`），模板标签也可写短横线（`:user-name`），两种 Vue 都认。 | 2.4 |
| `v-if`（条件渲染） | 条件为 false 时元素压根不渲染、不存在于 DOM 中，适合切换不频繁的场景。 | 2.5 |
| `v-show` | 元素始终留在 DOM 里，只切换 `display: none`，切换开销低，适合频繁开关（如标签页、弹窗）。 | 2.5 |
| `v-for`（列表渲染） | 按数组或对象循环生成一组元素，是渲染列表的标准写法。 | 2.6 |
| `:key` | 给每个循环节点一个唯一「身份证」，Vue 靠它追踪节点、正确移动而不是乱复用，必须加。 | 2.6 |
| Diff 算法 / 就地复用 | Diff 负责对比新旧 VNode 找出最小更新量；没有 key 时 Vue 只能按位置「就地复用」节点，容易让输入框里的内容串位。 | 2.7 |
| `v-memo` | Vue 3.2 的缓存指令：依赖数组里的值都没变，就复用上一次的 VNode、跳过 Diff，常用于长列表性能优化。 | 2.9 |
| Teleport | 把组件里的一段内容「传送」到 DOM 树的指定位置（比如 `<body>`），常用于弹窗、遮罩层。 | 2.10 |
| Suspense | 异步组件加载期间先显示占位内容（骨架屏），加载完成后再显示真正内容。 | 2.10 |
