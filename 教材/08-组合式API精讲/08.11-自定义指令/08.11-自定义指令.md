## 🤔 一、什么是自定义指令？

Vue 内置了 `v-model`、`v-if`、`v-for`、`v-show` 等指令。但实际开发中，你会遇到一些"重复的 DOM 操作"：

- 点击按钮复制一段文字到剪贴板 — `v-copy`
- 输入框一出现就自动聚焦 — `v-focus`
- 输入框加防抖处理 — `v-debounce`
- 根据用户权限显示/隐藏按钮 — `v-permission`

这些都可以用**组件**实现（包装一个 `<AutoFocusInput>`），但用**指令**更轻量：不需要额外的 DOM 节点，直接赋能现有元素。

> 💬 **老师备注**：判断用组件还是指令的口诀——"如果需要一段 HTML 模板和样式，用组件；如果只是给已有的 DOM 元素加点行为，用指令。"

## 💡 二、指令的生命周期

自定义指令有 7 个钩子，和组件生命周期对应：

```js
const myDirective = {
  created(el, binding, vnode)   { /* 指令绑定前 */ },
  beforeMount(el, binding, vnode) { /* 挂载前 */ },
  mounted(el, binding, vnode)   { /* 挂载后，最常用 */ },
  beforeUpdate(el, binding, vnode) { /* 更新前 */ },
  updated(el, binding, vnode)   { /* 更新后 */ },
  beforeUnmount(el, binding, vnode) { /* 卸载前 */ },
  unmounted(el, binding, vnode) { /* 卸载后，清理 */ }
}
```

**参数说明**：

| 参数 | 含义 |
|---|---|
| `el` | 指令绑定的 DOM 元素，直接可操作 |
| `binding` | 包含传参的对象：`binding.value`（值）、`binding.arg`（参数）、`binding.modifiers`（修饰符） |
| `vnode` | 虚拟节点（不常用） |

### 全局注册 vs 局部注册

```js
// main.js —— 全局注册
app.directive('focus', {
  mounted(el) { el.focus() }
})
```

```vue
<!-- 组件内 —— 局部注册 -->
<script setup>
// 以 v 开头的驼峰变量会自动映射为 v-xxx 指令
const vFocus = {
  mounted(el) { el.focus() }
}
</script>
```

## 🛠 三、实战一：v-copy（一键复制）

### 3.1 需求

点击按钮 → 把一段文本复制到剪贴板 → 短暂显示"已复制"提示。

### 3.2 实现

```js
// directives/vCopy.js
export const vCopy = {
  mounted(el, binding) {
    // binding.value 是要复制的文本
    const textToCopy = binding.value

    el.addEventListener('click', async () => {
      try {
        await navigator.clipboard.writeText(textToCopy)
        // 复制成功：改按钮文字提示
        const originalText = el.textContent
        el.textContent = '已复制！'
        el.classList.add('copied')
        setTimeout(() => {
          el.textContent = originalText
          el.classList.remove('copied')
        }, 1500)
      } catch {
        // 兜底方案：用传统方法
        const textarea = document.createElement('textarea')
        textarea.value = textToCopy
        textarea.style.position = 'fixed'
        textarea.style.opacity = '0'
        document.body.appendChild(textarea)
        textarea.select()
        document.execCommand('copy')
        document.body.removeChild(textarea)
        alert('已复制（兜底方案）')
      }
    })
  },

  // 如果 binding.value 变化，更新要复制的文本
  updated(el, binding) {
    el._copyText = binding.value
  }
}
```

### 3.3 使用

```
<script setup>
import { ref } from 'vue'
import { vCopy } from './directives/vCopy'

const couponCode = ref('SAVE50-OFF')
</script>

<template>
  <div>
    <p>优惠码：<code>{{ couponCode }}</code></p>
    <!-- v-copy 的值就是点击时要复制的内容 -->
    <button v-copy="couponCode">复制优惠码</button>

    <!-- 也可以直接传字符串 -->
    <button v-copy="'https://example.com/invite?code=ABC123'">
      复制邀请链接
    </button>
  </div>
</template>
```

## 🔑 四、实战二：v-focus（自动聚焦）

### 4.1 需求

输入框一出现就自动获取焦点。比每次在组件里写 `ref` + `onMounted(() => inputRef.value.focus())` 方便得多。

### 4.2 实现

```js
// directives/vFocus.js
export const vFocus = {
  mounted(el) {
    el.focus()
  }
}
```

只要一行！使用：

```vue
<template>
  <!-- 这个 input 一出现就自动聚焦 -->
  <input v-focus placeholder="我会自动获得焦点" />

  <!-- 条件渲染的元素也可以用 -->
  <input v-if="showSearch" v-focus placeholder="我也自动聚焦" />
</template>
```

## 🛡️ 五、实战三：v-debounce（防抖输入）

### 5.1 需求

有些场景下你不想用 composable 包一层，直接在模板里给 input 事件加防抖。

### 5.2 实现

```js
// directives/vDebounce.js
export const vDebounce = {
  mounted(el, binding) {
    // binding.value 是防抖延迟后的回调函数
    const delay = binding.arg ? Number(binding.arg) : 300

    let timer = null

    el.addEventListener('input', (e) => {
      clearTimeout(timer)
      timer = setTimeout(() => {
        binding.value(e)  // 延迟 delay 毫秒后调用回调
      }, delay)
    })
  }
}
```

### 5.3 使用

```
<script setup>
import { ref } from 'vue'
import { vDebounce } from './directives/vDebounce'

const keyword = ref('')

function handleSearch(e) {
  console.log('搜索（防抖后）：', e.target.value)
  // 发请求...
}
</script>

<template>
  <input
    v-model="keyword"
    v-debounce:500="handleSearch"
    placeholder="输入搜索关键词（500ms 防抖）"
  />
  <!-- v-debounce:500 —— :500 是 binding.arg，表示延迟 500ms -->
  <!-- handleSearch 是 binding.value，即防抖后执行的函数 -->
</template>
```

> 💬 **老师备注**：`v-debounce:500="handleSearch"` 中，`:500` 叫指令的**参数（arg）**，`handleSearch` 叫指令的**值（value）**。通过 `binding.arg` 和 `binding.value` 拿到。

### 5.4 进阶：带修饰符

```js
export const vDebounce = {
  mounted(el, binding) {
    const delay = binding.arg ? Number(binding.arg) : 300
    let timer = null

    // 支持 .keyup 修饰符：监听 keyup 而非 input
    const eventType = binding.modifiers.keyup ? 'keyup' : 'input'

    el.addEventListener(eventType, (e) => {
      clearTimeout(timer)
      timer = setTimeout(() => {
        binding.value(e)
      }, delay)
    })
  }
}
```

```vue
<!-- 按回车后才触发（用 keyup 事件） -->
<input v-debounce:500.keyup="handleSearch" />
```

## 🔄 六、简写形式

如果你的指令只在 `mounted` 和 `updated` 做同一件事，可以用简写：

```js
// 完整写法
const vFocus = {
  mounted(el) { el.focus() },
  updated(el) { el.focus() }
}

// 简写（函数形式）—— 等价于 mounted + updated 都执行
const vFocus = (el) => { el.focus() }
```

```
<script setup>
// 最简写法：一行搞定
const vFocus = (el) => el.focus()
const vHighlight = (el, binding) => {
  el.style.backgroundColor = binding.value || 'yellow'
}
</script>

<template>
  <input v-focus />
  <p v-highlight="'#ff0'">我会被高亮</p>
</template>
```

## ⚠️ 七、常见陷阱

### 陷阱 1：指令名和变量名映射

```vue
<script setup>
const vCopy = { ... }    // 模板里用 v-copy
const vMyDirective = { ... }  // 模板里用 v-my-directive
</script>
```

驼峰 → 短横线：`vCopy` → `v-copy`，`vMyDirective` → `v-my-directive`。

### 陷阱 2：在指令里忘了清理事件监听

```js
const vOutsideClick = {
  mounted(el, binding) {
    el._handler = (e) => {
      if (!el.contains(e.target)) binding.value()
    }
    document.addEventListener('click', el._handler)
  },
  unmounted(el) {
    // ✅ 一定要清理！
    document.removeEventListener('click', el._handler)
  }
}
```

### 陷阱 3：指令只操作 DOM，不做业务逻辑

指令是 DOM 层的工具。复杂的业务逻辑（网络请求、状态管理）应该放在组件或 composable 里，指令只负责"这个元素的行为"。

## 🧠 本节小结

- **用途**：自定义指令封装"作用于单个 DOM 元素"的复用行为（自动聚焦、点击外部关闭等）
- **注册方式**：本地 `directives: { vFocus }` / `<script setup>` 用 `vFocus` 命名约定；全局 `app.directive('focus', {...})`
- **指令钩子**：Vue 3 为 `created → beforeMount → mounted → updated → beforeUnmount → unmounted`，没有 Vue 2 的 `inserted`
- **简写形式**：只在 mounted + updated 重复触发时，可直接传一个函数
- **值/参数/修饰符**：`v-demo:arg.mod="value"`，binding 对象里取 `value`/`arg`/`modifiers`
- **职责边界**：指令只操作 DOM、不做业务逻辑；复杂逻辑放组件或 composable
