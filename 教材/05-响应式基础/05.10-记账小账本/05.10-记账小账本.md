# 5.10 章末实战：记账小账本（P5）

> 章节：第 5 章 响应式基础
> 课时：1 课时
> 类型：章末实战 · 独立小项目 P5

第五章把响应式讲透了：`ref` / `reactive` 存状态、不可变原则、更新对象/数组的正确姿势。这一节我们把它们变成**能记账、能算钱**的小应用——「记账小账本」。别小看它：大项目 Campus2Hand 的**购物车**（加购 / 数量 / 金额合计）就是这套"状态 + 计算"逻辑的放大版。先在记账本里把钱的加减算明白。

## 🎯 项目需求（一句话）

做一个"闲置交易记账本"：记录每笔"卖出 / 买入"流水（物品、金额、方向），能增删流水，并实时算出总收入、总支出、结余——全程只用第 5 章已学的 `ref` / `reactive`、计算属性、响应式更新姿势，不引入任何新库。

### ✅ 验收标准（能跑、能展示）

- [ ] 项目能 `npm run dev` 启动，页面能看到流水列表 + 汇总卡片（收入 / 支出 / 结余）
- [ ] 能新增一笔流水：填物品名、金额、选方向（卖出=收入 / 买入=支出），点提交后列表立刻出现
- [ ] 每笔流水可删除，删除后汇总数字同步变化
- [ ] 数据用 `reactive`（或 `ref`）管理，增删**遵循第 5 章教的更新姿势**（不做 `arr[i] = x` 之类失效操作）
- [ ] 汇总金额用计算属性推导，不手动维护"总金额"变量（改流水，汇总自动跟着变）
- [ ] 能向同学讲清：为什么"总金额"不该自己存一份，而要由列表计算出来？

## 🛠 分步提示（3~5 步，含关键代码锚点）

> 以下只给路线和关键锚点，**不贴全量答案**。卡住时回头翻 5.1 / 5.2 / 5.4 / 5.8 对应小节。

### Step 1：定义流水数据结构

```js
const records = ref([
  { id: 1, item: '九成新《高等数学》', amount: 15, direction: 'income' },
  { id: 2, item: '购入二手台灯', amount: 20, direction: 'expense' }
])
```

表单字段用 `reactive` 管理（回顾 5.2 对象/数组倾向 `reactive`；这里先用 `ref` 包对象也行，注意别混用踩坑）。

### Step 2：新增流水——先想"能不能原地 push"

新增用 `records.value.push({ id: nextId++, ... })` 即可触发更新（回顾 5.8：数组用 `push` 没问题）。**注意别** `records.value[i] = x` 这样按下标改已有项（回顾 5.4/5.8：会失效）；整体换新数组 `records.value = newArray` 在 `ref` 下能触发更新，但要手动拼新数组，不如 `splice` 直观，这里统一用会改原数组的方法。

```js
function addRecord() {
  if (!form.item.trim() || !(form.amount > 0)) return
  records.value.push({
    id: ++nextId,
    item: form.item.trim(),
    amount: Number(form.amount),
    direction: form.direction
  })
  form.item = ''
  form.amount = ''
}
```

### Step 3：用计算属性推导汇总（回顾 2.8 方案一）

总金额不手动存，全部由列表推导：

```js
const totalIncome = computed(() =>
  records.value.filter((r) => r.direction === 'income').reduce((s, r) => s + r.amount, 0)
)
const totalExpense = computed(() =>
  records.value.filter((r) => r.direction === 'expense').reduce((s, r) => s + r.amount, 0)
)
const balance = computed(() => totalIncome.value - totalExpense.value)
```

> 锚点检查：在计算属性里只依赖 `records`，删/加流水后汇总自动变——这就是"状态单一来源"的甜头。

### Step 4：删除流水——按 id 过滤出新数组

删除用"过滤出新数组再整体赋值"还是 `splice`？两种都要注意响应式（回顾 5.8）。推荐 `splice` 原地改：

```js
function removeRecord(id) {
  const idx = records.value.findIndex((r) => r.id === id)
  if (idx > -1) records.value.splice(idx, 1)
}
```

### Step 5：给界面加一点"账本感"

用 `v-for` 渲染流水列表，每条显示物品名 / 方向徽章（收入绿 / 支出红）/ 金额 / 删除按钮；顶部放三张汇总卡片。思考题：为什么把"收支统计"做成计算属性而不是在 `addRecord` 里手动 `total += amount`？
