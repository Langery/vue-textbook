## 🎯 本章目标

学完这章，你将能够：

- ✅ 理解 Vue 组件的**生命周期**（创建/挂载/更新/卸载）

- ✅ 用 **`watch`** 精准监听特定数据

## 🤔 为什么学这章

**数据有了，但怎么"对数据变化做反应"？**——比如：
- `count` 变了，要**请求接口**
- `userId` 变了，要**重置表单**
- 组件**卸载了，要清掉定时器**

本章教"副作用管理"——Vue 应用里 80% 的"业务逻辑"都在这一章。

> 🧑 **小白**：数据变了页面会自动更新，可我想在数据变化时"多做点事"——比如重新请求接口，该怎么办？

> 🤖 **Vue 君**：交给我 `watch` 和 `watchEffect`！你告诉我"盯谁、做什么"，剩下的依赖追踪我全包。

> 👨🏫 **老湿**：请求接口、重置表单、清理定时器……Vue 应用里 80% 的业务逻辑都在这章，认真学。

## ⚠️ 学习提示

- **不要**把"任何"逻辑都放进 `watchEffect`——**事件处理**用 `@click`，**计算**用 `computed`，只有"数据变化要做额外的事"才用 watch
- **清理函数** 一定要写——尤其是定时器、事件订阅、AbortController
- **`watch` 的 deep 选项** 默认是 false，对象/数组要写 `deep: true`

## 📖 本章术语表

下表收录本章 6.1~6.10 正文实际讲到的核心术语，按首次出现的节号排序，方便随时回查。

| 术语 | 一句话解释 | 首现节号 |
|---|---|---|
| `生命周期` | 组件从创建、挂载、更新到卸载所经历的一系列阶段，各阶段可挂载对应回调。 | 6.1 |
| `生命周期钩子` | 在组件生命周期各阶段自动执行的回调函数，如 onMounted、onUnmounted 等。 | 6.1 |
| `onMounted` | 组件挂载到 DOM 后触发的钩子，适合发请求、初始化图表、获取模板引用。 | 6.1 |
| `onUnmounted` | 组件卸载后触发的钩子，用来清理定时器、事件监听、网络连接等资源。 | 6.1 |
| `副作用` | 响应式数据变化后执行的额外操作，如发请求、写存储、操作 DOM 等外部影响。 | 6.2 |
| `纯函数` | 只依赖入参、不产生副作用、相同输入必得相同输出的函数。 | 6.2 |
| `onUpdated` | DOM 更新后触发的钩子，容易引发无限循环，多数场景用 watch 或 nextTick 替代。 | 6.3 |
| `模板引用` | 用 ref 绑定 DOM 元素或子组件实例，组件挂载后才能通过 el.value 访问。 | 6.3 |
| `nextTick` | 等待 DOM 更新完成后执行回调的一次性工具，避免手动依赖 onUpdated。 | 6.3 |
| `watchEffect` | 自动追踪回调内读到的响应式依赖，任一变化即重新执行，创建时立即跑一次。 | 6.4 |
| `flush` | watchEffect 的执行时机选项，可选 pre、post、sync 控制回调在渲染前后何时运行。 | 6.4 |
| `watch` | 明确指定监听源并回调拿到新旧值的侦听 API，支持 ref、reactive、getter 与数组。 | 6.5 |
| `getter 函数` | 作为 watch 监听源的返回表达式的函数，可精准监听对象某字段或计算结果。 | 6.5 |
| `deep` | watch 的深度监听选项，可感知对象/数组内部属性变化，但大对象上有性能开销。 | 6.5 |
| `immediate` | watch 选项，设置为 true 时创建监听即立即执行一次回调，常用于初始化。 | 6.5 |
| `onWatcherCleanup` | Vue 3.5+ 在 watch/watchEffect 回调中注册清理函数的 API，触发前先执行旧清理。 | 6.6 |
| `竞态条件` | 快速操作导致旧请求晚到、覆盖新结果的并发问题，常用 AbortController 取消旧请求。 | 6.6 |
| `AbortController` | 浏览器取消异步请求的 API，abort() 中断进行中的 fetch，配合清理函数防竞态。 | 6.6 |
| `内存泄漏` | 定时器、订阅等资源未清理导致内存持续占用、页面变卡的问题。 | 6.6 |
| `反模式` | 看似能用、长期必坑的写法，如 watch 里只做赋值、忘 deep、不清副作用等。 | 6.8 |
