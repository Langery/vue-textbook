## 📊 参考答案

### 选择题
1. C  2. C  3. C  4. B  5. C  6. B  7. **B**

> **第 5 题**：C `onWatcherCleanup`（3.5+）。D `onScopeDispose` 是第 7 章 `effectScope` 的 API，不属于本章范围。
> **第 7 题**：B。`'pre'`（默认）在 DOM 更新前跑，`'post'` 在之后跑——所以"DOM 更新后再操作元素"要用 `'post'`。

### 代码题

**13. 代码补全**：

```javascript
import { ref, watch, onWatcherCleanup } from 'vue'

watch(keyword, (newVal) => {
  const timer = setTimeout(() => {
    result.value = `搜索「${newVal}」的结果`
  }, 500)

  onWatcherCleanup(() => {
    clearTimeout(timer)
  })
})
```

**14. 实战题参考**：

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const seconds = ref(0)
let timer = null

onMounted(() => {
  timer = setInterval(() => {
    seconds.value++
  }, 1000)
})

onUnmounted(() => {
  clearInterval(timer)
  console.log(`用户停留了 ${seconds.value} 秒`)
})
</script>

<template>
  <p>已停留：{{ seconds }} 秒</p>
</template>
```

**15. 分析题参考**：

问题 1：**竞态条件**——用户快速点击，旧请求可能覆盖新请求。
问题 2：**没有清理**——组件卸载时请求可能还在进行。

修复：

```vue
<script setup>
import { ref, watch, onWatcherCleanup } from 'vue'

const userId = ref(1)
const userData = ref(null)
const loading = ref(false)

watch(userId, async (newId) => {
  loading.value = true
  const controller = new AbortController()

  onWatcherCleanup(() => {
    controller.abort()
  })

  try {
    const res = await fetch(`/api/user/${newId}`, {
      signal: controller.signal
    })
    userData.value = await res.json()
  } catch (err) {
    if (err.name !== 'AbortError') {
      console.error(err)
    }
  } finally {
    loading.value = false
  }
})
</script>
```
