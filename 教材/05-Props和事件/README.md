# 第 5 章 Props 和事件

> 课时：5.5 课时
> 难度：⭐⭐（进阶）

---

## 🎯 本章目标

学完这章，你将能够：

- ✅ 用 **Props** 实现父组件 → 子组件传值
- ✅ 用 **`$emit`** 实现子组件 → 父组件传值
- ✅ 理解 Props 的**只读性原则**（不能直接改 props）
- ✅ 掌握 **`v-model`** 在组件上的双向绑定
- ✅ 区分**受控 vs 非受控**组件的使用场景
- ✅ 了解父子组件通信的 4 种方式

---

## 🤔 为什么学这章

**前面学的组件都是"孤岛"**——一个组件自己玩。第 4 章学了怎么拆组件，但**没学怎么让组件之间交流**。

本章教**父子组件通信**——这是组件化的"血液循环"。学完这章，你才能把"拆开的组件"重新"组装"成一个完整应用。

> 🧑 **小白**：第 4 章学会了拆组件，可拆完的组件各玩各的，怎么让它们互相传话？

> 🤖 **Vue 君**：我是有"家族血缘"的——父组件通过 Props 把数据"交代"给子组件，子组件通过 `$emit` 向父组件"汇报"。

> 👨🏫 **老湿**：父子通信是组件化的"血液循环"。这章学完，拆开的组件就能重新组装成完整应用了。

## ⚠️ 学习提示

- **不要试图**直接修改 Props——会被警告，而且违反单向数据流
- **`v-model` 不是魔法**——本质是"Prop down + Event up"的语法糖
- **父子通信不只 Props/Emit**——还有 `provide/inject`（8 章）和 Pinia（11 章），但本章先掌握基础

## 📖 本章术语表

下表收录本章 5.1~5.9 正文实际讲到的核心术语，按首次出现的节号排序，方便随时回查。

| 术语 | 一句话解释 | 首现节号 |
|---|---|---|
| `Props` | 父组件向子组件传数据的自定义属性，子组件通过 defineProps 声明接收，形成自上而下的数据通道。 | 5.1 |
| `defineProps` | 组合式 API 中声明组件 Props 的编译宏，可定义属性名、类型与默认值，模板中可直接使用。 | 5.1 |
| `编译宏` | 以 define 开头、无需 import 即可直接使用的编译器特殊函数，如 defineProps、defineEmits。 | 5.1 |
| `单向数据流` | 数据只能从父组件流向子组件的约束，子组件不可直接修改 Props，保证数据来源唯一、可预测。 | 5.1 |
| `静态传值` | 用字符串字面量直接给 Props 传固定值的写法，适用于不依赖状态的常量数据。 | 5.2 |
| `动态传值` | 用 v-bind 把变量、表达式或响应式数据绑定给 Props 的传值方式，值可随状态变化更新。 | 5.2 |
| `v-bind` | Vue 动态绑定指令，可把表达式、变量或事件参数绑定到 HTML 属性或组件 Props 上。 | 5.2 |
| `透传属性` | 组件未声明为 Props 的属性会自动传递给根元素，常见于 class、style 等原生属性。 | 5.2 |
| `Props 只读` | Props 是只读数据，子组件修改会触发警告，正确做法是通过 emit 通知父组件修改。 | 5.3 |
| `本地副本` | 把 Props 值复制到组件本地 ref 再修改的写法，避免直接改 Props，适用于需临时编辑的场景。 | 5.3 |
| `解构 Props` | 直接从 props 对象解构属性值的写法，配合响应式解构可在模板和逻辑中便捷使用。 | 5.4 |
| `toRefs` | 把 reactive 对象的所有属性转为独立 ref 的工具函数，解构后仍保持响应式。 | 5.4 |
| `validator` | defineProps 对象语法中自定义校验函数，返回 false 时 Vue 会给出值不符合预期的警告。 | 5.4 |
| `emit` | 子组件向父组件触发自定义事件的机制，携带参数实现自下而上的通信。 | 5.5 |
| `defineEmits` | 组合式 API 声明组件可触发事件的编译宏，可定义事件名、参数与校验规则。 | 5.5 |
| `$event` | 模板事件处理中的特殊变量，表示事件对象或 emit 携带过来的参数，用于内联语句取值。 | 5.6 |
| `v-model` | 双向绑定语法糖，本质是 modelValue Prop 加 update:modelValue 事件的组合。 | 5.7 |
| `modelValue` | v-model 默认对应的 Prop 名，组件内通过它接收父组件绑定的值。 | 5.7 |
| `update:modelValue` | v-model 对应的事件名，组件内触发它并携带新值，通知父组件更新数据。 | 5.7 |
| `defineModel` | Vue 3.4+ 简化 v-model 实现的编译宏，自动生成 modelValue 与更新事件，减少样板代码。 | 5.7 |
