## 🛠 实操题（每题 25 分，共 50 分）

### 实操题 1：Tab 切换组件（25 分）

**要求**：

1. 创建 `TabBar.vue` 组件：
   - 接收 `tabs` prop（数组，如 `['首页', '消息', '我的']`）
   - 接收 `activeIndex` prop（当前激活的索引，默认 0）
   - 点击某个 tab 时 emit `change` 事件并传出索引
   - 激活的 tab 用高亮样式显示

2. 在 `App.vue` 中使用：
   - 传入 3 个 tab 名称
   - 根据激活索引展示不同的内容区域

**评分标准**：
- Props 定义正确（类型 + 默认值）：5 分
- Emit 事件正确触发并传参：5 分
- 样式实现（高亮 vs 非高亮）：5 分
- 父组件使用正确（:tabs + :active-index + @change）：5 分
- 代码可运行、结构清晰：5 分

### 实操题 2：带 v-model 的搜索表单（25 分）

**要求**：

1. 创建 `SearchForm.vue` 组件，支持三个 `v-model`：
   - `v-model:keyword` —— 搜索关键词
   - `v-model:category` —— 分类（下拉选择：`全部 / 前端 / 后端 / 设计`）
   - `v-model:onlyStock` —— 只看有货（复选框，布尔值）

2. 组件内有一个「搜索」按钮，点击时 emit `search` 事件。

3. 在 `App.vue` 中使用：
   - 绑定三个 v-model
   - 监听 `@search` 事件并打印当前搜索条件

**评分标准**：
- 三个 v-model 定义正确（用 defineModel 或传统方式均可）：10 分
- 下拉框和复选框实现正确：5 分
- 「搜索」按钮 emit 事件正确：5 分

## 📊 参考答案

### 选择题答案

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | **C** | Props 只能父传子，子传父用 Emit |
| 2 | **B** | 数字必须用 `:` 动态绑定，否则传的是字符串 |
| 3 | **A、B、C** | D 错误：`defineProps` 是编译宏，不需要 import |
| 4 | **D** | 箭头函数和普通函数都可以，关键在于必须是工厂函数 |
| 5 | **B** | `defineEmits` 接收数组，不能直接传多个字符串参数 |
| 6 | **D** | 组合式 API 用 `emit('change', val)`，选项式 API 用 `$emit('change', val)` |
| 7 | **B** | `v-model` 默认对应 `modelValue` prop 和 `update:modelValue` 事件 |
| 8 | **A、B、C** | D 错误：v-model 可以绑定任意类型（数字、对象等） |
| 9 | **D** | `defineModel` 不能替代所有场景，比如只需要 emit 不需要 prop 时不适用 |
| 10 | **A、B、C** | D 错误：直接修改 props 违反单向数据流原则 |

### 实操题参考实现要点

**实操题 1（TabBar）**：
- Props：`tabs: { type: Array, required: true }`，`activeIndex: { type: Number, default: 0 }`
- Emit：`emit('change', index)`
- 模板中用 `v-for` 渲染 tabs，`:class="{ active: index === activeIndex }"`
- 父组件用 `ref` 管理当前索引，`@change="currentTab = $event"`

**实操题 2（SearchForm）**：
- 推荐用 `defineModel('keyword')` / `defineModel('category')` / `defineModel('onlyStock')`
- 分类用 `<select v-model="category">` 渲染 `<option>`
- `emit('search')` 不带参数（因为父组件可以直接读 v-model 绑定的值）
- 父组件：`<SearchForm v-model:keyword="kw" v-model:category="cat" v-model:only-stock="stock" @search="handleSearch" />`
