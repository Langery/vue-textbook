# 第 4 章 组件化思想 ⭐

> 课时：9 课时（重点章）
> 难度：⭐⭐（进阶）
> 重要性：⭐⭐⭐⭐⭐（**上篇最核心**）

---

## 🎯 本章目标

学完这章，你将能够：

- ✅ **理解**：组件的本质——"UI = 数据 + 模板"
- ✅ **理解**：组件设计的三大原则（单一职责、可复用、可组合）
- ✅ **掌握**：组件组合模式（slot 默认插槽、具名插槽、作用域插槽）
- ✅ **掌握**：受控 vs 非受控组件的区别和使用场景
- ✅ **掌握**：组件文件的组织方式（一个文件一个组件 / Barrel export）
- ✅ **理解**：组件树的层次结构，能拆解中型页面的组件结构
- ✅ **了解**：选项式 API vs 组合式 API 的区别和选择

---

## 🤔 为什么本章是上篇最核心

**前面学的（1-2 章）都是"基础语法"**——能写，但写出来的是"一团代码"。

**学完本章，你会"组件化思考"**——把任何 UI 都拆成可复用的小积木。这是**从"会写 Vue"到"会用 Vue 写工程"的分水岭**。

> 🧑 **小白**：为什么非要把页面拆成组件？一个文件从头写到尾，不是更省事吗？

> 🤖 **Vue 君**：等你一个文件写到 5000 行，改一个按钮要翻三个地方一起动的时候，就会回来找我拆组件了……

> 👨🏫 **老湿**：组件化就是"把大问题拆成小积木"。这章是全书的分水岭，学完你才算真正"会写 Vue"。

> 💬 **老师备注**：本章是上篇**最关键的一章**。如果你只学一章，必须是这一章。8 课时的安排不是随便给的——组件化思维需要大量练习。

## 🛠 本章实战

学完本章，你应该能：

1. **独立设计**一个"商品列表页"的组件树（不超过 6 个组件）
2. **用 slot** 写一个通用"卡片"组件，支持自定义标题/内容/操作区
3. **用 `<component :is>`** 写一个 Tab 切换组件
4. **判断**某个表单应该用受控还是非受控
5. **组织**一个中等项目的 components/ 目录

## 📖 本章术语表

下表收录本章 4.1~4.14 正文实际讲到的核心术语，按首次出现的节号排序，方便随时回查。

| 术语 | 一句话解释 | 首现节号 |
|---|---|---|
| 组件（Component） | Vue 应用的基本构造单元，把界面拆成可复用、可组合的独立块。 | 4.1 |
| 单文件组件（SFC） | 用 `.vue` 文件封装模板、脚本、样式，一个文件就是一个组件。 | 4.1 |
| `scoped` | 让 `<style>` 里的样式只作用于当前组件，不污染全局。 | 4.1 |
| 组件树 | 组件按父子关系嵌套形成的层级结构，Vue 应用就是一棵组件树。 | 4.3 |
| 单向数据流 | 数据只能父传子（Props 向下），子组件不能直接改父数据。 | 4.3 |
| `Props` | 父组件向子组件传数据的通道，子组件只读不可修改。 | 4.3 |
| `emit` | 子组件向父组件发送事件通知的机制，配合 Props 形成完整通信。 | 4.3 |
| 选项式 API / 组合式 API | 两种写组件逻辑的方式：选项式按 data/methods 分组，组合式按功能组织。 | 4.4 |
| `<script setup>` | 组合式 API 的语法糖，代码更简洁，Vue 3 推荐写法。 | 4.4 |
| 单一职责原则 / 开闭原则 | 组件设计原则：一个组件只做一件事；对扩展开放、对修改关闭。 | 4.5 |
| 组件地狱 | 组件拆得过碎导致嵌套过深、通信混乱、难以维护的困境。 | 4.7 |
| 先写再拆 | 先整体写出功能，出现复用/复杂/变化信号时再拆组件的策略。 | 4.7 |
| `slot` / 具名 slot | 在组件里预留「坑位」让父组件填内容；具名 slot 按名字区分多个坑位。 | 4.8 |
| 作用域 slot | 子组件把数据绑到 slot 上抛回父组件，父组件可自定义渲染。 | 4.9 |
| `Teleport` | 把 DOM 渲染到指定位置（如 body），摆脱父容器样式限制，弹窗常用。 | 4.9 |
| 动态组件（`<component :is>`） | 用一个变量决定渲染哪个组件，一行代码替代一长串 `v-if`。 | 4.10 |
| `<KeepAlive>` | 缓存不活跃的组件，切回时状态不丢失，避免重复销毁重建。 | 4.11 |
| `<Suspense>` | 异步组件加载期间显示 fallback 占位内容，加载完再切换真实内容。 | 4.11 |
| 受控组件 / 非受控组件 | 受控：数据由父组件 Props 传入并控制；非受控：数据在组件内部自管。 | 4.12 |
| `v-model` | 受控组件的标准写法，本质是 `:modelValue` + `@update:modelValue` 语法糖。 | 4.12 |
