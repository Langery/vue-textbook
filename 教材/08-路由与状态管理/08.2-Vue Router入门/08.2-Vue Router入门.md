## 🤔 一、准备工作：安装 Vue Router

Vue Router 是 Vue 官方的路由库，Vue 3 对应的是 v4 版本：

```bash
npm install vue-router@4
```

装好之后，创建项目结构：

```text
src/
├── router/
│   └── index.js      ← 路由配置
├── views/
│   ├── Home.vue      ← 首页
│   └── About.vue     ← 关于页
├── App.vue
└── main.js
```

> 💬 **老师备注**：`views/` 和 `components/` 的分工——`views/` 放页面级组件（路由直接渲染的），`components/` 放可复用的小组件（按钮、卡片、表单）。这不是 Vue 强制的，是团队约定。

## 💡 二、配置路由：三步走

### 第一步：写页面组件

```vue
<!-- src/views/Home.vue -->
<script setup>
// 首页组件，目前很简单
</script>

<template>
  <h1>🏠 首页</h1>
  <p>欢迎来到我的 Vue 应用</p>
</template>
```

```
<!-- src/views/About.vue -->
<script setup>
</script>

<template>
  <h1>ℹ️ 关于我们</h1>
  <p>这是一个 Vue 3 + Vue Router 的入门示例</p>
</template>
```

### 第二步：创建路由表

```js
// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Home from '../views/Home.vue'
import About from '../views/About.vue'

// 路由表：一个数组，每个元素是一个路由规则
const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About },
]

// 创建 router 实例
const router = createRouter({
  history: createWebHistory(),  // History 模式
  routes,                        // 简写，等同于 routes: routes
})

export default router
```

### 第三步：挂载到 Vue 应用

```js
// src/main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

const app = createApp(App)
app.use(router)   // ← 关键：安装路由插件
app.mount('#app')
```

## 🔑 三、使用路由：`<router-link>` 和 `<router-view>`

配置好了，现在在 App.vue 里用起来：

```vue
<!-- src/App.vue -->
<script setup>
</script>

<template>
  <!-- 导航栏 -->
  <nav>
    <router-link to="/">首页</router-link>
    <router-link to="/about">关于</router-link>
  </nav>

  <!-- 路由出口：匹配到的组件渲染在这里 -->
  <router-view />
</template>
```

### `<router-link>` 做了什么？

它最终渲染成一个 `<a>` 标签，但点击时**不会刷新页面**——而是通过 Vue Router 在内部切换组件。Vue Router 还会自动给当前激活的链接加上 `router-link-active` 和 `router-link-exact-active` 两个 class，方便你写高亮样式：

```css
/* 当前页面的导航链接高亮 */
.router-link-exact-active {
  color: #42b983;
  font-weight: bold;
}
```

### `<router-view>` 做了什么？

它根据当前 URL 决定渲染哪个组件。URL 是 `/`，渲染 `<Home />`；URL 是 `/about`，渲染 `<About />`。这个"决定"的过程就是路由匹配。

## 🛠 四、完整示例：加上 404 页面

实际项目中一定会有一个"页面找不到"的处理：

```js
// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Home from '../views/Home.vue'
import About from '../views/About.vue'
import NotFound from '../views/NotFound.vue'

const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About },

  // 404 通配：匹配所有未定义的路由，必须放最后
  { path: '/:pathMatch(.*)*', component: NotFound },
]

const router = createRouter({
  history: createWebHistory(),
  routes,
})

export default router
```

```
<!-- src/views/NotFound.vue -->
<template>
  <div class="not-found">
    <h1>404</h1>
    <p>抱歉，页面不存在</p>
    <router-link to="/">回首页</router-link>
  </div>
</template>
```

`path: '/:pathMatch(.*)*'` 是 Vue Router 4 的通配语法，它会匹配所有未被上面路由匹配到的路径。

## ⚠️ 五、常见陷阱

### 陷阱 1：忘记 `app.use(router)`

```js
// ❌ 忘记了，路由不生效
const app = createApp(App)
app.mount('#app')

// ✅ 必须 use
const app = createApp(App)
app.use(router)
app.mount('#app')
```

### 陷阱 2：404 路由没有放在最后

路由匹配是**从上到下**的，如果 404 通配放在最前面，所有路径都会被它匹配到，后面的路由永远不会生效。

```js
const routes = [
  { path: '/:pathMatch(.*)*', component: NotFound },  // ❌ 放最前面，全拦截
  { path: '/', component: Home },                     // 永远匹配不到
]
```

### 陷阱 3：History 模式下刷新 404

History 模式下 URL 没有 `#`，用户刷新 `/about` 时浏览器会直接请求服务器的 `/about` 路径。开发环境下 Vite 会自动处理，但生产环境需要配置服务器将所有路径都指向 `index.html`。

## 🧠 本节小结

- **安装引入**：`npm install vue-router@4` + `app.use(router)`，别忘了要配 Vue 3
- **核心四件套**：`createRouter` + `createWebHistory()` + `routes` 数组 + 模板里的 `<router-view>`
- **routes 写法**：每个路由对象给 `path`（/ 开头）和 `component`，还可加 `name`
- **声明式跳转**：模板里用 `<router-link to="/about">`，它会渲染成可被拦截的 `<a>`
- **出口组件**：`<router-view>` 是当前匹配组件的插槽，页面切换就是它替换内容
- **懒加载**：`component: () => import('./Xxx.vue')` 让页面按需加载，首屏更快
