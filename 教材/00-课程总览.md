# 📘 Vue 3 教程——课程总览

> 大专/高职/应用型本科 · 计算机相关专业 · 大二下学期 · 64 课时

---

## 🎯 这本书讲什么

这是一本**写给大专学生的 Vue 3 入门到进阶教材**。从"什么是 Vue"开始，一步步带你用 Vue 3（组合式 API）做出**完整、规范、可维护**的现代 Web 应用。

**学完这本书，你将能够**：

- ✅ 独立搭建 Vue 3 + Vite + Pinia + Vue Router 的现代前端工程
- ✅ 熟练使用组合式 API 写出**可复用、可测试**的代码
- ✅ 理解组件化开发思想，能拆解中大型应用的组件树
- ✅ 掌握 Vue 3 响应式原理（Proxy），不只是会用
- ✅ 独立完成一个**完整 SPA 综合项目**（课程设计级别）

## 📚 课程结构

**全书分上下两篇，共 12 章（第 1-12 章）、138 小节、102 课时。**

> 📌 **课时数据从哪来**：全书各小节文件头部都标了「课时：X」，本表与各章 README 的课时表均**由这些标记汇总得出**，三者完全自洽。修改某节课时请改该文件头部的标记，不要只改汇总表。


> **章节编排说明**：条件列表与 key 在第 2 章《模板语法与渲染》内统一讲解（v-if/v-for/key 三件套），故不单列独立章节（原第 7 章相关内容已并入第 2 章 2.5~2.9 节）。所有目录以实际文件夹为准。

> **项目体系说明**：除第 12 章外，每章最后一节都是「章末实战」小项目（P1~P11），把当章语法落成一个能跑的小东西；第 12 章再把这些小项目的能力**收束成一个大项目**——「Campus2Hand」校园二手集市（前台商城 + 管理后台），形成"小项目练手 → 大项目收官"的完整链路。

### 上篇：基础篇（第 1-6 章，48.75 课时）

**目标**：掌握 Vue 3 核心语法，能写简单单页应用。

| 章 | 主题 | 课时 | 难度 | 重点 |
|---|---|---|---|---|
| **1** | Vue 入门与准备 | 5.5 | ⭐ | 装环境、跑通第一个组件 |
| **2** | 模板语法与渲染 | 12.75 | ⭐ | 插值、指令、条件渲染（v-if）、列表渲染（v-for）、key |
| **3** | 响应式数据 | 8 | ⭐⭐ | ref、reactive、响应式原理 |
| **4** | **组件化思想** ⭐ | 9 | ⭐⭐ | **重头戏**：组件设计 + 组合模式 |
| 5 | Props 和事件 | 5.5 | ⭐⭐ | 父子通信、v-model |
| 6 | 生命周期与副作用 | 8 | ⭐⭐ | 副作用、watch 体系 |

**上篇学完，你能**：
- 用 Vite + Vue 3 搭建项目
- 写单文件组件（SFC）`<script setup>`
- 用 `ref` / `reactive` 管理状态
- 用组件拆分中型页面

### 下篇：进阶篇（第 7-12 章，53.25 课时）

**目标**：掌握 Vue 3 生态，能写企业级应用。

| 章 | 主题 | 课时 | 难度 | 重点 |
|---|---|---|---|---|
| **7** | **组合式 API 与代码复用** ⭐ | 8.5 | ⭐⭐⭐ | **重头戏**：composables 模式 |
| **8** | **路由与状态管理** ⭐ | 8 | ⭐⭐⭐ | **重头戏**：Vue Router + Pinia |
| 9 | 服务端通信 | 5 | ⭐⭐ | Axios、拦截器、错误处理与重试 |
| 10 | 表单处理与验证 | 10.5 | ⭐⭐ | 表单组件、校验规则、注册表单实战 |
| 11 | 测试与调试 | 7.0 | ⭐⭐⭐ | Vitest 单元测试、DevTools、Bug 排查 |
| **12** | **综合项目** ⭐ | 14.0 | ⭐⭐⭐ | **收官之作**：Campus2Hand 双端项目（前台商城 + 管理后台） |

**下篇学完，你能**：
- 设计可复用的 composables
- 搭建企业级前端架构（Router + Pinia + 服务端通信 + 测试调试）
- 独立完成一个**双端综合项目**（前台商城 + 管理后台，课设级别）

## 📝 命名与风格约定

### 文件命名
- 章节目录：`XX-章名/`（如 `04-组件化思想/`）
- 小节目录：`XX.N-小节名/`（如 `04.1-组件到底是个啥/`）
- 章节内容：`XX.N-小节名.md`（如 `04.1-组件到底是个啥.md`）
- 图文件：`图N-X.svg`（N 章号，X 该章序号；以 `.svg` 为主，少数历史图为 `.png`）

### 语言风格
- ✅ **半正式**：技术准确但不学术腔
- ✅ **口语化**：老师讲课的口吻（"老师备注"、比喻、生活化表达）
- ✅ **完整可运行代码**：所有示例都能直接复制运行
- ✅ **中文术语优先**：保留必要英文术语（API、slot、ref、Props 等），首次出现时括号解释

### 课时分配原则
- 概念类章节：4 课时（短）
- 工程类章节：6 课时（中）
- 重点章节：8 课时（长）—— 第 4、7、8 章
- 综合项目：2 课时（自己课后完成）

## 📅 版本信息

- **当前版本**：v0.2（草稿阶段）
- **Vue 版本**：**Vue 3.5+**（推荐 `^3.5.44`）+ Vue 2.7 简要对比
  > ⚠️ **本书需要 Vue ≥ 3.5**。正文会用到 `defineModel`（3.4+）、响应式 Props 解构 / `useTemplateRef` / `onWatcherCleanup`（均为 3.5+）。装到 3.3 会连环报错且难以自查。
  > 验证：`npm list vue` 应显示 `3.5.x` 或更高。
- **Node 环境**：**≥ 22.18.0 或 ≥ 24.12.0**（create-vue 的硬性要求；Vite 8 本身要求 ≥ 20.19）
- **构建工具**：Vite 8（`^8.3.4`）
- **状态管理**：Pinia 4（需同时安装 `@vue/devtools-api`）
- **路由**：Vue Router 5
- **类型支持**：可选 TypeScript（不强求）
