## 🛠 分步提示（3~5 步，含关键代码锚点）

> 以下只给路线和关键锚点，**不贴全量答案**。卡住时回头翻 3.1 / 3.2 / 3.9 / 3.3 对应小节。

### Step 1：定义流水数据结构

```js
const records = ref([
  { id: 1, item: '九成新《高等数学》', amount: 15, direction: 'income' },
  { id: 2, item: '购入二手台灯', amount: 20, direction: 'expense' }
])
```

表单字段用 `reactive` 管理（回顾 3.2 对象/数组倾向 `reactive`；这里先用 `ref` 包对象也行，注意别混用踩坑）。

### Step 2：新增流水——先想"能不能原地 push"

新增用 `records.value.push({ id: nextId++, ... })` 即可触发更新（回顾 3.3：数组用 `push` 没问题）。**按下标改也能触发**（`records.value[i] = x` 在 Vue 3 完全有效），但当你要"按 id 定位再改"时，`splice` 语义更清楚，所以下面统一用会改原数组的方法。整体换新数组 `records.value = newArray` 在 `ref` 下也能触发更新，但要手动拼新数组，不如 `splice` 直观。

```js
function addRecord() {
  if (!form.item.trim() || !(form.amount > 0)) return
  records.value.push({
    id: ++nextId,
    item: form.item.trim(),
    amount: Number(form.amount),
    direction: form.direction
  })
  form.item = ''
  form.amount = ''
}
```

### Step 3：用计算属性推导汇总（回顾 2.8 方案一）

总金额不手动存，全部由列表推导：

```js
const totalIncome = computed(() =>
  records.value.filter((r) => r.direction === 'income').reduce((s, r) => s + r.amount, 0)
)
const totalExpense = computed(() =>
  records.value.filter((r) => r.direction === 'expense').reduce((s, r) => s + r.amount, 0)
)
const balance = computed(() => totalIncome.value - totalExpense.value)
```

> 🎯 **类比一下：手写余额小票 vs 银行自动结账**
>
> 手动维护"总金额"变量，就像在便利贴上自己写余额——每加一笔都要记得擦掉重写，擦漏一次就对不上账；用计算属性从流水列表推导，就像**银行对账单**——你存多少取多少，银行按每笔流水自动算出余额，永远和流水对得上。所以"总金额"不自己存，改流水汇总自动跟着变。

> 锚点检查：在计算属性里只依赖 `records`，删/加流水后汇总自动变——这就是"状态单一来源"的甜头。

### Step 4：删除流水——按 id 过滤出新数组

删除用"过滤出新数组再整体赋值"还是 `splice`？两种都要注意响应式（回顾 3.3）。推荐 `splice` 原地改：

```js
function removeRecord(id) {
  const idx = records.value.findIndex((r) => r.id === id)
  if (idx > -1) records.value.splice(idx, 1)
}
```

## 🚀 延伸挑战（1~2 个加分项）

2. **试试 `customRef` 做个金额输入**：参考 3.11，让金额输入带 2 位小数格式化 / 防抖——这是响应式自定义能力的第一次实战。
