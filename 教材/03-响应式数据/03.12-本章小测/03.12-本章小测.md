### 4. 以下代码中，哪个操作**不会**触发 `reactive` 数组的视图更新？

## 📊 参考答案

### 选择题答案

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | **C** | A 错误：ref 可以包任何类型；B 错误：`<script>` 里需要 `.value`；D 错误：Vue 3 用 Proxy + getter/setter |
| 2 | **B** | `ref(0)` 初始值为 0，`count.value = 5` 修改值，模板自动解包显示 5 |
| 3 | **C** | reactive 不能整体替换——会断开 Proxy 引用。应使用 `Object.assign` |
| 4 | **无正确选项**（本题 A~D 全部触发） | ⚠️ 本题原答案有误。Vue 3 的 `Proxy` 能拦截数组任意索引赋值，`push` / 索引赋值 / `splice` / `sort` **四种都能触发更新**。若按 Vue 2 的思路作答会选 B，那是 Vue 2 的限制 |
| 5 | **B** | `toRefs()` 把 reactive 对象每个属性转成 ref，用于安全解构 |
| 6 | **B** | Vue 异步批量更新 DOM，同一同步块多次修改合并为一次渲染 |
| 7 | **B** | `nextTick` 等待本次 DOM 更新完成，用于在更新后操作 DOM |
| 8 | **D** | `shallowRef` 跳过深层代理，创建和修改性能明显优于 `ref`（大对象场景） |
| 9 | **A、C、D** | B 错误：`track` 和 `trigger` 是工厂函数参数，不是从 vue 导入的 |
| 10 | **A、B、D** | C 错误：`list = [...]` 是给变量重新赋值，丢掉了原来的 Proxy 代理，视图不会更新 |

> 💬 **老师备注：三道最容易栽的选择题，到底错在哪**
>
> - **第 4 题（reactive 数组）**：本题是一道**纠错题**——A~D 在 Vue 3 里全都能触发更新。如果你在别处看到"`reactive` 数组不能改索引"，那是 Vue 2 的老规矩（依赖 `$set`，而 `$set` 在 Vue 3 已被移除）。数组操作真正的坑是 **`filter` / `map` 的返回值没赋回去**（见 3.3 节 3.4 条）。
> - **第 9 题（customRef 的参数）**：`track` 和 `trigger` 不是从 `vue` 里 `import` 进来的函数，而是 `customRef` 的工厂函数**在回调里递给你**的两个开关——`track` 负责记账，`trigger` 负责通知。
> - **第 10 题（reactive 整体替换）**：`state = {...}` 只换了变量指向，模板手里捧的还是**旧代理**，所以不会更新。这正是 3.9「不可变原则」反复强调的那条铁律。

### 实操题 1 参考实现

```vue
<script setup>
import { customRef, watch } from 'vue'

function debounceRef(value, delay = 500) {
  let timer = null
  return customRef((track, trigger) => {
    return {
      get() { track(); return value },
      set(newVal) {
        value = newVal
        clearTimeout(timer)
        timer = setTimeout(() => trigger(), delay)
      }
    }
  })
}

const keyword = debounceRef('', 500)
const isSearching = debounceRef(false, 0)  // 这个小 trick：让 isSearching 实时更新
// 更好的做法是用普通 ref：
import { ref } from 'vue'
const searching = ref(false)

// 监听输入变化模拟搜索
watch(keyword, (val) => {
  if (val) {
    console.log('发起搜索：', val)
    searching.value = false
  }
})

// 用原生 input 事件实时更新 searching 状态
function onInput(e) {
  searching.value = true
  keyword.value = e.target.value
}
</script>

<template>
  <input :value="keyword" @input="onInput" placeholder="搜索..." />
  <span v-if="searching">正在搜索...</span>
</template>
```
