## 🤔 一、CRUD 模块的标准开发流程

闲置物品管理是一个标准的**CRUD 模块**（Create / Read / Update / Delete），几乎所有管理后台都有类似的模块（课程管理、用户管理、文章管理等）。掌握这一节，你就能做任何类似的功能。

标准流程四步走：

```text
1. 写接口函数（api/goods.js）
2. 写列表页（GoodsList.vue）—— 读取 + 搜索 + 分页 + 删除

4. 配置路由（router/index.js）—— 列表 + 新增 + 编辑（第13.3节已完成）
```

## 💡 二、api/goods.js —— 接口函数封装

```js
// src/api/goods.js
import request from './index'

// 获取闲置物品列表（分页 + 搜索）
export const getGoodsList = (params) => {
  return request({
    url: '/goods',
    method: 'get',
    params   // { pageNum, pageSize, keyword }
  })
}

// 获取闲置物品详情（编辑时回填）
export const getGoodsDetail = (id) => {
  return request({
    url: `/goods/${id}`,
    method: 'get'
  })
}

// 新增闲置物品
export const createGoods = (data) => {
  return request({
    url: '/goods',
    method: 'post',
    data
  })
}

// 更新闲置物品
export const updateGoods = (id, data) => {
  return request({
    url: `/goods/${id}`,
    method: 'put',
    data
  })
}

// 删除闲置物品
export const deleteGoods = (id) => {
  return request({
    url: `/goods/${id}`,
    method: 'delete'
  })
}
```

> 💬 **老师备注**：接口函数命名保持统一风格——`getXxxList`（列表）、`getXxxDetail`（详情）、`createXxx`（新增）、`updateXxx`（更新）、`deleteXxx`（删除）。团队成员一看命名就知道功能。

## 🔑 三、闲置物品列表页（GoodsList.vue）——完整代码

```vue
<!-- src/views/goods/GoodsList.vue -->
<script setup>
import { ref, reactive, onMounted } from 'vue'
import { useRouter } from 'vue-router'
import { getGoodsList, deleteGoods } from '@/api/goods'
import { ElMessage, ElMessageBox } from 'element-plus'

const router = useRouter()

// ==================== 列表数据 ====================
const tableData = ref([])
const loading = ref(false)

// ==================== 分页参数 ====================
const pagination = reactive({
  pageNum: 1,
  pageSize: 10,
  total: 0
})

// ==================== 搜索关键词 ====================
const keyword = ref('')

// ==================== 获取列表数据 ====================
const fetchList = async () => {
  loading.value = true
  try {
    const res = await getGoodsList({
      pageNum: pagination.pageNum,
      pageSize: pagination.pageSize,
      keyword: keyword.value
    })
    tableData.value = res.data.list
    pagination.total = res.data.total
  } catch (error) {
    ElMessage.error('获取闲置物品列表失败')
  } finally {
    loading.value = false
  }
}

// ==================== 搜索 ====================
const handleSearch = () => {
  pagination.pageNum = 1   // 搜索时重置为第一页
  fetchList()
}

// ==================== 分页切换 ====================
const handlePageChange = (page) => {
  pagination.pageNum = page
  fetchList()
}

const handleSizeChange = (size) => {
  pagination.pageSize = size
  pagination.pageNum = 1   // 切换每页条数时重置为第一页
  fetchList()
}

// ==================== 删除 ====================
const handleDelete = (row) => {
  ElMessageBox.confirm(
    `确定要删除闲置物品「${row.name}」吗？删除后不可恢复。`,
    '确认删除',
    { confirmButtonText: '确定', cancelButtonText: '取消', type: 'warning' }
  ).then(async () => {
    await deleteGoods(row.id)
    ElMessage.success('删除成功')
    fetchList()
  }).catch(() => {
    // 用户点取消，不做任何事
  })
}

// ==================== 状态切换 ====================
const handleStatusChange = async (row) => {
  // 此处调用更新接口
  // await updateGoods(row.id, { status: row.status })
  // ElMessage.success(`已${row.status === 1 ? '上架' : '下架'}`)
}

// ==================== 跳转新增/编辑 ====================
const goToAdd = () => router.push('/goods/add')
const goToEdit = (id) => router.push(`/goods/edit/${id}`)

// 页面挂载时获取数据
onMounted(() => {
  fetchList()
})
</script>

<template>
  <div class="goods-list">
    <!-- 搜索栏 -->
    <div class="search-bar">
      <el-input
        v-model="keyword"
        placeholder="输入闲置物品名称搜索"
        clearable
        style="width: 300px"
        @keyup.enter="handleSearch"
      />
      <el-button type="primary" @click="handleSearch">搜索</el-button>
      <el-button type="success" @click="goToAdd">新增闲置物品</el-button>
    </div>

    <!-- 表格 -->
    <el-table
      :data="tableData"
      v-loading="loading"
      stripe
      border
      style="width: 100%"
    >
      <el-table-column prop="id" label="ID" width="80" align="center" />
      <el-table-column prop="name" label="闲置物品名称" min-width="150" />
      <el-table-column label="闲置物品图片" width="100" align="center">
        <template #default="{ row }">
          <el-image
            v-if="row.image"
            :src="row.image"
            style="width: 50px; height: 50px"
            fit="cover"
            preview-teleported
            :preview-src-list="[row.image]"
          />
          <span v-else>无图片</span>
        </template>
      </el-table-column>
      <el-table-column prop="price" label="价格（元）" width="120" align="center">
        <template #default="{ row }">¥{{ row.price.toFixed(2) }}</template>
      </el-table-column>
      <el-table-column prop="stock" label="库存" width="80" align="center" />
      <el-table-column label="状态" width="100" align="center">
        <template #default="{ row }">
          <el-switch
            :model-value="row.status === 1"
            active-text="上架"
            inactive-text="下架"
            @change="handleStatusChange(row)"
          />
        </template>
      </el-table-column>
      <el-table-column label="操作" width="160" align="center" fixed="right">
        <template #default="{ row }">
          <el-button size="small" type="primary" @click="goToEdit(row.id)">
            编辑
          </el-button>
          <el-button size="small" type="danger" @click="handleDelete(row)">
            删除
          </el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- 分页 -->
    <div class="pagination-wrapper">
      <el-pagination

        v-model:page-size="pagination.pageSize"
        :total="pagination.total"
        :page-sizes="[10, 20, 50]"
        layout="total, sizes, prev, pager, next, jumper"
        @current-change="handlePageChange"
        @size-change="handleSizeChange"
      />
    </div>
  </div>
</template>
```

### 列表页关键设计说明

| 功能点 | 实现方式 |
|---|---|
| 搜索 | `keyword` ref + `handleSearch()` 重置 `pageNum` 为 1 |
| 分页 | `el-pagination` + `@current-change` / `@size-change` |
| 删除确认 | `ElMessageBox.confirm` 二次确认，防止误删 |
| 图片预览 | `el-image` 的 `preview-src-list` 点击可放大 |
| 上架/下架 | `el-switch` 切换状态 |
| loading 状态 | `v-loading="loading"` 加载中显示转圈 |

## 🧠 本节小结

- **CRUD 四步走**：写接口函数 → 列表页（读/搜/删）→ 表单页（增/改，下节）→ 配路由（13.3 已完成）；所有管理后台模块都长这样
- **接口命名即文档**：`getXxxList` / `getXxxDetail` / `createXxx` / `updateXxx` / `deleteXxx`，团队看名字就知道用途
- **分页三状态**：`pageNum` / `pageSize` / `total`；**搜索与切换每页条数都必须把 `pageNum` 重置为 1**，否则可能停在不存在的高页码
- **删除必须二次确认**：`ElMessageBox.confirm` 防误删，成功后再 `fetchList()` 刷新
- **fetchList 统一收口**：搜索、翻页、切 size、删除后都只调它，loading 用 try/finally 保证关掉
- **体验细节**：表格 `v-loading` 转圈、图片 `preview-src-list` 点击放大、回车触发搜索
