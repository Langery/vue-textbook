## 🛠 本章实战

**主项目（必修）：「Campus2Hand」校园二手集市**——本书的收官之作，就是这 19 节带你一步步搭出来的双端项目：

**前台商城（学生视角）**

- 首页：闲置列表 + 关键词 / 分类 / 价格三条件筛选
- 详情：商品详情 + 留言互动
- 发布：表单校验 + 图片本地预览
- 购物车与模拟下单

**管理后台（管理员视角）**

- 登录注册（JWT + Pinia + 路由守卫）
- 闲置物品管理（CRUD + 表单 + 分页）
- 交易订单管理（列表 + 详情弹窗 + 状态流转）
- 数据看板

> 🎓 这个项目同时就是你的**课程设计作品**：需求文档、路由设计、目录结构、可运行代码、部署上线，一整套齐全。

**扩展方向（选做，有能力再挑战）**

| 方向 | 可以怎么做 |
|---|---|
| 博客管理系统 | 把"闲置"换成"文章"，复用 CRUD + 留言 |
| 在线教育平台 | 把"闲置"换成"课程"，加视频播放页 |
| 真实后端 | 用 Node/Express 或 json-server 替换 mock 数据 |
| 移动端适配 | 用媒体查询或 Vant 做一套移动端页面 |

**最低要求**：主项目跑通并部署上线，提交完整代码 + 设计文档。
