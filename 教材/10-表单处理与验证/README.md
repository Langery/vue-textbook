## 🤔 为什么学这章

**表单是 Web 应用最常见的交互方式。** 登录、注册、搜索、评论、下单——本质上都是表单。

不夸张地说，你写的 80% 的 Vue 页面都包含表单。而这章从原理（`v-model` 本质）到实践（VeeValidate + 综合实战），帮你建立完整的表单处理能力。

> 🧑 **小白**：写表单不就是放几个 input 再加个提交按钮吗？用得着专门花一章？

> 🤖 **Vue 君**：那你试试处理"输入校验、失焦报错、异步查重、防重复提交"……是不是头大了？

> 👨🏫 **老湿**：你写的 80% 的页面里都有表单。这章从 v-model 原理到 VeeValidate 实战一次讲透，学完能少掉一半头发。

## ⚠️ 学习提示

- **先理解 v-model 的本质再学 VeeValidate**——理解 `:value` + `@input` 的底层原理后，你会发现 VeeValidate 只是帮你自动化了这个过程
- **不要跳过手写验证**——哪怕你项目里最终用 VeeValidate，手写一遍验证系统能帮你理解验证的本质
- **重点节 10.7 尽量手敲一遍**——注册表单是面试和实际项目中最常见的场景，完整的代码要能默写出来
- **异步规则注意防抖**——用户名查重这种场景一定要加防抖（`useDebounceFn`），否则每个字符都发一次请求会打爆后端

## 📖 本章术语表

下表收录本章 10.1~10.11 正文实际讲到的核心术语，按首次出现的节号排序，方便随时回查。

| 术语 | 一句话解释 | 首现节号 |
|---|---|---|
| `v-model` | 表单双向绑定指令，本质是 :value 属性绑定加 @input 事件监听的语法糖。 | 10.1 |
| `.lazy` | v-model 修饰符，把更新时机从每次输入改为 change（失焦）事件触发。 | 10.1 |
| `.number` | v-model 修饰符，用 parseFloat 自动把输入字符串转成数字类型。 | 10.1 |
| `modelValue` | 组件 v-model 默认展开的 prop 名，接收父组件 v-model 传入的值。 | 10.1 |
| `update:modelValue` | 子组件向父组件回传新值的事件，与 modelValue 配套完成 v-model 闭环。 | 10.1 |
| `defineModel` | Vue 3.4 编译宏，组件内一行声明 props 与事件，简化 v-model 双向绑定。 | 10.1 |
| `checkbox` | 复选框控件：单个绑布尔值，同组多个绑数组，用 v-model 管理勾选状态。 | 10.2 |
| `select` | 下拉选择控件：单选存选中值，加 multiple 多选存数组，支持绑定对象。 | 10.2 |
| `表单验证` | 提交前在前端校验用户输入并即时反馈错误，减少无效请求、提升体验。 | 10.3 |
| `失焦验证` | 字段失去焦点（@blur）时触发的单字段校验，实现边填边纠错的交互。 | 10.3 |
| `errors` | 验证错误信息对象：键为字段名、值为错误文案，空字符串表示该字段通过。 | 10.3 |
| `VeeValidate` | Vue 3 生态的声明式表单验证库，内置常用规则并自动管理错误展示。 | 10.4 |
| `useField` | VeeValidate 核心 API，返回单个字段的值、错误信息与校验方法。 | 10.4 |
| `useForm` | VeeValidate 表单级 API，管理整体校验状态，配合 validationSchema 声明规则。 | 10.4 |
| `defineRule` | VeeValidate 的规则注册函数，可在全局或组件内定义自定义验证规则。 | 10.4 |
| `异步规则` | 返回 Promise 的验证规则，等异步结果返回后再判定，典型场景为用户名查重。 | 10.5 |
| `防重复提交` | 用 submitting 状态禁用提交按钮拦截连点，避免同一表单重复发送请求。 | 10.6 |
| `resetForm` | VeeValidate 重置表单的 API，可清空为初始值或恢复为指定值。 | 10.6 |
| `异步查重` | 通过接口检查用户名/手机号是否已被占用，配合防抖与提交前复查使用。 | 10.8 |
| `Composable` | 组合式函数，把表单校验、查重、提交等逻辑抽离成可复用模块，组件只留 UI。 | 10.9 |
