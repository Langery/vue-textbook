## 🤔 一、为什么需要表单验证？

用户输入不可信——这不是不信任用户，而是写程序的基本原则。你可能遇到：

- 用户忘了填必填项
- 邮箱格式写错（`zhangsan@`）
- 密码只有两位（"12"）
- 两次输入的密码不一样
- 手机号少了一位

表单验证就是在数据提交到后端**之前**，在前端做第一道把关。一方面减少无效请求，另一方面给用户即时反馈。

## 💡 二、手写验证的基本框架

一个最简的验证系统只需要三样东西：

1. **表单数据**（`form`）
2. **验证规则**（`rules`）
3. **错误信息**（`errors`）

```vue
<script setup>
import { reactive, ref } from 'vue'

// 1. 表单数据
const form = reactive({
  username: '',
  email: '',
  password: ''
})

// 2. 错误信息
const errors = reactive({
  username: '',
  email: '',
  password: ''
})

// 3. 验证规则（返回错误信息，空字符串表示通过）
function validateUsername(val) {
  if (!val) return '用户名不能为空'
  if (val.length < 3) return '用户名至少 3 个字符'
  return ''
}

function validateEmail(val) {
  if (!val) return '邮箱不能为空'
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(val)) return '邮箱格式不正确'
  return ''
}

function validatePassword(val) {
  if (!val) return '密码不能为空'
  if (val.length < 6) return '密码至少 6 位'
  return ''
}
</script>
```

## 🛠 三、提交验证（最基础的模式）

用户点"提交"按钮时，跑一遍所有字段的校验，全部通过才发请求。

```
<script setup>
// ... 接上面的 form / errors / validate 函数

function validateAll() {
  let isValid = true

  // 跑所有校验
  errors.username = validateUsername(form.username)
  errors.email = validateEmail(form.email)
  errors.password = validatePassword(form.password)

  // 只要有一个非空错误信息，就是没通过
  if (errors.username || errors.email || errors.password) {
    isValid = false
  }
  return isValid
}

function handleSubmit() {
  if (!validateAll()) {
    alert('请检查表单中的错误')
    return
  }
  // 全部通过，发送请求
  console.log('提交数据：', form)
}
</script>

<template>
  <form @submit.prevent="handleSubmit">
    <div>
      <input v-model="form.username" placeholder="用户名" />
      <span style="color: red">{{ errors.username }}</span>
    </div>
    <div>
      <input v-model="form.email" placeholder="邮箱" />
      <span style="color: red">{{ errors.email }}</span>
    </div>
    <div>
      <input v-model="form.password" type="password" placeholder="密码" />
      <span style="color: red">{{ errors.password }}</span>
    </div>
    <button type="submit">注册</button>
  </form>
</template>
```

## 🛠 四、实时验证（失焦验证）

提交验证的问题是：用户填完整个表单点"提交"才发现有一堆错误，体验不好。更好的做法是**失焦时立即验证单个字段**：

```vue
<script setup>
// ... 接上面的 form / errors / validate 函数

// 单字段验证
function validateField(field) {
  switch (field) {
    case 'username':
      errors.username = validateUsername(form.username)
      break
    case 'email':
      errors.email = validateEmail(form.email)
      break
    case 'password':
      errors.password = validatePassword(form.password)
      break
  }
}

// 用户修改字段时清除该字段的错误
function clearError(field) {
  errors[field] = ''
}
</script>

<template>
  <form @submit.prevent="handleSubmit">
    <div>
      <input
        v-model="form.username"
        placeholder="用户名"
        @blur="validateField('username')"
        @input="clearError('username')"
      />
      <span class="error">{{ errors.username }}</span>
    </div>
    <!-- email、password 同理 -->
  </form>
</template>
```

关键逻辑：
- `@blur`：失焦时跑验证，显示错误
- `@input`：用户修改时立刻清除错误（你不会想让用户在改正时还看到旧的错误提示）

三种验证时机没有谁优谁劣，关键看场景怎么搭配：

| 对比维度 | 实时验证 | 失焦验证（blur） | 提交验证 |
|---|---|---|---|
| 触发时机 | 每输入一个字符 | 字段失去焦点时 | 点击提交按钮时 |
| 用户体验 | 最即时，但可能太吵 | 友好，改正时不打扰 | 一次全报，压力较大 |
| 实现成本 | 高（每个字段每个输入都要跑） | 中（`@blur` 监听） | 低（提交时统一校验） |
| 适合场景 | 密码强度、字符计数 | 邮箱、手机号格式 | 必填项总检查、兜底 |
| 常见组合 | 常与失焦 / 提交组合使用 | 与提交验证搭配 | 所有表单必须有 |

## 🛠 五、完整示例：带实时验证 + 提交验证的注册表单

```
<script setup>
import { reactive } from 'vue'

const form = reactive({
  username: '',
  phone: '',
  email: '',
  password: '',
  confirmPassword: ''
})

const errors = reactive({
  username: '',
  phone: '',
  email: '',
  password: '',
  confirmPassword: ''
})

// ========== 校验函数 ==========
function validateUsername(val) {
  if (!val) return '用户名不能为空'
  if (val.length < 3) return '用户名至少 3 个字符'
  if (val.length > 20) return '用户名不能超过 20 个字符'
  return ''
}

function validatePhone(val) {
  if (!val) return '手机号不能为空'
  if (!/^1[3-9]\d{9}$/.test(val)) return '手机号格式不正确'
  return ''
}

function validateEmail(val) {
  if (!val) return '邮箱不能为空'
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(val)) return '邮箱格式不正确'
  return ''
}

function validatePassword(val) {
  if (!val) return '密码不能为空'
  if (val.length < 6) return '密码至少 6 位'
  if (val.length > 30) return '密码不能超过 30 位'
  return ''
}

function validateConfirmPassword(val) {
  if (!val) return '请再次输入密码'
  if (val !== form.password) return '两次输入的密码不一致'
  return ''
}

// ========== 验证逻辑 ==========
function validateField(field) {
  switch (field) {
    case 'username':   errors.username = validateUsername(form.username); break
    case 'phone':      errors.phone = validatePhone(form.phone); break
    case 'email':      errors.email = validateEmail(form.email); break
    case 'password':   errors.password = validatePassword(form.password); break
    case 'confirmPassword': errors.confirmPassword = validateConfirmPassword(form.confirmPassword); break
  }
  // 确认密码依赖密码字段，密码改了也要重验确认密码
  if (field === 'password' && form.confirmPassword) {
    errors.confirmPassword = validateConfirmPassword(form.confirmPassword)
  }
}

function clearError(field) {
  errors[field] = ''
}

// ========== 提交 ==========
function validateAll() {
  const fields = ['username', 'phone', 'email', 'password', 'confirmPassword']
  fields.forEach(f => validateField(f))
  return Object.values(errors).every(e => e === '')
}

function handleSubmit() {
  if (!validateAll()) return
  console.log('✅ 表单通过验证，提交数据：', form)
}
</script>

<template>
  <form @submit.prevent="handleSubmit" class="form">
    <!-- 用户名 -->
    <div class="field">
      <label>用户名</label>
      <input
        v-model="form.username"
        @blur="validateField('username')"
        @input="clearError('username')"
        placeholder="至少 3 个字符"
      />
      <span v-if="errors.username" class="error">{{ errors.username }}</span>
    </div>

    <!-- 手机号 -->
    <div class="field">
      <label>手机号</label>
      <input
        v-model="form.phone"
        @blur="validateField('phone')"
        @input="clearError('phone')"
        placeholder="11 位手机号"
      />
      <span v-if="errors.phone" class="error">{{ errors.phone }}</span>
    </div>

    <!-- 邮箱 -->
    <div class="field">
      <label>邮箱</label>
      <input
        v-model="form.email"
        @blur="validateField('email')"
        @input="clearError('email')"
        placeholder="example@mail.com"
      />
      <span v-if="errors.email" class="error">{{ errors.email }}</span>
    </div>

    <!-- 密码 -->
    <div class="field">
      <label>密码</label>
      <input
        v-model="form.password"
        type="password"
        @blur="validateField('password')"
        @input="clearError('password')"
        placeholder="至少 6 位"
      />
      <span v-if="errors.password" class="error">{{ errors.password }}</span>
    </div>

    <!-- 确认密码 -->
    <div class="field">
      <label>确认密码</label>
      <input
        v-model="form.confirmPassword"
        type="password"
        @blur="validateField('confirmPassword')"
        @input="clearError('confirmPassword')"
        placeholder="再次输入密码"
      />
      <span v-if="errors.confirmPassword" class="error">{{ errors.confirmPassword }}</span>
    </div>

    <button type="submit">注册</button>
  </form>
</template>

<style scoped>
.form { max-width: 400px; margin: 0 auto; }
.field { margin-bottom: 16px; }
.field label { display: block; margin-bottom: 4px; font-weight: bold; }
.field input { width: 100%; padding: 8px; box-sizing: border-box; }
.error { color: #e74c3c; font-size: 13px; margin-top: 4px; display: block; }
</style>
```

## ⚠️ 六、常见陷阱

### 陷阱 1：空字符串 `''` 被当成 truthy

```js
// ❌ if (errors.username) 对空字符串 '' 判断为 false，逻辑反了
if (errors.username) { /* 不会执行 */ }
```

所有校验函数返回**空字符串表示"通过"**，但空字符串在 JS 里是 falsy。如果你想判断"是否有错误"，应该用：

```js
// ✅ 明确判断是否非空
if (errors.username !== '') { /* 有错误 */ }
```

或者统一用 `.every(e => e === '')` 判断全表单状态。

### 陷阱 2：改了字段但忘了重验关联字段

比如确认密码校验，用户改了密码但确认密码没变，按道理确认密码应该重新验证（因为和密码不一致了）。上例中在 `validateField('password')` 里手动加了重验 `confirmPassword`，实际开发中容易漏。

### 陷阱 3：正则表达式的边界问题

```js
// ❌ 这个正则会匹配 "zhangsan@gmail.comxxx"，因为没加 ^ 和 $
const emailRegex = /\S+@\S+\.\S+/

// ✅ 加上起止锚点
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
```

### 陷阱 4：验证逻辑写在模板里

```vue
<!-- ❌ 不要把验证逻辑塞模板 -->
<span v-if="form.username.length < 3">用户名至少 3 个字符</span>
```

业务逻辑应该集中在 `<script>` 里，模板只负责渲染。验证逻辑写到模板里会导致散落各处、难以维护。

## 🧠 本节小结

- **核心三件套**：`form`（表单数据）+ 校验函数（合格标准）+ `errors`（错误信息）；校验函数返回空字符串表示通过
- **提交验证**：点提交时 `validateAll` 跑全部字段，用 `Object.values(errors).every(e => e === '')` 判断整体是否通过，通过才发请求
- **实时验证**：`@blur` 失焦时校验单个字段、`@input` 修改时清除该字段旧错误；像"确认密码"这类依赖其他字段的校验，关联字段变化时要联动重验
- **空字符串是 falsy**：判断"有没有错误"别用 `if (errors.username)`，要明确比较 `!== ''`
- **可维护性**：验证逻辑集中在 `<script>`，别散在模板里；正则记得加 `^` 和 `$` 锚点防边界穿透
- **三种时机配合**：失焦验证友好、提交验证兜底，正式表单通常两者组合
