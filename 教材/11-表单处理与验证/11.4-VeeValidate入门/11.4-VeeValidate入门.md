## 🤔 一、为什么需要 VeeValidate？

上一节我们手写了完整的验证逻辑，你一定感受到了——**代码量很大，而且很多是重复的**。

每加一个字段，你就要：
1. 写一个 `validateXxx` 函数
2. 在 `validateField` 的 `switch` 里加一个 `case`
3. 在 `validateAll` 里加一行
4. 在模板里加 `@blur` 和 `@input` 绑定

字段多了以后，维护成本直线上升。VeeValidate 就是来解决这个问题的——它把"定义规则"和"执行验证"这两件事封装好了，你只需要**声明规则**，剩下的（失焦验证、错误收集、提交拦截）它全帮你做了。

## 💡 二、安装 VeeValidate

VeeValidate 4 是专为 Vue 3 设计的版本，API 和 Vue 3 的组合式 API 完全对齐。

```bash
npm install vee-validate@4 @vee-validate/rules
```

- `vee-validate@4`：核心库
- `@vee-validate/rules`：内置验证规则包（可选，也可以只装你需要的规则）

## 🛠 三、最小示例：用 useField 管理单个字段

`useField` 是 VeeValidate 最核心的 API，它把一个字段的"值 + 验证 + 错误"全部封装起来。

```vue
<script setup>
import { useField } from 'vee-validate'
import * as rules from '@vee-validate/rules'
import { defineRule } from 'vee-validate'

// 1. 注册内置规则（只需注册一次）
defineRule('required', rules.required)
defineRule('email', rules.email)

// 2. 用 useField 管理 email 字段
const { value: email, errorMessage, handleBlur } = useField('email', 'required|email')
</script>

<template>
  <div>
    <input
      v-model="email"
      @blur="handleBlur"
      placeholder="请输入邮箱"
    />
    <span v-if="errorMessage" style="color: red">{{ errorMessage }}</span>
  </div>
</template>
```

`useField` 返回的对象里：
- `value`：字段的值（用 `v-model` 绑定）
- `errorMessage`：当前字段的第一条错误信息（没有错误时为 `undefined`）
- `handleBlur`：失焦时的处理函数（内部会触发验证）

## 🛠 四、useForm：管理整个表单

实际项目中，你不会每个字段都单独 `useField`，而是用 `useForm` 统一管理。

```
<script setup>
import { useForm } from 'vee-validate'
import { defineRule } from 'vee-validate'
import * as rules from '@vee-validate/rules'

// 注册规则
defineRule('required', rules.required)
defineRule('email', rules.email)
defineRule('min', rules.min)
defineRule('confirmed', rules.confirmed)

// 定义表单
const { handleSubmit, errors } = useForm({
  validationSchema: {
    username: 'required|min:3',
    email: 'required|email',
    password: 'required|min:6',
    confirmPassword: 'required|confirmed:@password'
  }
})

// 提交回调（只有验证通过才会执行）
const onSubmit = handleSubmit((values) => {
  console.log('✅ 表单通过验证：', values)
})
</script>

<template>
  <form @submit="onSubmit">
    <div>
      <input v-model="username" name="username" />
      <span v-if="errors.username">{{ errors.username }}</span>
    </div>
    <!-- 其他字段同理 -->
    <button type="submit">注册</button>
  </form>
</template>
```

> 💬 **老师备注**：`handleSubmit` 是 VeeValidate 提供的包装函数。它会在提交前自动跑所有字段的验证，只有全部通过才调用你传入的回调。你不需要自己写 `validateAll` 了。

## 🛠 五、规则写法详解

### 5.1 字符串写法（简单规则）

```js
validationSchema: {
  username: 'required|min:3|max:20'
}
```

管道符 `|` 分隔多个规则，冒号 `:` 传参数。

### 5.2 对象写法（推荐，更清晰）

```js
validationSchema: {
  username: { required: true, min: 3, max: 20 },
  email: { required: true, email: true },
  password: { required: true, min: 6 }
}
```

### 5.3 函数写法（复杂逻辑）

```js
validationSchema: {
  age: (value) => {
    if (!value) return '年龄不能为空'
    if (value < 0 || value > 150) return '年龄不合法'
    return true  // 返回 true 表示通过
  }
}
```

## 🛠 六、完整示例：注册表单（VeeValidate 版）

```vue
<script setup>
import { useForm } from 'vee-validate'
import { defineRule } from 'vee-validate'
import * as rules from '@vee-validate/rules'
import { ref } from 'vue'

// 注册规则
defineRule('required', rules.required)
defineRule('email', rules.email)
defineRule('min', rules.min)
defineRule('confirmed', rules.confirmed)

const { handleSubmit, errors, resetForm } = useForm({
  validationSchema: {
    username: { required: true, min: 3 },
    email: { required: true, email: true },
    password: { required: true, min: 6 },
    confirmPassword: { required: true, confirmed: '@password' }
  }
})

// 提交
const onSubmit = handleSubmit((values) => {
  console.log('✅ 提交数据：', values)
  // 实际项目中这里发请求
})

// 重置
function handleReset() {
  resetForm()
}
</script>

<template>
  <form @submit="onSubmit" class="form">
    <div class="field">
      <label>用户名</label>
      <input v-model="username" name="username" />
      <span v-if="errors.username" class="error">{{ errors.username }}</span>
    </div>

    <div class="field">
      <label>邮箱</label>
      <input v-model="email" name="email" />
      <span v-if="errors.email" class="error">{{ errors.email }}</span>
    </div>

    <div class="field">
      <label>密码</label>
      <input v-model="password" name="password" type="password" />
      <span v-if="errors.password" class="error">{{ errors.password }}</span>
    </div>

    <div class="field">
      <label>确认密码</label>
      <input v-model="confirmPassword" name="confirmPassword" type="password" />
      <span v-if="errors.confirmPassword" class="error">{{ errors.confirmPassword }}</span>
    </div>

    <div class="actions">
      <button type="submit">注册</button>
      <button type="button" @click="handleReset">重置</button>
    </div>
  </form>
</template>

<style scoped>
.form { max-width: 400px; margin: 0 auto; }
.field { margin-bottom: 16px; }
.field label { display: block; margin-bottom: 4px; font-weight: bold; }
.field input { width: 100%; padding: 8px; box-sizing: border-box; }
.error { color: #e74c3c; font-size: 13px; margin-top: 4px; display: block; }
.actions { display: flex; gap: 8px; }
</style>
```

## ⚠️ 七、常见陷阱

### 陷阱 1：忘了注册规则

```js
// ❌ 直接写规则名，但没注册
validationSchema: { email: 'required|email' }
// 运行时报错：Rule 'email' is not defined
```

必须先 `defineRule('email', rules.email)` 注册，才能在 `validationSchema` 里用。

### 陷阱 2：`confirmed` 规则的 `@` 语法

```js
// ✅ @password 表示"和 password 字段的值一致"
confirmPassword: 'required|confirmed:@password'

// ❌ 不要写成 confirmed: 'password'（这是字符串比较，不是字段引用）
```

### 陷阱 3：`handleSubmit` 的返回值

```js
// ❌ 这样写不会触发验证！
<form @submit.prevent="handleSubmit(onSubmit)">

// ✅ 正确写法：handleSubmit 返回的是一个函数
<form @submit="handleSubmit(onSubmit)">
```

`handleSubmit` 返回的是一个包装后的 submit 处理函数，直接传给 `@submit` 即可，不要自己包一层 `.prevent`（VeeValidate 内部已经处理了）。

### 陷阱 4：VeeValidate 4 和 3 的 API 完全不同

VeeValidate 3 是给 Vue 2 用的，API 是选项式的（`ValidationObserver`、`ValidationProvider` 组件）。VeeValidate 4 是给 Vue 3 用的，完全基于组合式 API。**不要混着看文档**。

## 🧠 本节小结

- **为什么用库**：手写验证每加一个字段要改 4 处（校验函数 / switch case / validateAll / 模板绑定），规则散落难维护；VeeValidate 把「定义规则 + 执行验证 + 错误展示」封装成声明式写法
- **安装**：`npm install vee-validate@4 @vee-validate/rules`；VeeValidate 4 专为 Vue 3 组合式 API 设计，3 的选项式 API 文档不要混看
- **useField**：管理单个字段，返回 `value`（v-model 绑定）、`errorMessage`（第一条错误）、`handleBlur`（失焦验证）
- **useForm + validationSchema**：整表单声明规则；`handleSubmit` 是包装函数——提交前自动全量验证、通过才调用你传入的回调，直接绑 `@submit` 即可，不要再包 `.prevent`
- **规则三种写法**：字符串 `'required|min:3'`、对象 `{ required: true }`、函数 `(value) => true / '错误信息'`；`confirmed: '@password'` 的 `@` 表示引用其他字段
- **常见坑**：规则必须先用 `defineRule` 注册（否则报 Rule not defined）
