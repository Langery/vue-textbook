## 💡 一、`<KeepAlive>`：缓存动态组件

### 问题：切换组件会丢失状态

动态组件有一个"副作用"——**切换走一个组件时，它会被销毁（unmount），再切回来时重新创建（mount），之前的状态全丢了**。

假设你有一个多步骤表单：

```vue
<template>
  <component :is="currentStep" />
  <button @click="nextStep">下一步</button>
</template>
```

用户在第 1 步填了 10 个字段，切到第 2 步，再切回第 1 步——**填的东西全没了**。因为第 1 步的组件被销毁重建了。

### 解决方案：用 `<KeepAlive>` 包起来

```vue
<template>
  <!-- KeepAlive 会缓存不活跃的组件，切回来时状态还在 -->
  <KeepAlive>
    <component :is="currentStep" />
  </KeepAlive>
  <button @click="nextStep">下一步</button>
</template>
```

### KeepAlive 的精细控制

```
<template>
  <!--
    include：只缓存名字匹配的组件
    exclude：不缓存名字匹配的组件
    max：最多缓存几个（超出按 LRU 淘汰最久没用的）
  -->
  <KeepAlive :include="['Step1', 'Step2']" :exclude="['Step3']" :max="3">
    <component :is="currentStep" />
  </KeepAlive>
</template>
```

> 💬 **老师备注**：`include` / `exclude` 匹配的是组件的 `name` 选项（在 `<script setup>` 里组件名默认是文件名）。KeepAlive 是 Vue 内置组件，不需要 import。

### KeepAlive 的生命周期钩子

被 KeepAlive 缓存的组件，多了两个生命周期钩子：

```
<script setup>
import { onActivated, onDeactivated } from 'vue'

// 组件被激活（切回来显示）时触发
onActivated(() => {
  console.log('组件被激活了！')
})

// 组件被缓存（切走隐藏）时触发
onDeactivated(() => {
  console.log('组件被缓存了！')
})
</script>
```

| 钩子 | 触发时机 | 典型用途 |
|---|---|---|
| `onActivated` | 组件从缓存中恢复显示 | 重新请求最新数据 |
| `onDeactivated` | 组件即将被缓存（离开） | 暂停定时器、保存草稿 |

## 🚀 二、异步组件 + Suspense：优雅的加载体验

动态组件让我们按需切换组件，但如果某个组件**体积很大**（比如图表组件、富文本编辑器），一次性全部打包会导致首屏加载很慢。Vue 提供了两把利器来解决这个问题：

- **`defineAsyncComponent`**：定义一个"异步组件"——Vue 只在需要渲染它的时候才去加载
- **`<Suspense>`**：在异步组件加载期间显示 fallback（骨架屏、加载动画），加载完成后自动切换

### 基础用法

```vue
<script setup>
import { defineAsyncComponent } from 'vue'

// 定义一个异步组件：只在真正需要渲染时才去网络加载
const HeavyChart = defineAsyncComponent(() =>
  import('./HeavyChart.vue')
)

// 也可以配置加载状态
const HeavyEditor = defineAsyncComponent({
  loader: () => import('./HeavyEditor.vue'),
  // 加载中显示的组件（可选）
  loadingComponent: { template: '<div class="skeleton">加载中，请稍候...</div>' },
  // 加载失败显示的组件（可选）
  errorComponent: { template: '<div class="error">加载失败，请重试</div>' },
  // 展示 loadingComponent 前的延迟（ms），避免闪烁
  delay: 200,
  // 超时时间（ms），超时后显示 errorComponent
  timeout: 3000
})
</script>

<template>
  <!-- 用法和普通动态组件完全一样 -->
  <component :is="currentTab === 'chart' ? HeavyChart : HeavyEditor" />
</template>
```

### 搭配 Suspense：更优雅的方案

`defineAsyncComponent` 自带的 loadingComponent 只能处理**单个组件**的加载状态。如果你的页面有**多个异步组件**，希望统一管理加载状态（例如一个整体骨架屏），就用 `<Suspense>`：

```vue
<script setup>
import { ref, defineAsyncComponent } from 'vue'

// 定义两个异步组件
const AsyncDashboard = defineAsyncComponent(() => import('./Dashboard.vue'))
const AsyncChart = defineAsyncComponent(() => import('./Chart.vue'))

const currentView = ref('dashboard')
</script>

<template>
  <div class="async-demo">
    <nav>
      <button @click="currentView = 'dashboard'">仪表盘</button>
      <button @click="currentView = 'chart'">图表</button>
    </nav>

    <!-- Suspense 包裹所有异步内容 -->
    <Suspense>
      <!-- #default：真正要显示的内容（异步加载完成后渲染） -->
      <template #default>
        <component :is="currentView === 'dashboard' ? AsyncDashboard : AsyncChart" />
      </template>

      <!-- #fallback：加载中显示的占位内容 -->
      <template #fallback>
        <div class="loading-skeleton">
          <div class="skeleton-bar" style="width: 60%"></div>
          <div class="skeleton-bar" style="width: 80%"></div>
          <div class="skeleton-bar" style="width: 40%"></div>
          <p style="color: #a0aec0; text-align: center; margin-top: 16px;">
            正在加载组件...
          </p>
        </div>
      </template>
    </Suspense>
  </div>
</template>

<style scoped>
.async-demo nav { display: flex; gap: 8px; margin-bottom: 16px; }
.loading-skeleton { padding: 24px; }
.skeleton-bar {
  height: 16px;
  background: linear-gradient(90deg, #edf2f7 25%, #e2e8f0 50%, #edf2f7 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
  border-radius: 4px;
  margin-bottom: 12px;
}
@keyframes shimmer {
  0% { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
</style>
```

**Suspense 的工作流程**：

```text
1. 用户看到页面 → 异步组件开始加载
2. Suspense 检测到异步组件还没 ready → 显示 #fallback（骨架屏）
3. 异步组件加载完成 → 自动切换到 #default（真实内容）
4. 再切换 Tab → 另一个异步组件加载 → 再次显示 #fallback...
```

> 💬 **老师备注**：`defineAsyncComponent` 和 `<Suspense>` 是 Vue 3 异步加载的"黄金搭档"。前者负责"按需加载"，后者负责"优雅地展示加载过程"。在实际项目中，路由懒加载（第 10 章）就是基于 `defineAsyncComponent` 实现的。现在你只需要记住这个组合的存在，后面会反复用到。

### Suspense 与 KeepAlive 的搭配

两者可以一起使用，顺序是 **`<Suspense>` 包 `<KeepAlive>`**：

```
<Suspense>
  <template #default>
    <KeepAlive>
      <component :is="currentTab" />
    </KeepAlive>
  </template>
  <template #fallback>
    <div>加载中...</div>
  </template>
</Suspense>
```

这样既享受了 KeepAlive 的缓存，又享受了 Suspense 的优雅加载体验。

## 🛠 三、完整可运行示例：Tab 页签切换

```vue
<!-- DynamicTabs.vue -->
<script setup>
import { ref, computed, markRaw } from 'vue'
import { KeepAlive } from 'vue'

// ====== TabA：用户列表 ======
// （为了示例简洁，这里把三个组件内联定义）
const UserList = {
  template: `
    <div class="tab-content">
      <h3>用户管理</h3>
      <ul>
        <li v-for="u in users" :key="u.id">
          {{ u.name }} - {{ u.email }}
        </li>
      </ul>
    </div>
  `,
  setup() {
    const users = [
      { id: 1, name: '张三', email: 'zhangsan@example.com' },
      { id: 2, name: '李四', email: 'lisi@example.com' },
      { id: 3, name: '王五', email: 'wangwu@example.com' }
    ]
    return { users }
  }
}

// ====== TabB：计数器（验证 KeepAlive 保持状态） ======
const Counter = {
  template: `
    <div class="tab-content">
      <h3>计数器（切走再回来，数字不会重置）</h3>
      <p class="count-display">{{ count }}</p>
      <button @click="count++">+1</button>
      <button @click="count--">-1</button>
    </div>
  `,
  setup() {
    const count = Vue.ref(0)
    return { count }
  }
}

// ====== TabC：设置面板 ======
const SettingsPanel = {
  template: `
    <div class="tab-content">
      <h3>系统设置</h3>
      <label><input type="checkbox" v-model="autoSave" /> 自动保存</label>
      <br />
      <label><input type="checkbox" v-model="darkMode" /> 深色模式</label>
      <p>自动保存：{{ autoSave ? '开' : '关' }}</p>
      <p>深色模式：{{ darkMode ? '开' : '关' }}</p>
    </div>
  `,
  setup() {
    const autoSave = Vue.ref(true)
    const darkMode = Vue.ref(false)
    return { autoSave, darkMode }
  }
}

// ====== 标签页配置 ======
const tabs = [
  { id: 'users', label: '用户管理', comp: markRaw(UserList) },
  { id: 'counter', label: '计数器', comp: markRaw(Counter) },
  { id: 'settings', label: '设置', comp: markRaw(SettingsPanel) }
]

const activeId = ref('users')

const activeComp = computed(() => {
  return tabs.find(t => t.id === activeId.value)?.comp
})
</script>

<template>
  <div class="tab-container">
    <!-- 标签导航 -->
    <nav class="tab-nav">
      <button
        v-for="tab in tabs"
        :key="tab.id"
        :class="['tab-btn', { active: activeId === tab.id }]"
        @click="activeId = tab.id"
      >
        {{ tab.label }}
      </button>
    </nav>

    <!-- 动态组件 + 缓存 -->
    <KeepAlive>
      <component :is="activeComp" />
    </KeepAlive>
  </div>
</template>

<style scoped>
.tab-container {
  border: 1px solid #e2e8f0;
  border-radius: 12px;
  overflow: hidden;
  max-width: 600px;
}
.tab-nav {
  display: flex;
  background: #f7fafc;
  border-bottom: 1px solid #e2e8f0;
}
.tab-btn {
  flex: 1;
  padding: 12px 16px;
  border: none;
  background: none;
  cursor: pointer;
  font-size: 14px;
  color: #718096;
  transition: all 0.2s;
  border-bottom: 2px solid transparent;
}
.tab-btn:hover {
  color: #2d3748;
  background: #edf2f7;
}
.tab-btn.active {
  color: #42b883;
  border-bottom-color: #42b883;
  font-weight: 600;
}
.tab-content {
  padding: 24px;
}
.count-display {
  font-size: 48px;
  font-weight: bold;
  color: #42b883;
  text-align: center;
  margin: 16px 0;
}
</style>
```

**运行效果**：
- 切换 Tab，右边组件跟着切
- 切到"计数器"，点 +1 到 5，切到"设置"，再切回"计数器"——数字还是 5（KeepAlive 保持了状态）
- 三个 Tab 各自独立，互不干扰

> 💬 **老师备注**：试试去掉 `<KeepAlive>` 标签，看看计数器数字会不会重置。这个对比让你直观理解 KeepAlive 的作用。

## ⚠️ 四、常见陷阱

### 陷阱 1：KeepAlive 不生效

```
<!-- ❌ KeepAlive 只能包一个直接子节点 -->
<KeepAlive>
  <div>
    <component :is="current" />
  </div>
</KeepAlive>

<!-- ✅ 必须直接包 <component> -->
<KeepAlive>
  <component :is="current" />
</KeepAlive>
```

### 陷阱 2：缓存过多导致内存占用大

KeepAlive 默认缓存所有组件，如果你的 Tab 有 20 个，其中一些带大图表或视频——内存会很高。解决方案：**设置 `:max="5"` 限制缓存数量**，或者用 `:exclude` 排除重组件。

## 🧠 本节小结

- **`<KeepAlive>` 保状态**：包住动态组件后，组件切走不销毁而是缓存，回来时状态原样保留
- **精细控制**：`include` / `exclude` 按名字决定谁被缓存，`max` 限制缓存数量防内存膨胀
- **新生命周期**：被缓存的组件用 `onActivated` / `onDeactivated` 感知"回到前台/切到后台"，比 mounted/unmounted 更贴近真实
- **异步组件 + Suspense**：`defineAsyncComponent` 懒加载大组件，配合 `<Suspense>` 给加载过程一个优雅的 fallback
- **三个注意**：KeepAlive 只对动态组件（`:is`）有效；缓存组件太多会占内存；异步加载失败要有兜底处理
