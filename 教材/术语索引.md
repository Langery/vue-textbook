## 十、贯穿全书的主线

这一本书的 12 章不是 12 个独立话题，而是**一条线**。看懂这条线，比记住每个 API 更有用：

```
第 1 章  跑起来         项目结构 / SFC / ref / 组件
   ↓
第 2 章  看得见         模板语法：插值、条件、列表、key
   ↓
第 3 章  活起来         响应式：ref / reactive / computed / 不可变原则
   ↓
第 4 章  拆得开         组件化：设计原则 / 组合模式 / 组件通信
   ↓
第 5 章  传得对         Props / Emit / v-model
   ↓
第 6 章  管得住         生命周期 / 副作用 / watch 体系
   ↓
第 7 章  复用得漂亮     组合式 API / composables / provide-inject
   ↓
第 8 章  跑得通         路由 + Pinia
   ↓
第 9 章  拿得到         Axios / 拦截器 / 错误处理
   ↓
第 10 章  填得对         表单 / 校验 / 提交
   ↓
第 11 章  测得准         Vitest / 组件测试 / DevTools
   ↓
第 12 章  做得完         Campus2Hand 校园二手集市（前台 + 后台）
```

**11 个章末实战**（P1~P11）就是这条线上的 checkpoint，每个实战都是下一个章的预演：

| 实战 | 名字 | 它是第 12 章的什么 |
|---|---|---|
| P1 | 个人名片站 | 页头页脚 + 组件拆分 |
| P2 | 校园公告板 | 首页列表 + 分类 + 空态 |
| P3 | 小组件库 | 可复用组件 + 弹窗 |
| P4 | 点赞投票器 | 商品口碑 + 状态管理雏形 |
| P5 | 记账小账本 | **购物车的状态逻辑** |
| P6 | 番茄钟 | 计时 + 组件卸载清理 |
| P7 | 本地笔记 | composable 拆分 + 本地持久化 |
| P8 | 迷你店铺导航 | **路由 + Pinia + 守卫** |
| P9 | 每日一言壁纸 | 接口调用 + loading / 错误 |
| P10 | 活动报名表单 | 表单校验 + 防重复提交 |
| P11 | 记账本单测 | 给 P5 补测试 |
