**三、简答题**

**12.** 参考答案：
- 前端路由是指在不刷新页面的情况下，通过监听 URL 变化来切换页面内容的技术。
- 解决的问题：传统多页应用每次跳转都要重新请求 HTML，白屏时间长；SPA 用前端路由实现无刷新切换，体验更流畅。
- Hash 模式：URL 带 `#`，通过 `hashchange` 事件监听，不需要服务器配置。History 模式：URL 干净无 `#`，通过 `pushState` / `popstate` 实现，需要服务器配合（所有路径返回 index.html）。

**13.** 参考答案：

```js
// stores/cart.js
import { ref, computed } from 'vue'
import { defineStore } from 'pinia'

export const useCartStore = defineStore('cart', () => {
  const items = ref([])

  const totalPrice = computed(() =>
    items.value.reduce((sum, item) => sum + item.price * item.quantity, 0)
  )

  function addItem(product) {
    const existing = items.value.find(i => i.id === product.id)
    if (existing) {
      existing.quantity += product.quantity || 1
    } else {
      items.value.push({ ...product, quantity: product.quantity || 1 })
    }
  }

  function removeItem(id) {
    const index = items.value.findIndex(i => i.id === id)
    if (index !== -1) items.value.splice(index, 1)
  }

  function clearCart() {
    items.value = []
  }

  return { items, totalPrice, addItem, removeItem, clearCart }
})
```

**14.** 三个问题：
1. **安装顺序错误**：`app.use(router)` 在 `app.use(pinia)` 之前，守卫里的 `useAuthStore()` 会报错。应该先 `use(pinia)` 再 `use(router)`。
2. **守卫没有返回值**：走到 `if` 分支只调了 `router.push`，没有 `return`，导航可能继续。应该 `return '/login'` 或 `return { path: '/login', query: { redirect: to.fullPath } }`。
3. **登录成功后无回跳**：没有带 `redirect` 参数，用户登录后不知道原本要去哪。应该 `return { path: '/login', query: { redirect: to.fullPath } }`。

修正版本：
```js
// main.js
app.use(pinia)
app.use(router)

// router/index.js
router.beforeEach((to, from) => {
  const auth = useAuthStore()
  if (to.meta.requiresAuth && !auth.isLoggedIn) {
    return { path: '/login', query: { redirect: to.fullPath } }
  }
  return true
})
```

**16.** 参考实现：

```js
// stores/settings.js
import { ref, watch } from 'vue'
import { defineStore } from 'pinia'

export const useSettingsStore = defineStore('settings', () => {
  // 初始化时从 localStorage 恢复
  const theme = ref(localStorage.getItem('app-theme') || 'light')
  const fontSize = ref(localStorage.getItem('app-font-size') || 'medium')

  // 变化时持久化
  watch(theme, v => localStorage.setItem('app-theme', v))
  watch(fontSize, v => localStorage.setItem('app-font-size', v))

  function toggleTheme() {
    theme.value = theme.value === 'light' ? 'dark' : 'light'
  }

  return { theme, fontSize, toggleTheme }
})
```

```vue
<!-- App.vue -->
<script setup>
import { storeToRefs } from 'pinia'
import { useSettingsStore } from './stores/settings'

const settings = useSettingsStore()
const { theme, fontSize } = storeToRefs(settings)
</script>

<template>
  <div :class="[theme, `font-${fontSize}`]">
    <router-view />

    <!-- 设置面板 -->
    <div class="settings-panel">
      <h3>设置</h3>
      <button @click="settings.toggleTheme()">主题：{{ theme }}</button>
      <select v-model="fontSize">
        <option value="small">小</option>
        <option value="medium">中</option>
        <option value="large">大</option>
      </select>
    </div>
  </div>
</template>
```
