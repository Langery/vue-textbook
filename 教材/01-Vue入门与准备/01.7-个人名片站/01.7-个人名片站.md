第一章把"装环境 → 建项目 → 看结构 → 跑组件"整条链路走通了，但每一步都是小片段。这一节我们做点能"拿得出手"的东西：搭一个**个人名片站**——把 Vue 工程里的导航、页脚、页面外壳先立起来。它正是大项目 Campus2Hand 校园二手集市的"公共外壳"原型，后面每个小项目都会挂在同一个壳里长大。

> 🎯 **类比一下**：这个"公共外壳"就像「商场的统一门面」——不管里面开的是奶茶店还是服装店，门头框架、水电管线、消防通道都是一套。P1 名片站先把这个壳搭好，后面 P2 公告板、P3 记账本都是"换个招牌、换批货架"的事。先立骨架，再填血肉，大项目就是这么长出来的。

> 👨🏫 **老湿**：所以千万别小看这节"静态页面"——它练的不是 Vue 语法，而是"一个项目从零到能跑"的完整手感。这个手感，后面每一章都会用到。

<details>
<summary>🧊 深究一下：图片为什么不放 src 里？</summary>

`public/` 目录里的文件会被**原样**复制到网站根目录，引用路径写死（`/images/logo.png`），适合放"不常变、不需要打包处理"的资源；`src/assets/` 里的图片会经过 Vite 打包、加哈希指纹，适合放"会被组件用到、想被优化"的图片。个人名片站这种简单项目，放哪都行，但知道区别能帮你少走弯路。
</details>

## 🎯 项目需求（一句话）

做一个"个人名片站"单页应用：顶部有站点导航，中间是个人名片（头像、昵称、身份、一句签名），底部有页脚，点击按钮能切换签名——全程只用第 1 章已学的内容（Vite 建项目、SFC 三段式、`ref`、插值、组件抽离），不引入任何新库。

### ✅ 验收标准（能跑、能展示）

- [ ] 项目能 `npm run dev` 启动，浏览器打开能看到页面
- [ ] 页面有明显三段结构：顶部导航 / 中间名片 / 底部页脚
- [ ] 名片信息（头像 emoji、昵称、身份、签名）用 `ref` 声明、模板插值渲染，改一处数据页面同步更新
- [ ] 至少抽出一个组件（如 `ProfileCard.vue`），在 `App.vue` 中引用；能向同学说清"谁是被复用的、为什么要抽"
- [ ] 有一个按钮，点击后更换一句个性签名（体验"改 `value`，页面自动更新"）
- [ ] 点击头像 / 状态区可在「在线接单 / 暂不接单」之间切换，状态文案跟着变（纯数据驱动，不写死）

## 🛠 分步提示（3~5 步，含关键代码锚点）

> 以下只给路线和关键锚点，**不贴全量答案**。卡住时回头翻 1.3 / 1.4 / 1.5 对应小节。

### Step 1：用 Vite 建一个干净的 Vue 工程（回顾 1.3）

```bash
npm create vite@latest name-card -- --template vue
cd name-card && npm install && npm run dev
```

把 `App.vue` 里默认的计数器模板、`HelloWorld` 引用和多余样式全部清掉，只留一个最简组件壳。

### Step 2：用 `ref` 把"名片数据"集中声明（回顾 1.5）

把人和站点的信息放进响应式容器，模板只负责展示：

```js
import { ref } from 'vue'

const profile = ref({
  nickname: '小林同学',
  role: '校园闲置主理人',
  avatar: '🧑‍🎓',
  signature: '九成新教材，都是好价出~'
})
const siteName = ref('Campus2Hand · 个人名片站')
```

> 锚点检查：模板里 `{{ siteName }}`、`{{ profile.nickname }}` 能正常渲染，改 `profile.value.nickname` 页面会变——做到这一步就说明 `ref` 用对了。

### Step 3：抽一个 `ProfileCard` 组件（回顾 1.5 "实战 3"）

在 `src/components/` 下新建组件文件，把名片卡片的模板和样式搬进去，再在 `App.vue` 顶部 `import ProfileCard from './components/ProfileCard.vue'`，像用普通标签一样 `<ProfileCard />` 使用它。组件里继续用 `ref` 保存属于自己的数据（如签名列表）。

### Step 4：加一个"换签名"按钮（回顾 1.5 "实战 2"）

给组件加按钮，点击时轮换签名：

```js
const signatureList = ['九成新教材，好价出~', '电车周租，宿舍楼下自提', '吉他换专业课笔记，私聊']
function nextSignature() {
  const idx = signatureList.indexOf(profile.value.signature)
  profile.value.signature = signatureList[(idx + 1) % signatureList.length]
}
```

模板里写 `<button @click="nextSignature">换一句签名</button>`。

### Step 5（进阶锚点）：把"状态"也变成数据

在 `profile` 里加一个 `online` 布尔字段，再准备"在线接单 / 暂不接单"两份文案：点击头像或状态区时 `profile.value.online = !profile.value.online`，模板里用插值把当前状态文案渲染出来——这样"展示什么"完全由 `ref` 数据决定，你已经摸到"数据驱动页面"的门道了（样式绑定要到第 2 章才系统学，这里先不碰）。

**`src/components/ProfileCard.vue`**：

```vue
<script setup>
import { ref } from 'vue'

// defineProps：父组件传进来的数据（回顾 1.5）
const props = defineProps({
  nickname: String,
  role: String,
  avatar: String,
  signature: String,
  online: Boolean
})

// emit：告诉父组件"我想改什么"（回顾 1.5）
const emit = defineEmits(['change-signature', 'toggle-online'])

// 组件自己的数据：签名列表（只有本组件用，不需要父组件传）
const signatureList = [
  '九成新教材，好价出~',
  '电车周租，宿舍楼下自提',
  '吉他换专业课笔记，私聊'
]

function nextSignature() {
  const idx = signatureList.indexOf(props.signature)
  emit('change-signature', signatureList[(idx + 1) % signatureList.length])
}
</script>

<template>
  <div class="card">
    <!-- 点击头像切换在线状态 -->
    <button class="avatar" @click="emit('toggle-online')">{{ avatar }}</button>

    <h2 class="nickname">{{ nickname }}</h2>
    <p class="role">{{ role }}</p>

    <!-- online 是布尔，直接插值显示的是 true/false，用三元换成文案 -->
    <p class="status">{{ online ? '🟢 在线接单中' : '⚪ 暂不接单' }}</p>

    <p class="signature">「{{ signature }}」</p>

    <button class="btn" @click="nextSignature">换一句签名</button>
  </div>
</template>
```

**`src/App.vue`**：

```vue
<script setup>
import { ref } from 'vue'
import ProfileCard from './components/ProfileCard.vue'

// 站点名与页脚年份：都用 ref 存，呼应 Step 5「用数据而不是手写」
const siteName = ref('Campus2Hand · 个人名片站')
const year = ref(new Date().getFullYear())

// 名片数据：改动这个对象，页面就跟着变（回顾 3.x 数据驱动的思路）
const profile = ref({
  nickname: '小林同学',
  role: '校园闲置主理人',
  avatar: '🧑‍🎓',
  signature: '九成新教材，好价出~',
  online: true
})

// 接收子组件的事件（回顾 1.5 emit）
function onChangeSignature(text) {
  profile.value.signature = text
}

function onToggleOnline() {
  profile.value.online = !profile.value.online
}
</script>

<template>
  <div class="page">
    <!-- 顶部导航 -->
    <header class="topbar">
      <span class="brand">{{ siteName }}</span>
      <nav class="nav">
        <a href="#">首页</a>
        <a href="#">我的发布</a>
        <a href="#">关于</a>
      </nav>
    </header>

    <!-- 中间名片 -->
    <main class="main">
      <ProfileCard
        :nickname="profile.nickname"
        :role="profile.role"
        :avatar="profile.avatar"
        :signature="profile.signature"
        :online="profile.online"
        @change-signature="onChangeSignature"
        @toggle-online="onToggleOnline"
      />
    </main>

    <!-- 底部页脚：年份来自数据，不是手写 -->
    <footer class="footer">© {{ year }} Campus2Hand · 学号 20260001</footer>
  </div>
</template>
```

**照着做完可以顺手验证的 4 个知识点**：

| 验证动作 | 观察到什么 | 对应小节 |
|---|---|---|
| 点"换一句签名" | 页面上的签名变了，但组件里的 `signatureList` 没变——数据流是单向的 | 1.5 emit |
| 点头像 | `online` 布尔翻转，状态文案跟着换 | 1.5 布尔插值 |
| 把 `:nickname="profile.nickname"` 改成 `nickname="小林"`（去掉冒号） | 页面仍显示`小林同学`——不加冒号传的是字符串字面量，父组件数据变了它也不动 | 1.5 插值 |
| 删掉 `@change-signature="onChangeSignature"` | 点按钮没反应，控制台无报错——**事件没人监听就静默失效** | 1.5 事件 |

> 💬 **老师备注：这版代码里有一个"故意的坑"**
> 组件里用了 `const props = defineProps(...)`，但模板中直接写 `{{ nickname }}` 而不是 `{{ props.nickname }}`——这是对的，因为 `<script setup>` 会把 `defineProps` 的返回值**自动解构到模板作用域**（Vue 3.5 的响应式 Props 解构特性）。
> 如果你的项目 Vue 低于 3.5，模板里得写 `props.nickname`。**这也是本书要求 Vue ≥ 3.5 的原因之一。**
