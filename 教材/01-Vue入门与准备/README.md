# 第 1 章 Vue 入门与准备

> 课时：4 课时
> 难度：⭐（入门）
> 重要性：🔧 基础（不学不能学后面）

---

## 🎯 本章目标

学完这章，你将能够：

- ✅ 说出 Vue 是什么、它解决什么问题
- ✅ 在自己电脑上**装好开发环境**（Node.js + Vite + VS Code）
- ✅ 用 `npm create vue@latest` 创建项目
- ✅ 认识 Vue 项目的**目录结构**（每个文件夹是干什么的）
- ✅ 写出**第一个 Vue 组件**并跑起来

---

## 🤔 为什么学这章

Vue 是个 JavaScript 框架——**你写 Vue 代码之前，得先有个能跑代码的环境**。

这章不讲"怎么写代码"（那是第 2 章以后的事），而是**把工具准备好**。学完这章，你的电脑就是一个"Vue 工厂"——以后写任何 Vue 项目，都从这里开始。

> 🧑 **小白**：我要学 Vue，怎么第一章不是写代码，而是装 Node.js、Vite？这也太不"酷"了吧？

> 🤖 **Vue 君**：别急，我跑起来需要一台"发动机"——Node.js 就是我的引擎，Vite 是点火开关。没它们，你写了代码我也没法表演。

> 👨🏫 **老湿**：工具顺了，后面每章的代码才能"即写即跑"。这一章花 4 课时，换来后面 12 章的顺畅，值！

## 🛠 本章实战

学完本章，你应该能完成这些事：

1. **打开终端**，输入 `node -v` 能看到 Node.js 版本
2. **打开 VS Code**，安装好 Vue 官方插件（Volar）
3. **执行命令** `npm create vue@latest` 创建一个新项目
4. **运行** `npm run dev` 看到浏览器里的"Welcome to Vue"
5. **修改** `App.vue` 让页面显示 "你好，我是 XXX"（XXX 是你的名字）

## 📖 本章术语表

下表收录本章 1.1~1.7 正文实际讲到的核心术语，按首次出现的节号排序，方便随时回查。

| 术语 | 一句话解释 | 首现节号 |
|---|---|---|
| Vue（Vue.js） | 渐进式 JavaScript 框架，用于构建用户界面，核心是数据驱动视图自动更新。 | 1.1 |
| 渐进式框架 | 核心轻量够用，需要时再按需引入路由、状态管理等全家桶能力。 | 1.1 |
| 声明式渲染 | 只描述页面「该长什么样」，不用手动操作 DOM，由框架负责更新界面。 | 1.1 |
| 响应式 | 数据变化时依赖它的界面自动更新，是 Vue 最核心的「魔法」。 | 1.1 |
| 单文件组件（SFC） | 把模板、脚本、样式写在一个 `.vue` 文件里，一个文件就是一个组件。 | 1.1 |
| Node.js | JavaScript 的运行时环境，让 JS 能在浏览器之外运行，Vue 工程依赖它。 | 1.2 |
| npm | Node.js 自带的包管理器，用来安装、管理项目依赖包。 | 1.2 |
| Vite | 前端开发服务器与构建工具，启动快、支持热更新，官方脚手架用它。 | 1.2 |
| VS Code | 微软出品的免费代码编辑器，本书推荐编写 Vue 项目的工具。 | 1.2 |
| Volar | VS Code 里官方推荐的 Vue 插件，提供模板高亮与类型提示。 | 1.2 |
| Vue DevTools | 浏览器扩展调试工具，可查看组件树、数据状态与性能。 | 1.2 |
| LTS | 长期支持版本，稳定可靠，下载 Node.js 时应优先选择。 | 1.2 |
| `create-vue`（`npm create vue@latest`） | Vue 官方脚手架命令，一条命令生成新项目骨架。 | 1.3 |
| 脚手架 | 自动生成项目目录与配置的工具，免去手动搭环境的重复劳动。 | 1.3 |
| `npm run dev` | 启动项目开发服务器的命令，执行后浏览器自动打开页面。 | 1.3 |
| `main.js` / `App.vue` | `main.js` 是应用入口，`App.vue` 是根组件，整个应用从它开始。 | 1.3 |
| `package.json` / `node_modules` | `package.json` 记录项目依赖与脚本，`node_modules` 存放安装的依赖包。 | 1.3 |
| HMR 热更新 | 改完代码页面即时刷新且不丢状态，是开发体验的关键能力。 | 1.5 |
