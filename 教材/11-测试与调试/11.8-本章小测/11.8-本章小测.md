## 📊 参考答案

### 选择题

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | **C** | 单元测试是金字塔基石，数量最多、速度最快、成本最低。A 错在"真实"；B 错在 E2E 最慢；D 错在单元测试应占 60%~70%。 |
| 2 | **B** | Vue 的 DOM 更新是异步的，trigger 后必须 await 等更新完成。 |
| 3 | **B** | `return false` 阻止错误继续向上冒泡。 |
| 4 | **C** | `console.table()` 将数组或对象以表格形式输出，直观易读。 |

| 题号 | 答案 | 解析 |

### 简答题

**13.** 参考答案：

`data-test` 属性是专门为测试设计的标记，与样式和结构解耦。用 `class` 或标签名查找元素的问题是：改样式（比如 `class="btn"` 改成 `class="button"`）或改结构（比如 `<button>` 换成 `<a>`）会导致测试挂掉，即使功能完全没变。`data-test` 属性的命名约定明确表达了"这是给测试用的"，团队成员不会因为改样式而误改它。

**14.** 参考答案：

在设置页面中，用自定义的 `ErrorBoundary` 组件包裹"修改头像"模块。`ErrorBoundary` 内部使用 `onErrorCaptured` 钩子捕获子组件抛出的错误并 `return false` 阻止向上传播。当图片裁剪库崩溃时，`ErrorBoundary` 显示降级 UI（如"头像编辑功能暂时不可用，请稍后重试"），但设置页面的其他功能（修改昵称、修改密码等）不受影响，正常可用。

### 编程题

**15.** 参考答案：

```vue
<!-- TodoItem.vue -->
<script setup>
defineProps({
  text: { type: String, required: true },
  done: { type: Boolean, default: false }
})
const emit = defineEmits(['toggle', 'delete'])
</script>

<template>
  <div class="todo-item">
    <span
      data-test="text"
      :class="{ done }"
      @click="emit('toggle')"
    >
      {{ text }}
    </span>
    <button data-test="delete-btn" @click="emit('delete')">删除</button>
  </div>
</template>

<style scoped>
.done { text-decoration: line-through; color: #999; }
</style>
```

```js
// __tests__/TodoItem.test.js
import { mount } from '@vue/test-utils'
import TodoItem from '../TodoItem.vue'

describe('TodoItem', () => {
  test('渲染 text', () => {
    const wrapper = mount(TodoItem, {
      props: { text: '学 Vue 3' }
    })
    expect(wrapper.find('[data-test="text"]').text()).toBe('学 Vue 3')
  })

  test('done 默认 false，无 .done 类', () => {
    const wrapper = mount(TodoItem, {
      props: { text: '学 Vue 3' }
    })
    expect(wrapper.find('[data-test="text"]').classes()).not.toContain('done')
  })

  test('done 为 true 时有 .done 类', () => {
    const wrapper = mount(TodoItem, {
      props: { text: '学 Vue 3', done: true }
    })
    expect(wrapper.find('[data-test="text"]').classes()).toContain('done')
  })

  test('点击文字触发 toggle', async () => {
    const wrapper = mount(TodoItem, {
      props: { text: '学 Vue 3' }
    })
    await wrapper.find('[data-test="text"]').trigger('click')
    expect(wrapper.emitted('toggle')).toHaveLength(1)
  })

  test('点击删除按钮触发 delete', async () => {
    const wrapper = mount(TodoItem, {
      props: { text: '学 Vue 3' }
    })
    await wrapper.find('[data-test="delete-btn"]').trigger('click')
    expect(wrapper.emitted('delete')).toHaveLength(1)
  })
})
```
