## 🔑 一、Axios 请求封装——让每个请求自动带 token

每个接口都要手动在 Header 里加 token 太麻烦了，用**请求拦截器**统一处理：

```js
// src/api/index.js
import axios from 'axios'
import { useUserStore } from '@/stores/user'
import { ElMessage } from 'element-plus'
import router from '@/router'

// 创建 Axios 实例
const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || '/api',
  timeout: 10000  // 10 秒超时
})

// ==================== 请求拦截器 ====================
request.interceptors.request.use(
  (config) => {
    const userStore = useUserStore()
    if (userStore.token) {
      config.headers.Authorization = `Bearer ${userStore.token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

// ==================== 响应拦截器 ====================
request.interceptors.response.use(
  (response) => {
    // 后端返回格式：{ code: 0, message: 'ok' }
    const res = response.data
    if (res.code !== 0 && res.code !== undefined) {
      // 业务错误（如"用户名已存在"）
      ElMessage.error(res.message || '请求失败')
      return Promise.reject(new Error(res.message))
    }
    return res
  },
  (error) => {
    // HTTP 状态码错误（401/403/500 等）
    if (error.response) {
      const { status } = error.response
      if (status === 401) {
        // token 过期或无效
        ElMessage.error('登录已过期，请重新登录')
        const userStore = useUserStore()
        userStore.logout()
        router.push('/login')
      } else if (status === 403) {
        ElMessage.error('没有权限访问')
      } else {
        ElMessage.error(`服务器错误（${status}）`)
      }
    } else {
      ElMessage.error('网络连接失败，请检查网络')
    }
    return Promise.reject(error)
  }
)

export default request
```

### 拦截器流程图

```text
请求发出前
  → 请求拦截器
  → 自动加 Authorization Header
  → 发送请求
  → 响应回来
  → 响应拦截器
  → code !== 0 ? 弹错误提示 : 返回 data
  → HTTP 错误 ? 401 → 清除 token + 跳转登录
```

## 🔧 二、api/auth.js —— 登录接口封装

```js
// src/api/auth.js
import request from './index'

// 登录
export const login = (data) => {
  return request({
    url: '/auth/login',
    method: 'post',
    data
  })
}

// 退出登录
export const logout = () => {
  return request({
    url: '/auth/logout',
    method: 'post'
  })
}

// 获取当前用户信息
export const getUserInfo = () => {
  return request({
    url: '/auth/userinfo',
    method: 'get'
  })
}
```

> 💬 **老师备注**：真实的后端接口需要你自己用 Node.js / Express / Koa 写，或者用 Mock 数据。课设阶段可以用 `json-server` 快速搭建一个假后端，也可以直接在接口函数里返回假数据。

## 🛠 三、登录页面（LoginView.vue）——完整代码

```vue
<!-- src/views/login/LoginView.vue -->
<script setup>
import { ref, reactive } from 'vue'
import { useRouter, useRoute } from 'vue-router'
import { useUserStore } from '@/stores/user'
import { ElMessage } from 'element-plus'

const router = useRouter()
const route = useRoute()
const userStore = useUserStore()

// 如果已登录，直接跳转
if (userStore.token) {
  router.push(route.query.redirect || '/dashboard')
}

// ==================== 表单数据 ====================
const loginForm = reactive({
  username: '',
  password: ''
})

// ==================== 表单验证规则 ====================
const rules = {
  username: [
    { required: true, message: '请输入用户名', trigger: 'blur' }
  ],
  password: [
    { required: true, message: '请输入密码', trigger: 'blur' },
    { min: 6, message: '密码至少 6 位', trigger: 'blur' }
  ]
}

// ==================== 登录逻辑 ====================
const loginFormRef = ref(null)
const loading = ref(false)

const handleLogin = async () => {
  // 1. 表单验证
  await loginFormRef.value.validate(async (valid) => {
    if (!valid) return

    loading.value = true
    try {
      // 2. 调用 Pinia action 登录
      await userStore.login({
        username: loginForm.username,
        password: loginForm.password
      })

      ElMessage.success('登录成功')

      // 3. 跳转到目标页或首页
      const redirect = route.query.redirect || '/dashboard'
      router.push(redirect)
    } catch (error) {
      // 登录失败（账号密码错误等）
      ElMessage.error(error.message || '登录失败')
    } finally {
      loading.value = false
    }
  })
}
</script>

<template>
  <div class="login-container">
    <div class="login-card">
      <h2>「Campus2Hand」校园二手集市</h2>

      <el-form
        ref="loginFormRef"
        :model="loginForm"
        :rules="rules"
        label-width="80px"
        size="large"
      >
        <el-form-item label="用户名" prop="username">
          <el-input
            v-model="loginForm.username"
            placeholder="请输入用户名"
            prefix-icon="User"
          />
        </el-form-item>

        <el-form-item label="密码" prop="password">
          <el-input
            v-model="loginForm.password"
            type="password"
            placeholder="请输入密码"
            prefix-icon="Lock"
            show-password
            @keyup.enter="handleLogin"
          />
        </el-form-item>

        <el-form-item>
          <el-button
            type="primary"
            style="width: 100%"
            :loading="loading"
            @click="handleLogin"
          >
            登录
          </el-button>
        </el-form-item>
      </el-form>
    </div>
  </div>
</template>

<style scoped>
.login-container {
  height: 100vh;
  display: flex;
  align-items: center;
  justify-content: center;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
.login-card {
  width: 420px;
  padding: 40px;
  background: white;
  border-radius: 8px;
  box-shadow: 0 2px 12px rgba(0, 0, 0, 0.1);
}
.login-card h2 {
  text-align: center;
  margin-bottom: 30px;
  color: #303133;
}
</style>
```

## 🧠 本节小结

- **请求拦截器统一带 token**：`request.interceptors.request.use` 里从 `useUserStore()` 取 token，有则写 `config.headers.Authorization = \`Bearer ${token}\``，全项目接口免手写 Header
- **响应拦截器分两类错误**：`code !== 0` 是后端业务错误（弹 `res.message`）；HTTP 401 是登录失效（清 token + 跳 `/login`），403 无权限、其他 5xx 与断网各自提示
- **接口封装薄薄一层**：`api/auth.js` 只负责"方法 + URL + 参数"，复用同一个 `request` 实例，业务层不用关心拦截逻辑
- **登录页三件套**：已登录直接跳 `redirect`；`el-form` rules 校验用户名必填/密码 6 位；`loading` 状态防重复提交，`finally` 里复位
- **整条链路**：表单 → `userStore.login()`（内部走封装接口）→ 成功 `ElMessage` + `router.push(redirect || '/dashboard')` → 失败只弹错不跳转
