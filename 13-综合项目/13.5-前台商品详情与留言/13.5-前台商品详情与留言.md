## 🤔 一、从"列表"到"详情"：动态路由参数

回忆 9.3：路径里的冒号片段是**参数占位符**。

```js
// 13.3 已经配好的路由
{
  path: '/goods/:id',
  name: 'goods-detail',
  component: () => import('@/views/front/GoodsDetailView.vue'),
  meta: { title: '闲置物品详情', requiresAuth: false }
}
```

`/goods/1`、`/goods/2`、`/goods/99` 全都命中**同一个组件**，差别只在 `id` 的取值。这就是动态路由的价值：不用为每件闲置物品写一个页面。

### 1.1 让卡片可点击

最简单的做法是用 `router-link` 把整张卡片包起来（`src/components/GoodsCard.vue` 里改一行结构）：

```vue
<!-- src/components/GoodsCard.vue（template 部分） -->
<template>
  <router-link :to="`/goods/${goods.id}`" class="card-link">
    <el-card class="goods-card" shadow="hover">
      <!-- …… 卡片内容不变 …… -->
    </el-card>
  </router-link>
</template>

<style scoped>
/* 去掉链接默认样式，让整卡可点 */
.card-link { text-decoration: none; color: inherit; display: block; }
</style>
```

> 💬 **老师备注**：也可以用 `@click="router.push(...)"`，但 `<router-link>` 会渲染成真正的 `<a>`，支持"新标签页打开""悬停看地址"，语义更好。卡片类跳转优先用它。

## 💡 二、在详情页取到"这一条"

新建 `src/views/front/GoodsDetailView.vue`，第一件事是取参、定位数据：

```vue
<script setup>
import { ref, computed } from 'vue'
import { useRoute } from 'vue-router'
import { ElMessage } from 'element-plus'
import { goodsList } from '@/data/goods'

const route = useRoute()

// 关键：params.id 是字符串，必须转成数字再比较
const good = computed(() =>
  goodsList.find((g) => g.id === Number(route.params.id))
)
</script>
```

三个细节值得停一下：

| 细节 | 为什么 |
|---|---|
| `Number(route.params.id)` | URL 里的参数**永远是字符串**，`1 === '1'` 恒为 `false`（陷阱 1） |
| 用 `computed` 而不是 `onMounted` 里赋值 | 从 `/goods/1` 跳到 `/goods/2` 时组件会被复用，`onMounted` 不会再执行；`computed` 会随 `route.params` 自动重算（陷阱 2） |
| `find` 找不到时返回 `undefined` | 正好可以用 `v-if="good"` 做兜底，不必额外抛错 |

## 🛠 三、页面结构与兜底

完整的 `GoodsDetailView.vue`：

```vue
<!-- src/views/front/GoodsDetailView.vue -->
<script setup>
import { ref, computed } from 'vue'
import { useRouter, useRoute } from 'vue-router'
import { ElMessage } from 'element-plus'
import { goodsList } from '@/data/goods'

const route = useRoute()
const router = useRouter()

const good = computed(() => goodsList.find((g) => g.id === Number(route.params.id)))

// ---------- 留言（本地模拟） ----------
const newComment = ref('')
const comments = ref([
  { id: 1, user: '阿May', content: '还在吗？能不能小刀一点～', time: '09-08 21:10' },
  { id: 2, user: '豆豆', content: '同问，方便今晚宿舍楼下自提吗？', time: '09-09 10:02' }
])

function submitComment() {
  const text = newComment.value.trim()
  if (!text) {
    ElMessage.warning('留言内容不能为空')
    return
  }
  comments.value.unshift({
    id: Date.now(),
    user: '我',
    content: text,
    time: '刚刚'
  })
  newComment.value = ''
  ElMessage.success('留言成功')
}
</script>

<template>
  <div class="detail">
    <!-- 找到了：正常渲染 -->
    <template v-if="good">
      <div class="main">
        <div class="cover">
          <img v-if="good.cover" :src="good.cover" :alt="good.title" />
          <div v-else class="cover-placeholder">暂无图片</div>
        </div>

        <div class="info">
          <h2>{{ good.title }}</h2>
          <p class="price">￥{{ good.price }}</p>

          <div class="tags">
            <el-tag size="small" type="info">{{ good.condition }}</el-tag>
            <el-tag size="small">{{ good.category }}</el-tag>
          </div>

          <p class="seller">卖家：@{{ good.seller }}</p>
          <p class="desc">{{ good.desc }}</p>

          <el-button type="primary" @click="ElMessage.info('已通知卖家，请等待回复')">
            联系卖家
          </el-button>
        </div>
      </div>

      <!-- 留言区 -->
      <div class="comments">
        <h3>留言（{{ comments.length }}）</h3>

        <div class="comment-form">
          <el-input
            v-model="newComment"
            placeholder="想问点什么？比如成色、能否自提……"
            maxlength="100"
            show-word-limit
          />
          <el-button type="primary" @click="submitComment">发表</el-button>
        </div>

        <ul class="comment-list">
          <li v-for="c in comments" :key="c.id">
            <div class="comment-head">
              <strong>@{{ c.user }}</strong>
              <span class="time">{{ c.time }}</span>
            </div>
            <p>{{ c.content }}</p>
          </li>
        </ul>
      </div>
    </template>

    <!-- 没找到：兜底 -->
    <el-empty v-else description="这件闲置可能已被卖掉或下架">
      <el-button type="primary" @click="router.push('/')">回首页逛逛</el-button>
    </el-empty>
  </div>
</template>

<style scoped>
.detail { max-width: 960px; margin: 0 auto; padding: 16px; }
.main { display: flex; gap: 24px; }
.cover img { width: 360px; height: 240px; object-fit: cover; border-radius: 6px; }

  width: 360px; height: 240px; display: flex; align-items: center; justify-content: center;
  background: #f5f7fa; color: #c0c4cc; border-radius: 6px;
}
```

## 🔑 四、留言交互：本地读写

留言这一版的定位是"**把交互跑通**"，所以：

- 数据放在 `comments = ref([...])` 里（本地初始两条），刷新会重置
- 发表时先做**非空校验**（`trim()` 后为空就 `ElMessage.warning` 提示并 `return`）
- 新留言用 `unshift` 放到**列表顶部**（最新在前，符合留言区习惯）
- 提交后清空输入框并给一条成功提示

等 13.11 后台接口就绪，只需把 `comments` 换成"按 id 请求留言 + 提交接口"两个调用，页面结构与校验逻辑原封不动。

## ⚠️ 五、常见陷阱

### 陷阱 1：拿字符串参数直接和数字比较

```js
// ❌ route.params.id 是 '1'（字符串），恒为 false → 永远进兜底
const good = goodsList.find((g) => g.id === route.params.id)

// ✅ 先转换类型
const good = goodsList.find((g) => g.id === Number(route.params.id))
```

### 陷阱 2：用 `onMounted` 赋值，切下一条时页面不变

```js
// ❌ 从 /goods/1 跳到 /goods/2，组件被复用，onMounted 不再执行 → 页面还是旧数据
const good = ref(null)
onMounted(() => { good.value = goodsList.find((g) => g.id === Number(route.params.id)) })

// ✅ 用 computed 跟随 route.params 自动重算
const good = computed(() => goodsList.find((g) => g.id === Number(route.params.id)))
```

### 陷阱 3：留言用 `v-html` 渲染

```html
<!-- ❌ 用户输入的内容直接当 HTML 解析，有 XSS 风险 -->
<p v-html="c.content"></p>

<!-- ✅ 插值渲染，Vue 会自动转义 -->
<p>{{ c.content }}</p>
```

留言的 `:key` 也别用 `index`——发表后 `unshift` 会让所有 index 后移，DOM 复用错位（同 13.4 陷阱 1，这里是 `c.id`）。

## 🧠 本节小结

- **动态路由 `/goods/:id`**：一个组件承载 N 个详情页，参数从 `route.params.id` 取，**永远是字符串**
- **详情取数用 `computed` + `find`**：既避免"组件复用不更新"，又让 id 非法时自然得到 `undefined`
- **兜底不能省**：`v-if / v-else` + `el-empty`，闲置被卖掉或下架时别让用户看到白屏
- **留言本地交互**：`ref` 数组 + `unshift` 发表 + 非空校验 + 清空输入；`key` 用 `c.id`，渲染用插值而非 `v-html`
- **数据源升级路径**：本节仍是本地 mock，13.10 后换成接口，页面结构与校验逻辑保持不变
