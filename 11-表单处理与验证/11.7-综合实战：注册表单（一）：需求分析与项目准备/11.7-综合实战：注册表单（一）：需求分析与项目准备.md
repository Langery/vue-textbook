## 🤔 一、需求分析：做一个什么样的注册表单？

咱们来做一个"像样"的注册表单。什么叫"像样"？不是那种输入框 + 一个按钮就完事的，而是具备以下特性：

| 特性 | 说明 |
|---|---|
| **字段** | 用户名、手机号、邮箱、密码、确认密码、同意用户协议 |
| **实时验证** | 每个字段失焦时立即验证并显示错误 |
| **异步校验** | 用户名和手机号失焦后调接口检查是否已被注册（下一节实现） |
| **密码强度** | 输入密码时实时显示强度等级（弱/中/强），用颜色和进度条反馈 |
| **密码可见切换** | 点击小眼睛图标切换密码明文/密文 |
| **提交状态** | 提交中按钮禁用 + 显示"提交中..."，防止重复提交 |
| **成功/失败处理** | 成功后清空表单并提示，失败后保留数据并显示后端错误 |
| **协议勾选** | 未勾选协议时提交按钮不可用 |

## 🛠 二、第一步：搭建项目基础

### 2.1 安装依赖

```bash
npm install vee-validate@4 @vee-validate/rules @vueuse/core
```

- `vee-validate@4`：表单验证
- `@vee-validate/rules`：内置规则
- `@vueuse/core`：用里面的 `useDebounceFn` 给异步校验加防抖

### 2.2 规则注册（全局）

建议在项目的 `main.js` 或 `plugins/vee-validate.js` 里统一注册：

```js
// plugins/vee-validate.js
import { defineRule } from 'vee-validate'
import * as rules from '@vee-validate/rules'

// 注册全部内置规则（开发阶段图省事，生产环境建议按需引入）
Object.keys(rules).forEach(rule => {
  defineRule(rule, rules[rule])
})

// --- 自定义规则 ---

// 手机号
defineRule('phone', (value) => {
  if (!value) return true
  if (!/^1[3-9]\d{9}$/.test(value)) return '请输入正确的 11 位手机号'
  return true
})

// 密码强度（至少 8 位，含数字+字母）
defineRule('passwordStrength', (value) => {
  if (!value) return true
  if (value.length < 8) return '密码至少 8 位'
  if (!/[a-zA-Z]/.test(value) || !/\d/.test(value)) return '密码必须包含数字和字母'
  return true
})
```

### 2.3 main.js 引入

```js
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import './plugins/vee-validate'  // 引入规则注册

createApp(App).mount('#app')
```

## 💡 三、第二步：密码强度组件

先做一个独立的密码强度指示器组件，它接收密码字符串，计算强度并渲染进度条。

```vue
<!-- components/PasswordStrength.vue -->
<script setup>
import { computed } from 'vue'

const props = defineProps({
  password: { type: String, default: '' }
})

// 强度计算：0=空, 1=弱, 2=中, 3=强
const strength = computed(() => {
  const pwd = props.password
  if (!pwd) return 0

  let score = 0
  // 长度 ≥ 8 → +1 分
  if (pwd.length >= 8) score++
  // 包含数字 → +1 分
  if (/\d/.test(pwd)) score++
  // 包含字母 → +1 分
  if (/[a-zA-Z]/.test(pwd)) score++
  // 包含特殊字符 → +1 分
  if (/[!@#$%^&*(),.?":{}|<>]/.test(pwd)) score++

  // 映射到 0~3
  if (score <= 1) return 1    // 弱
  if (score === 2) return 2   // 中
  return 3                     // 强
})

const strengthText = computed(() => {
  return ['', '弱', '中', '强'][strength.value]
})

const strengthColor = computed(() => {
  return ['', '#e74c3c', '#f39c12', '#27ae60'][strength.value]
})

const barWidth = computed(() => {
  return (strength.value / 3) * 100 + '%'
})
</script>

<template>
  <div class="password-strength" v-if="password">
    <div class="bar-bg">
      <div
        class="bar-fill"
        :style="{ width: barWidth, backgroundColor: strengthColor }"
      />
    </div>
    <span class="label" :style="{ color: strengthColor }">
      {{ strengthText }}
    </span>
  </div>
</template>

<style scoped>
.password-strength {
  display: flex;
  align-items: center;
  gap: 8px;
  margin-top: 4px;
}
.bar-bg {
  flex: 1;
  height: 6px;
  background: #eee;
  border-radius: 3px;
  overflow: hidden;
}
.bar-fill {
  height: 100%;
  border-radius: 3px;
  transition: width 0.3s, background-color 0.3s;
}
.label {
  font-size: 12px;
  font-weight: bold;
  min-width: 24px;
}
</style>
```

这个组件的设计思路：
- 纯展示组件，不操作任何数据
- 根据密码字符的多样性计算分数，映射到"弱/中/强"三个等级
- 用 CSS transition 让进度条颜色和宽度变化更平滑

## 🧠 本节小结

- **先需求后代码**：真实表单先用特性表把字段（6 项）、实时验证、异步查重、密码强度、密码可见、提交三态、协议联动列清楚，再动手写
- **依赖三件套**：`vee-validate@4` + `@vee-validate/rules` + `@vueuse/core`；`plugins/vee-validate.js` 统一注册内置与自定义规则，`main.js` 引入一次
- **规则注册分场景**：开发图省事可 `Object.keys(rules).forEach` 全量注册；生产建议按需 `defineRule` 引入用到的规则
- **纯展示组件原则**：`PasswordStrength` 只收 `password` prop、用 computed 输出强度，不碰业务数据——可复用、好测试
- **强度评分套路**：长度 + 数字 + 字母 + 特殊字符四条件打分，映射弱/中/强三档，进度条宽度与颜色反馈
