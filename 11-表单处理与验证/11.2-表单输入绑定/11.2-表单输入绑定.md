## 🤔 一、text 和 textarea

这是最常用的两种，也是最简单的：

```vue
<script setup>
import { ref } from 'vue'

const text = ref('')
const message = ref('')
</script>

<template>
  <!-- 单行文本 -->
  <input type="text" v-model="text" placeholder="输入点什么" />

  <!-- 多行文本 -->
  <textarea v-model="message" placeholder="写点什么"></textarea>

  <p>输入内容：{{ text }}</p>
  <p>多行内容：{{ message }}</p>
</template>
```

注意：textarea 不支持插值写法 `{{ }}`，必须用 `v-model`。

> 💬 **老师备注**：早期 HTML 中 textarea 的默认值是写在标签中间的，但 Vue 里统一用 `v-model`，不要混用 `<textarea v-model="msg">{{ msg }}</textarea>`。

## 💡 二、checkbox

checkbox 有两种模式，取决于 `v-model` 绑定的变量类型：

### 2.1 单个 checkbox → 布尔值

```
<script setup>
import { ref } from 'vue'
const agreed = ref(false)
</script>

<template>
  <input type="checkbox" v-model="agreed" id="agree" />
  <label for="agree">我同意用户协议</label>
  <p>状态：{{ agreed }}</p>  <!-- true 或 false -->
</template>
```

### 2.2 多个 checkbox 同组 → 数组

```vue
<script setup>
import { ref } from 'vue'
const hobbies = ref([])
</script>

<template>
  <label><input type="checkbox" v-model="hobbies" value="篮球" /> 篮球</label>
  <label><input type="checkbox" v-model="hobbies" value="足球" /> 足球</label>
  <label><input type="checkbox" v-model="hobbies" value="游泳" /> 游泳</label>

  <p>你的爱好：{{ hobbies }}</p>
  <!-- 选中篮球和游泳 → ["篮球", "游泳"] -->
</template>
```

关键点：同一组的 checkbox 必须**绑定同一个数组**，每个 checkbox 的 `value` 就是被选中时加入数组的值。

### 2.3 true-value / false-value

默认情况下，单个 checkbox 的选中值是 `true`，未选中是 `false`。如果你想自定义这两个值（比如选中时存 `'yes'`），用 `true-value` 和 `false-value`：

```
<input
  type="checkbox"
  v-model="agree"
  true-value="yes"
  false-value="no"
/>
<!-- 选中 → agree === 'yes'，未选中 → agree === 'no' -->
```

## 💡 三、radio

radio 的用法和"同组的 checkbox"很像，但 `v-model` 绑定的是**字符串**而不是数组：

```vue
<script setup>
import { ref } from 'vue'
const gender = ref('')
</script>

<template>
  <label><input type="radio" v-model="gender" value="male" /> 男</label>
  <label><input type="radio" v-model="gender" value="female" /> 女</label>
  <label><input type="radio" v-model="gender" value="other" /> 其他</label>

  <p>性别：{{ gender }}</p>
</template>
```

同一组的 radio 绑定同一个 `v-model`，每个 radio 的 `value` 就是选中时的值。

## 💡 四、select

### 4.1 单选（默认）

```
<script setup>
import { ref } from 'vue'
const city = ref('')
</script>

<template>
  <select v-model="city">
    <option disabled value="">请选择城市</option>
    <option value="beijing">北京</option>
    <option value="shanghai">上海</option>
    <option value="guangzhou">广州</option>
  </select>

  <p>所选城市：{{ city }}</p>
</template>
```

### 4.2 多选

加 `multiple` 属性后，`v-model` 绑定数组：

```vue
<select v-model="cities" multiple>
  <option value="beijing">北京</option>
  <option value="shanghai">上海</option>
  <option value="guangzhou">广州</option>
</select>
```

### 4.3 用 v-for 渲染选项

实战中选项通常来自后端数据，用 `v-for` 渲染：

```
<script setup>
import { ref } from 'vue'

const selected = ref('')
const options = ref([
  { id: 1, label: '前端开发' },
  { id: 2, label: '后端开发' },
  { id: 3, label: 'UI 设计' }
])
</script>

<template>
  <select v-model="selected">
    <option disabled value="">请选择职位</option>
    <option
      v-for="item in options"
      :key="item.id"
      :value="item.id"
    >
      {{ item.label }}
    </option>
  </select>
</template>
```

### 4.4 value 绑定对象

`option` 的 `value` 不限于字符串，用 `v-bind:value` 可以绑定任意类型：

```vue
<select v-model="selected">
  <option
    v-for="item in options"
    :key="item.id"
    :value="item"   <!-- 绑定整个对象 -->
  >
    {{ item.label }}
  </option>
</select>
<!-- selected 是整个 { id: 2, label: '后端开发' } 对象 -->
```

> 💬 **老师备注**：如果你的选项数据包含额外字段（比如 `dept_id`、`level`），推荐绑定整个对象，这样后续处理时不用再根据 ID 去查数据。

## 🛠 五、完整示例：用户信息表单

把前面五种输入串起来：

```
<script setup>
import { ref } from 'vue'

const form = ref({
  username: '',
  bio: '',
  agreed: false,
  hobbies: [],
  gender: '',
  city: ''
})

const cityOptions = ['北京', '上海', '广州', '深圳', '杭州']

function handleSubmit() {
  console.log('提交数据：', form.value)
}
</script>

<template>
  <form @submit.prevent="handleSubmit">
    <!-- text -->
    <div>
      <label>用户名：</label>
      <input v-model.trim="form.username" placeholder="请输入用户名" />
    </div>

    <!-- textarea -->
    <div>
      <label>个人简介：</label>
      <textarea v-model="form.bio" rows="3"></textarea>
    </div>

    <!-- checkbox 单选 -->
    <div>
      <label>
        <input type="checkbox" v-model="form.agreed" />
        我同意用户协议
      </label>
    </div>

    <!-- checkbox 多选 -->
    <div>
      <label>爱好：</label>
      <label><input type="checkbox" v-model="form.hobbies" value="阅读" /> 阅读</label>
      <label><input type="checkbox" v-model="form.hobbies" value="运动" /> 运动</label>
      <label><input type="checkbox" v-model="form.hobbies" value="旅行" /> 旅行</label>
    </div>

    <!-- radio -->
    <div>
      <label>性别：</label>
      <label><input type="radio" v-model="form.gender" value="男" /> 男</label>
      <label><input type="radio" v-model="form.gender" value="女" /> 女</label>
    </div>

    <!-- select -->
    <div>
      <label>城市：</label>
      <select v-model="form.city">
        <option disabled value="">请选择</option>
        <option v-for="c in cityOptions" :key="c" :value="c">{{ c }}</option>
      </select>
    </div>

    <button type="submit">提交</button>
  </form>
</template>
```

## ⚠️ 六、常见陷阱

### 陷阱 1：checkbox 绑了数组但忘了 value 属性

```vue
<!-- ❌ 选中后数组里加的是 "on"（浏览器默认 value） -->
<label><input type="checkbox" v-model="hobbies" /> 篮球</label>

<!-- ✅ 必须显式指定 value -->
<label><input type="checkbox" v-model="hobbies" value="篮球" /> 篮球</label>
```

### 陷阱 2：select 的初始值不匹配

```
<select v-model="city">
  <option value="beijing">北京</option>
</select>
<!-- city 初始值为 ''，没有匹配的 option，浏览器显示空白 -->
```

解决方案：加一个 `disabled` 的 option 作为占位提示：

```vue
<option disabled value="">请选择城市</option>
```

### 陷阱 3：radio 同组但 v-model 不同

```
<!-- ❌ 这两个 radio 互不影响，因为 v-model 不一样 -->
<input type="radio" v-model="gender1" value="male" />
<input type="radio" v-model="gender2" value="female" />
```

radio 靠 `v-model` 同一变量来互斥，不是靠 `name` 属性（Vue 里 `name` 可选）。

## 🧠 本节小结

- **text / textarea**：字符串一对一绑定；textarea 不支持 `{{ }}` 插值，必须用 `v-model`
- **checkbox 两种模式**：单个绑布尔；同组多个绑同一数组，每个 checkbox 必须显式写 `value`，否则存进数组的是浏览器默认值 "on"
- **true-value / false-value**：自定义 checkbox 选中/未选中时写入的值（如 `'yes'` / `'no'`）
- **radio**：同组绑定**同一个** v-model 变量即互斥（不靠 name），绑定的值等于选中项的 `value`
- **select**：单选绑字符串、`multiple` 多选绑数组；选项用 `v-for` 渲染，`:value` 可绑定整个对象（选项带额外字段时推荐）
- **坑位提醒**：select 初始值与选项不匹配会显示空白，用 `<option disabled value="">` 占位
