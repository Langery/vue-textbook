## 🎯 项目需求（一句话）

做一个"跳蚤市集活动报名"表单：姓名、手机号、想报名的场次（下拉）、是否带闲置物品（勾选）、备注（可选）；带必填与手机号格式校验，提交时 loading + 防重复，成功后清空表单并展示"报名成功"卡片——全程只用第 11 章已学的 VeeValidate 能力（或课堂 11.3 的手写验证框架，二选一），并仿照 11.9 把逻辑抽成 composable。

### ✅ 验收标准（能跑、能展示）

- [ ] 项目能 `npm run dev` 启动，页面是一张完整的"活动报名"表单
- [ ] 姓名为空失焦时报"必填"；手机号格式不对时报错；场次未选时报"请选择场次"
- [ ] 提交按钮点击后进入 loading（文案变"提交中…"）并禁止重复点击
- [ ] 模拟提交成功（0.8 秒）后：按钮恢复、表单清空、页面显示"报名成功，活动前一天短信提醒"
- [ ] 表单的校验 + 提交逻辑抽在 `composables/useSignup.js` 里，`SignupForm.vue` 只负责模板
- [ ] 能向同学讲清：`handleSubmit` 返回的函数为什么能安全地做 loading / 防重复？`resetForm` 之后校验状态为什么也要一起清掉？

## 🛠 分步提示（3~5 步，含关键代码锚点）

> 以下只给路线和关键锚点，**不贴全量答案**。卡住时回头翻 11.4 / 11.5 / 11.6 / 11.7 / 11.9 对应小节。

### Step 1：注册全局规则（回顾 11.5 / 11.7）

在 `main.js`（或独立 `rules.js`）里用 `defineRule` 注册两条规则：`required`（非空）与 `phone`（手机号格式，可参考 11.7 的课堂实现），再用 11.5 的方式全局 `extend` 或按需注册。锚点检查：任意输入框给 `rules="required"` 后，清空失焦即报"必填"。

### Step 2：搭 `useForm` 骨架（回顾 11.4 / 11.6）

字段定为 `name`、`phone`、`session`（场次）、`bringItem`（是否带闲置，布尔）、`remark`（备注）。用 `useForm({ validationSchema: {...} })` 声明校验规则（schema 形式或每条规则字符串均可，按课堂习惯来），解出 `handleSubmit`、`errors`、`values`、`resetForm`。

### Step 3：写"报名"提交逻辑（回顾 11.6 的 loading 与防重复）

先做一个假提交函数 `submitSignup(payload)`：`new Promise` 延迟 800ms 后 resolve（模拟给后端），在 `handleSubmit` 的回调里 `await` 它：

```js
const { isSubmitting, handleSubmit, resetForm, ... } = useForm({ ... })

const onSubmit = handleSubmit(async (values) => {
  await submitSignup(values)          // 模拟接口，内部自己管理 loading
  success.value = true                // 显示"报名成功"卡片
  resetForm()                         // 成功后清空表单（回顾 11.6：校验状态一并清）
})
```

> 锚点检查：疯狂连点提交按钮，只发出一次"提交中"；成功后表单所有字段与错误提示都回到初始态。

### Step 4：模板绑定五种输入 + 错误展示（回顾 11.1 / 11.2 / 11.7）

用 `useField` 或 `useForm` 的 `defineField` 把 `name`（text）、`phone`（text + `inputmode="numeric"`）、`session`（select，含"9:00-11:00 场 / 14:00-16:00 场 / 19:00-21:00 场"）、`bringItem`（checkbox）、`remark`（textarea）绑进模板；每项下方用 `errors.xxx` 展示红字错误，提交失败可聚焦到第一个错误字段。样式做到"错误时输入框红边"，参考 11.7 的交互体验。

### Step 5：抽成 `useSignup` composable（回顾 11.9）

把 `useForm` 的配置、校验 schema、`onSubmit` 成功/失败处理全部搬进 `src/composables/useSignup.js`，返回 `errors / isSubmitting / handleSubmit / success` 等，组件里只留：

```js
const { errors, isSubmitting, handleSubmit, success } = useSignup()
```

并让"报名成功"卡片在 `success` 为真时显示，关闭按钮把它置回 `false`。
