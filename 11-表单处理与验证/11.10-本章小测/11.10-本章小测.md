const { values, handleSubmit } = useForm({

## 参考答案

**一、单选题**

| 题号 | 答案 | 解析 |
|---|---|---|
| 1 | B | `.trim` 自动去首尾空格。A 错在"只能"，组件上也能用；C 错在用户输入非数字时保持原样；D 错在 checkbox 和 select 走的是 `@change` 而不是 `@input` |
| 2 | B | 一个组件可以绑定多个 `v-model`（`v-model:firstName`、`v-model:lastName`） |
| 3 | D | `confirmed:@password` 是和 `password` 字段对比。A 错在验证失败时回调不执行（会走 invalidSubmit）；B 错在 `resetForm` 同时重置值和状态；C 错在 `defineRule` 必须在 `useForm` 之前 |
| 4 | C | checkbox 多选时 `v-model` 必须绑定数组，每个 checkbox 的 `value` 就是选中时加入数组的值 |
| 5 | D | 异步规则必须考虑网络错误，要用 try-catch 处理并返回友好的错误信息 |
| 6 | A | `submitting` ref + `:disabled` 是最常见的防重复方案。`@submit.once` 不存在；`resetForm()` 不能阻止用户快速双击 |

|---|---|

| 8 | ❌ 错误（用 `:value` 绑定可以传对象） |

**三、简答题**

**12.** 参考答案：
- 原生 `<input>` 上的 `v-model` 是 `:value` + `@input` 的语法糖，Vue 帮你做了 DOM 和数据的双向同步
- 组件上的 `v-model` 本质是 `:modelValue` prop + `@update:modelValue` 事件。它并没有打破"单向数据流"——子组件不直接改父组件的数据，而是通过 emit 事件通知父组件去改，控制权始终在父组件手里。Vue 3.4 的 `defineModel` 只是让写法更简洁，底层仍然是 prop + emit
- 之所以说它是"实现双向绑定的正确方式"，是因为它遵循了"数据向下，事件向上"的原则，比直接在子组件里改父组件传入的对象要安全可控

**13.** 参考答案（至少 3 点）：
1. **规则散落**：手写验证时每个字段的校验逻辑散落在不同函数里，加一个字段要改多处。VeeValidate 把所有规则集中声明在 `validationSchema` 里，一目了然。
2. **重复代码**：每个字段都要写 `@blur` + `@input` 绑定、错误信息展示模板。VeeValidate 提供 `handleBlur`、`errors` 等开箱即用的方案。
3. **提交拦截**：手写时需要在 `handleSubmit` 里先调 `validateAll()`，返回值判断。VeeValidate 的 `handleSubmit` 自动拦截，只有通过才执行回调。
4. （加分）**异步校验**：手写异步校验需要自己管理 loading 状态、防抖、超时等。VeeValidate 的 `defineRule` 天然支持返回 Promise，配合 VueUse 的 `useDebounceFn` 能快速实现。

**14.** 三个问题：
1. `checkUsername` 没有被 await——提交回调里 `checkUsername(formValues.username)` 没有 `await`，校验结果被忽略了，异步校验形同虚设。
2. 没有错误处理——`fetch` 如果网络出错，页面会直接崩溃，没有任何 try-catch。
3. 校验结果没有整合到表单验证流——`checkUsername` 返回 `false` 时只弹了 alert，但没有阻止后续的 `fetch('/api/register')`。

修正版本：
```js
const onSubmit = handleSubmit(async (formValues) => {
  try {
    const available = await checkUsername(formValues.username)
    if (!available) return  // 校验不通过，阻止提交
  } catch (err) {
    alert('校验失败：' + err.message)
    return
  }
  await fetch('/api/register', {
    method: 'POST',
    body: JSON.stringify(formValues)
  })
})
```

**四、编程题**

**15.** `PriceInput` 参考实现：

```
<script setup>
const model = defineModel({
  get(val) {
    // 向外暴露：分 → 元
    return (val / 100).toFixed(2)
  },
  set(val) {
    // 向内存储：元 → 分
    const num = parseFloat(val)
    return isNaN(num) ? 0 : Math.round(num * 100)
  }
})
</script>

<template>
  <div class="price-input">
    <span class="prefix">¥</span>
    <input
      :value="model"
      @input="model = $event.target.value.replace(/[^\d.]/g, '')"
      placeholder="0.00"
    />
  </div>
</template>
```
